## M0-T03 · 色彩与主题 token — DONE·部分（2026-11-10 02:32）

**做了什么**：反推真 FlowUs 的完整浅色调色板并做 WCAG 对比度核验；深色未采集到，拆为 M0-T14。

**方法（重要）**：FlowUs **不用 CSS 变量**（整页只有 3 个，还都是图标 URL），配色编译进 Tailwind 工具类。所以写 `palette.mjs` 从「class 名 → 计算样式」反推，按 `bg-*`/`text-*`/`border-*` 归组取主值，并过滤 `text-left`/`text-ellipsis` 这类排版误报。

**实测基色板**：
- 主色 `rgb(2,133,255)` = `#0285FF`
- 内容底 `#FFFFFF`｜侧栏底 `#F7F7F7`（bg-aside）｜悬停底 `rgba(0,0,0,0.06)`｜选中底 `rgba(2,133,255,0.10)`
- 文字四级：正文 `#37352F`(t2) / 次级 `#5F5E5B`(grey2·t2-medium) / 三级 `#91918E`(grey3·t4-medium) / 标题·选中 `#000000`
- **默认边框 `#E5E5E5`，实测出现 307 次**，是全局第一高频色
- 侧栏右边框 `#F0F0F0`(grey7)｜重边框 `#E0E0E0`(grey5)
- 语义命名体系：`active_color` / `grey2..grey7` / `t2..t4`，浅底一律 **alpha 变体**（0.05/0.10/0.30）

**⚠️ 关键发现：FlowUs 自己的配色有 5 组文字不达 WCAG AA**

| 组合 | 对比度 | 阈值 |
| --- | --- | --- |
| 三级文字 `#91918E` on 白 | 3.16 | 4.5 ❌ |
| 三级文字 `#91918E` on 侧栏底 | 2.95 | 4.5 ❌ |
| 主色文字 `#0285FF` on 白 | 3.62 | 4.5 ❌ |
| 主色文字 `#0285FF` on 侧栏底 | 3.38 | 4.5 ❌ |
| 白字 on 主色（普通字号按钮） | 3.62 | 4.5 ❌ |

达标项：正文 10.76–12.26、次级 5.69–6.48、黑标题 21.00。
根因是 `#0285FF` 这个蓝本身很亮，不是换算错。**本项目旧调色板曾全部压到 ≥4.56，按 FlowUs 复刻会主动退回不达 AA。**

**取舍建议（等用户一句话，未擅自改）**：默认**照抄**以保 1:1；若用户希望外观一致但文字更清晰，最小改动是把主色压到 `#0070E0`、三级压到 `#7A7A77`，肉眼几乎无差、AA 可过。

**深色主题：未采集到**。侧栏图标行 5 个入口 / 空间设置全表 / 「更多」菜单（打开的是 FlowUs AI 面板）/ localStorage 14 个键（无任何 theme·dark 键）/ 根节点 `color-scheme: normal` —— 都没找到开关。**不硬凑、不编**，拆为 **M0-T14**。

**交付物**：`docs/基准/基准-色彩.md`；证据 `docs/基准/证据/M0-T03/`；工具 `palette.mjs` + `contrast.mjs`

**验收（真实输出）**：规格 9 个关键值全覆盖；`contrast.mjs` 默认退出 **0**、`--strict` 退出 **1**（语义符合设计）。→ **通过**
