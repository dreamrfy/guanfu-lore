## M0-T07 · 交互行为规格 — DONE（2026-11-10 03:16）

**动效体系（全量去重实测）**：
- **`background-color | 0.1s | ease-out` 出现 547 次** —— 全站主力，做错整站手感就不对
- 第二梯队 `background-color, border-color, color, fill, stroke | 0.1s | cubic-bezier(0.4,0,0.2,1)`（61）+ `opacity | 0.1s | 同曲线`（33）
- 另有 opacity 0.15s（18）、all 0.15s（14）、**all 0.02s ease-in（12，近乎瞬时）**、all 0.2s/0.3s/0.5s 各 1–2 处
- **最长过渡只有 0.5s，且无弹跳/回弹缓动** —— 全程克制
- 动画：`fade-in 0.3s ease`（13）、`fadeIn 1s ease`（4）

**hover 揭示三种模式并存（实测）**：
1. `display` 切换（`hidden` → `group-hover:flex`）：侧栏 ⋯ 与 ＋，各 20×20
2. `opacity` 切换（`opacity-0` → `group-hover:opacity-100`）：占位不消失，**避免布局跳动**
3. 反向切换（`group-hover:hidden`）：页项 emoji 图标

## M0-T31 · M0 收尾补采 — DONE·部分（2026-11-10 07:34）【结案了一个悬案】

### 🎯 ② 「16/24 vs 16/26」**彻底解决**（悬了 T04→T24→T27→T30 四轮）

| 层级 | 元素 | 字号 | **行高** | 高 |
| --- | --- | --- | --- | --- |
| L0 | `SPAN`（文字） | 16px | **26px** | 21 |

| L2 | `SECTION`（块容器，`my-px`） | 16px | **24px** | 34 |
| L3 | 内容区容器 | 16px | **24px** | 228 |

```
块高 34 = 行内行高 26 + py-1 上下内边距 (4+4)
块间距 2 = my-px 上下外边距 (1+1)
```

   - `FlowUsDocument`：以 uuid 为键的块表 + 根块；**渲染顺序看 `subNodes`**；能从 `/api/docs/{id}` 响应直接还原（M6 导入的入口）
2. **正文序列化升级 v1 → v2**：`content` 列不再存自制的 `{v:1,b:[{t,x,i}]}`，改存 FlowUs 块结构。
   `decodeBlocks` 同时兼容 v2 / v1 / 更早的纯文本，`BlockData` 增加 `level`（标题级别）
3. **DB `schemaVersion` 7 → 8** + `migrateContentToFlowUsBlocks()`：存量正文就地升级、幂等、空正文跳过。
   **只改数据不改表，所以不需要重跑 codegen** —— 这也让并行会话不会因为我改 `database.g.dart` 而编译失败。

### 为什么没建 `blocks` 表（明确的设计取舍，记下来备查）

最"教科书"的做法是建 blocks 表（uuid 主键 + pageId + type + parentId + subNodes + data + version），
这样 M7 同步能按块做增量 diff。**但这一轮不做**，理由是：M2 的编辑器要用 `appflowy_editor_ce`（已选型），
它的文档 JSON 是 Delta 结构、按页整存；现在就上 blocks 表会变成"两份真相"，M2-T02 起每写一次要同步两张表。
所以先用**一列 JSON（FlowUs 形状）单真相**，等 M7 真做同步时再按块拆表（那时 `FlowUsDocument` 就是拆表的现成输入）。
**这条决定需要在 M7 开工前复查。**

### 踩到的坑

- **枚举常量不能和字段同名**：我写了 `code(25,'代码块')` 而枚举里又有 `final int code` —— Dart 里枚举常量是静态成员，
  直接撞名，报的却是一串"int 不能赋给 FlowUsBlockType"的迷惑错误。改名 `codeBlock` 后立刻好。
- **旧测试断言的是存储字符串**：`expect(fired.last, contains('"t":"bullet"'))`。格式一升级就全红。
  改成"解码后类型对"——**断言要绑定语义，不要绑定编码**，否则每次改格式都要修测试（而且修法容易变成"改断言让它过"）。
- `final` 局部变量在 try/catch 里两次赋值，Dart 也不允许（`legacy` 改成非 final）。

## M2-T21 块手柄 overlay 化 + 「＋」插块（2026-11-10）

M2-T07 遗留的"手柄画得出、点不到"这轮解决了。

**根因**：手柄原本画在 `blockWrapper` 的块内 Stack 里 —— 块外 20px 被裁剪；而 Flutter 的 hit test
出不了父边界，所以块外那块永远点不到。

**做法**：换成 **OverlayPortal**，两个图标挂到根 Overlay（整屏坐标），位置用 hovered 块的**全局矩形**算：
`手柄 left = 块 left − 20`、`＋ left = 块 left − 22`、`＋ top = 手柄 top + 14`。
块侧只做"报到"（`BlockHandleController`：hover 进入/离开、块内 dx），36 宽的实测热区里
"上半=手柄 / 下半=加号"分派点击；离开块后 120ms 淡出，够把指针挪到图标上。
