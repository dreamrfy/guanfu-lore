【第 2 步 · 断掉僵尸任务（硬性 30 分钟）】
遍历 state.running：`startedAt` 距今超 30 分钟**且执行报告-v5.md 没有该任务的新进度行** → 任务表标 `断掉·超时（写最后进度一行）`，从 running 移除，删它的锁 `ops/锁/T-<编号>.lock`，执行报告记一条。本轮不重试（第 3 步 5 处理）。
**长任务免疫**：估时 >40min 的任务按纪律 1 每个子步骤落进度行；有新进度行就视为有进展，不断。

【第 3 步 · 领任务】
1. 并发上限 = `state.maxConcurrent`（默认 2）。running 已满 → 回「并发已满，本轮不领」结束。
2. 候选 = 任务表编号从小到大，第一个同时满足：状态 `TODO`（或 `TODO·重试`）、不在 running、**模块与所有 running 任务不同**（并行只跨模块）。
3. 原子认领：创建 `ops/锁/T-<编号>.lock`（写 sessionId+时间）；已存在 → 被别人领了，换下一个，绝不抢锁。
4. 认领成功立即：任务表状态改 `DOING·领取（HH:MM 领）`；state.running 追加 `{taskId, sessionId, module, startedAt}`；写盘。
5. 无 TODO 候选、但存在 `断掉·超时` 任务 → 把编号最小的一个重开为 `TODO·重试`，正常领取它。一次只重开一个。
6. 全部 DONE/BLOCKED 且无断掉 → 收工（第 8 步）。
