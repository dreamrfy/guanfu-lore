# 复盘：通用踩坑与经验总结（跨项目通用）

> 从 2026-11-04~06 的 CloudBase 探坑、云函数排障、VPS 部署、浏览器操控中提炼的通用规律。**换项目依然适用。**

## 一、Serverless/云函数类

1. **免费套餐第一看「执行超时」**：3 秒（CloudBase 免费版）只能跑"查天气"级任务；任何"读网页+下载+存储"的多步 I/O 任务都要 300 秒级。建函数前先看超时能不能调——一个数字判断套餐生死。
2. **运行时版本是隐形门槛**：跑 TypeScript（原生 strip 模式）必须 Node 22.6+/24；平台默认常是旧版，**建实例时锁定运行时，创建后不可改**。
3. **Node 24 两个新特性/坑**：①可直接 `require(".ts")`（type stripping）；②**不支持构造函数参数属性**（`constructor(private x)` 语法报 ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX）。
4. **云函数加载器是 CommonJS 世界**：ESM `import` 入口会加载即崩（443、日志无堆栈）。垫片写 `module.exports.main` + 包内 package.json **去掉 `type:module`**。async main 记得 **返回 Promise + callback 双兼容**（平台可能不等未决 Promise 就判失败，报 430+2ms）。
5. **「自动安装依赖」开关 vs 包内 node_modules 会打架**：自带依赖就关掉它。
6. **错误码的规律**：443/430=加载或调用层、433=超时类、`ResourceNotFound.Entryfile`=入口文件不匹配。**日志无堆栈=代码没执行到**，问题在加载层。

## 二、打包与上传

7. **PowerShell `Compress-Archive` 的 zip 云平台常解不开**（路径分隔符变体）→ 用 Windows 自带 `tar.exe -a -c -f`（标准 zip）。打包脚本末尾**必须自验**（`-tf` 列表检查关键文件存在）。
8. **scp 端口是大写 `-P`**（ssh 是小写 `-p`）——历史不一致，所有 cli 都这样记不住就查。
9. Git Bash 里 Windows 路径：`E:\` → `/e/`，`\` → `/`。

## 三、Linux/SSH 通用

10. **Ubuntu 24.04 的 ssh.socket 机制**会绕过 `sshd_config` 的 Port 改动！修复：`systemctl disable --now ssh.socket` → `restart ssh` → `enable ssh`。改端口后用 `ss -tlnp` 实证监听，别信配置文件。
11. **SSH 加固顺序是保命的**：传公钥 → 验证密钥登录 → 才能禁密码/关旧端口；全程留一个已连接窗口当保险通道。
12. **换端口的意义只是降噪**（躲开扫描清单：22/2222/8080 等），真正的安全是密钥（数学不可伪造）。原则：5 位数、躲 8000~11000（未来自用段）、自己好记。
13. **腾讯云轻量镜像自带**：1.9G swap、Docker、监控四件套（~150MB，barad_agent 是控制台监控图的数据源，别乱卸）。
14. **PG 模式 CloudBase 环境没有文档型数据库**，且 PG 实例无法单独关闭（空转计费关不掉，~40 点/天）。开环境前想清楚数据库类型，**它跟环境绑死**。
15. **买 VPS 看续费价**：99 首年次年常跳 300+；数据放对象存储（R2）的话搬家十分钟，"到期换一家新购"是合法策略。轻量机带宽 3M=384KB/s，后台任务完全够用。

## 四、AI 操控浏览器（Tabbit）经验

16. **用户登录态过期是头号假象源**：页面显示"函数正常"可能是缓存，刷新后跳登录页才见真相；列表 0 条 + 报错 = 会话死了。
17. React 组件的 radio/dropdown 用 `dispatchEvent` 合成事件序列（mousedown/mouseup/click）才能切动；`force: true` 绕浮层遮挡；隐藏 `input[type=file]` 可直接 `setInputFiles` 绕过系统文件选择窗。
18. 控制台表单的保存可能静默失败（触发器 JSON 写两次都弹回）——**保存后必须刷新复核**，别信"没报错就是成功"。
19. **部署 ≠ 创建**：CloudBase 建完函数还要在详情页点一次「部署」；更新代码走「上传代码」面板再部署，报 `baseCodeCosInf` 就删函数重建（创建通道更稳）。

## 五、工作方法（对 AI 协作特别有效）

20. **"要死就死完了再说"的实测主义**：免费版能不能跑，配置好就真转发测一轮——两轮 0 入库的数据比任何推测都有力，直接终结决策内耗。
21. **逐步停等授权的教学模式**：每步给「目的+命令+逐词解释+预期效果」→ 用户选"授权我做"或"我自己来"——用户全程亲手踩了 SSH 的 5 个坑，学习密度远超一键代劳。
22. **改源码走正路**：本机改 → 跑测试 → scp 上传成品；在服务器上 sed/追加拼接源码会被安全钩子拦截（合理的保护），而且绕过测试很危险。
23. **文件系统分区哲学**：`E:\credentials`（永久凭证，永不清）/ `E:\dev\tmp`（临时，随时清）/ 项目内 docs（进 git 的证据与复盘）——**密钥远离一切"会被批量清理"的目录**。
