## 〇、这份文档是什么，怎么用

**它是一份长期手册**，不是一次性结论。用途有两个：

1. **现在**：让你确认「我想要的确实都在这份清单里、没有多余的东西」；
2. **将来**：每做一个功能之前，先翻到对应条目——里面记着这个功能该用哪些现成开源件、
   每个候选的详细情况（授权、活跃度、能力边界、集成方式），**包括这次没选中的候选**，
   因为下一个功能可能正好需要它。

### 怎么读

清单的组织结构是三层：

```
模块（12 个，对应产品的十二条线）
  └ 需求（一块能叫出名字的能力，如「斜杠菜单」）
      └ 微件（最小单位，小到「拖拽手柄」这种，每个微件单独去查开源件）
```

### 每个微件条目写三件事（按你的要求 + 去掉一切与已有代码有关的内容）

| 栏 | 内容 |
| --- | --- |
| **① 这是什么** | 说人话：它解决什么问题、没有它会怎样 |
| **② 在 FlowUs 里的位置** | 你在哪个界面、哪一步会遇到它（尽量配已采集的真机截图） |
| **③ 你怎么验收** | 不懂技术也能用：点哪几下、看到什么算对了 |

将来每个条目下方还会挂第四块：**④ 开源候选**（查证阶段填，含所有候选、不只选中的那个）。

## 二、模块一：编辑器与页面（微件级明细）

> 这个模块 34 条，是全书条目的格式样板。其余模块按同一格式续补。

### 1.1 页面与页面树

---

**M1-01 页面本体** ｜ P0

- **① 这是什么**：一篇笔记就是一个「页面」——有标题、有正文，也能变成别人的子页面。
  它是整个软件的最小容器；一切东西（文字、表格、图片、AI 结果）最后都装在某个页面里。
- **② 在 FlowUs 里的位置**：点侧栏任意一项，右边整块区域就是一个页面。
- **③ 你怎么验收**：新建一篇 → 随便写几个字 → 关掉软件再打开 → 字还在 = 对了。

---

**M1-02 侧栏页面树** ｜ P0

- **① 这是什么**：左边那一竖栏把所有页面按父子层级列出来（子页面缩进），像电脑的文件夹树。
  没有它，你的笔记就是一堆散页，找不到、也组织不起来。
- **② 在 FlowUs 里的位置**：窗口最左侧，从上到下那一列页面名。
- **③ 你怎么验收**：新建一篇页 → 侧栏立刻多出它的名字；把它拖到另一篇底下 →
  它变成那篇的子页；关掉软件再开 → 层级还在 = 对了。

---

**M1-03 页面树操作（新建 / 重命名 / 删除 / 移动）** ｜ P0

- **① 这是什么**：在侧栏那一项上右键或点「⋯」能改名字、挪位置、删除。
  没有它，你建错了页面就只能忍着。
- **② 在 FlowUs 里的位置**：侧栏某项悬停时右边冒出的「⋯」，或右键菜单。
- **③ 你怎么验收**：右键一篇 → 改名 → 侧栏跟着变；删除 → 它进回收站、侧栏消失 = 对了。

---

**M1-04 页面标题** ｜ P0

- **① 这是什么**：每篇最上面那行大字标题，空的时候显示灰色「无标题」提示。
- **② 在 FlowUs 里的位置**：正文最顶上的大字号那一行。
- **③ 你怎么验收**：点标题打字 → 侧栏那一项的名字也跟着变 = 对了。

---

**M1-05 页面图标** ｜ P1

- **① 这是什么**：标题旁边那个小图标（emoji 或图片），用来一眼认出是哪篇。
- **② 在 FlowUs 里的位置**：标题左上方；鼠标移上去出现「添加图标」。
- **③ 你怎么验收**：加一个 🍀 → 侧栏那一项前面也出现同样的图标 = 对了。

---

**M1-06 页面封面图** ｜ P1

- **① 这是什么**：页面顶部那张横幅大图，让一篇笔记有「封面感」。
- **② 在 FlowUs 里的位置**：标题上方整条；鼠标移上去出现「更改封面」。
- **③ 你怎么验收**：设一张图 → 顶部出现横幅 → 重启还在 = 对了。

---

### 1.2 正文块类型

---

**M1-07 段落块** ｜ P0

- **① 这是什么**：正文的基本单位，一段话就是一个块。空段落会显示灰色提示语。
- **② 在 FlowUs 里的位置**：正文里每一段普通文字。
- **③ 你怎么验收**：敲回车 → 新起一段，段与段之间的间距和 FlowUs 看着一致 = 对了。

---

**M1-08 标题块（H1~H4）** ｜ P0

- **① 这是什么**：比正文大的分节标题，用来给长文分段。
- **② 在 FlowUs 里的位置**：输入 `/标题` 或行首输入 `#` 空格。
- **③ 你怎么验收**：打 `##` 再空格 → 这行变成二级标题，字号明显变大 = 对了。

---

**M1-09 无序 / 有序列表块** ｜ P0

- **① 这是什么**：圆点和数字列表，列点东西时用。
- **② 在 FlowUs 里的位置**：行首打 `-` 空格 / `1.` 空格，或 `/列表`。
- **③ 你怎么验收**：打 `-` 空格 → 出现圆点；回车 → 自动续一个圆点；退格 → 退出列表 = 对了。

---

**M1-10 待办列表块（勾选框）** ｜ P0

- **① 这是什么**：带方框的清单项，点一下打勾。日常记待办全靠它。
- **② 在 FlowUs 里的位置**：`/待办列表`，或行首 `[]` 空格。
- **③ 你怎么验收**：打勾 → 方框里出现对勾、文字变灰划线 → 重启后还是打勾状态 = 对了。

---

**M1-11 折叠列表块（toggle）** ｜ P1

- **① 这是什么**：一个能收起来的小三角，点开显示里面的内容，点合就隐藏。用来放长内容不占地方。
- **② 在 FlowUs 里的位置**：`/折叠列表`。
- **③ 你怎么验收**：写一句、下面缩进写两行 → 点左边小三角 → 下面两行收起来了 = 对了。

---

**M1-12 引用块** ｜ P0

- **① 这是什么**：左边一条竖线的引用段落，用来引别人的话、放摘录。**剪藏的原文正文就靠它**。
- **② 在 FlowUs 里的位置**：`/引用`，或行首 `>` 空格。
- **③ 你怎么验收**：打 `>` 空格 → 出现左边竖线缩进的一段 = 对了。

---

**M1-13 着重文字块（callout）** ｜ P1

- **① 这是什么**：带底色和左边小图标的一个方框（灰/黄/红/蓝四种底色），用来强调重点。
- **② 在 FlowUs 里的位置**：`/着重文字`。
- **③ 你怎么验收**：插入一个着重文字 → 它是一个带背景颜色的方框，左边有个小图标 = 对了。

---

**M1-14 代码块** ｜ P0

- **① 这是什么**：深色底、等宽字的一段代码，能选语言做语法高亮。
- **② 在 FlowUs 里的位置**：`/代码`，或行首三个反引号。
- **③ 你怎么验收**：打三个反引号 → 出现深色代码框；在里面打字不会被当成正常文本 = 对了。

---

**M1-15 分割线** ｜ P2

- **① 这是什么**：一条横线，把上下内容分开。
- **② 在 FlowUs 里的位置**：`/分割线`，或行首 `---`。
- **③ 你怎么验收**：打 `---` → 变成一个横线；光标自动落到下面新的一段 = 对了。

---

**M1-16 图片块** ｜ P0

- **① 这是什么**：正文里的图片，能拖边改大小、能加说明文字。**剪藏的封面图、文章配图要靠它**。
- **② 在 FlowUs 里的位置**：`/图片` 或直接把图拖进来 / 粘贴。
- **③ 你怎么验收**：拖一张图进来 → 显示出来；拖右下角改大小；重启后还在 = 对了。

---

**M1-17 视频 / 音频 / 文件块** ｜ P1

- **① 这是什么**：嵌视频（B站/YouTube 等）、传附件文件（PDF/压缩包）的块。
  剪藏 B站/抖音视频时，至少要存住视频信息或本地备份。
- **② 在 FlowUs 里的位置**：`/视频` `/文件`。
- **③ 你怎么验收**：贴一个 B站链接 → 变成一个能点的视频卡片 = 对了。

---

**M1-18 网页书签块** ｜ P1

- **① 这是什么**：贴一个链接，自动变成一张带标题和图的小卡片。收集资料很常用。
- **② 在 FlowUs 里的位置**：`/网页书签`，或粘贴链接后选「作为书签」。
- **③ 你怎么验收**：贴一条公众号链接 → 出现带标题的小卡片（不是一行蓝字）= 对了。

---

**M1-19 表格块（简单表格）** ｜ P1

- **① 这是什么**：正文里插一个普通小表格（行列格子，不是第 2 模块的多维表）。
- **② 在 FlowUs 里的位置**：`/表格`。
- **③ 你怎么验收**：插入表格 → 能加行加列、能填字 = 对了。

---

**M1-20 多维表格块（嵌入页面）** ｜ P0

- **① 这是什么**：把一个多维表（第 2 模块那套）当作一个块嵌进页面正文里。
  剪藏库就是这么嵌在「剪藏」页里的。
- **② 在 FlowUs 里的位置**：`/多维表格` → 选已有库 或 新建库。
- **③ 你怎么验收**：在页面里插入一个多维表 → 表格直接显示在正文中，能编辑 = 对了。

### 1.3 块的操作方式（你在 FlowUs 里最顺手的那套）

---

**M1-21 斜杠菜单（/ 命令）** ｜ P0

- **① 这是什么**：空行打一个 `/`，弹出所有块类型的菜单，打字筛选、回车插入。
  **这是 FlowUs 里最高频的操作，手感必须一致。**
- **② 在 FlowUs 里的位置**：任意空段落，敲 `/`。
- **③ 你怎么验收**：敲 `/` → 弹菜单 → 打「代码」→ 回车 → 变成代码块 = 对了。
  （手感要点：菜单出现在光标正下方、能用方向键选、Esc 能关掉。）

---

**M1-22 块菜单（六点手柄）** ｜ P0

- **① 这是什么**：鼠标移到某块左侧，出现「六点手柄 + ＋」，点手柄弹出该块的菜单
  （删除/复制/颜色/转换为/移动…）。
- **② 在 FlowUs 里的位置**：任意块的左边，鼠标悬停时。
- **③ 你怎么验收**：鼠标移到一段左边 → 出现手柄 → 点它 → 弹出菜单 → 点「删除」块没了 = 对了。

---

**M1-23 块拖拽（手柄拖动排序）** ｜ P0

- **① 这是什么**：按住六点手柄上下拖，把块挪位置，甚至拖进别的页面。整理笔记时天天用。
- **② 在 FlowUs 里的位置**：同上，按住手柄拖动。
- **③ 你怎么验收**：按住第一段的手柄往下拖 → 它跟着鼠标走、落点有蓝线 → 松手后顺序真的变了 = 对了。

---

**M1-24 块颜色面板** ｜ P1

- **① 这是什么**：块菜单里的「颜色」，能给一块文字上色或加底色。
- **② 在 FlowUs 里的位置**：块菜单 →「颜色」，右侧弹出两段色板（文字颜色 / 背景颜色）。
- **③ 你怎么验收**：选一段 → 颜色 → 点一个底色 → 那段有底色了；重启还在 = 对了。

---

**M1-25 块转换** ｜ P1

- **① 这是什么**：把已有的一块从一种类型换成另一种（比如普通段落 ↔ 标题 ↔ 引用），内容不丢。
- **② 在 FlowUs 里的位置**：块菜单 →「转换为」。
- **③ 你怎么验收**：一段文字 → 转换为标题 → 字变大了但内容没丢 = 对了。

---

**M1-26 输入快捷（Markdown 即时转换）** ｜ P1

- **① 这是什么**：行首打 `#`、`-`、`>`、`1.` 再空格就自动变成对应块，不用开菜单。
- **② 在 FlowUs 里的位置**：直接在空行打这些符号。
- **③ 你怎么验收**：打 `1.` 空格 → 变成有序列表 = 对了。

---

**M1-27 键盘快捷键体系** ｜ P1

- **① 这是什么**：Ctrl+B 加粗、Ctrl+Z 撤销这类。老手的效率全靠它。
- **② 在 FlowUs 里的位置**：任何可输入处。
- **③ 你怎么验收**：选中一段按 Ctrl+B → 变粗体 = 对了。

---

**M1-28 撤销 / 重做** ｜ P0

## 四、模块三：捕获与收集（微件级明细）

> 这是三大核心的第二条：**把外面的东西收进来**。核心链路是

### 3.1 你的日常入口

---

**M3-01 微信转发通道** ｜ P0

- **③ 你怎么验收**：微信里转发一篇文章给那个号 → 等一两分钟 → 知识库里出现这条记录，

**M3-02 入库去向配置** ｜ P0

- **① 这是什么**：进来的东西**放到哪**由你定——进哪个表、落在哪个页面下、哪些字段怎么填。

**M3-03 入库回执** ｜ P1

- **③ 你怎么验收**：转发一篇文章 → 手机上或软件里能看到「已入库」的提示；故意发个坏链接 →

**M3-04 粘贴链接入库** ｜ P0

- **① 这是什么**：不用微信转发也行——把链接粘到知识库的某个入口，它自己去抓。

**M3-05 快速捕捉入口（全局快捷键 / 悬浮窗）** ｜ P1

- **① 这是什么**：无论在用什么软件，按一下快捷键就弹出一个小窗，随手记一句 / 存一条链接，回车收工。

- **② 在 FlowUs 里的位置**：FlowUs 桌面端有快捷入口（类似「新建到收件箱」）。
- **③ 你怎么验收**：按快捷键 → 弹出小窗 → 打一行字回车 → 知识库里多出这条 = 对了。

---

**M3-06 手机端接收入口（系统分享面板 + 微信「更多打开方式」）** ｜ **P0**（2026-11-14 由 P1 提为 P0，用户拍板为最高优先级）

- **① 这是什么**：手机上刷到文章，**不用转发、不用粘贴**，直接把文章交给知识库。微信里有两条路：
  - **路径 ②「更多打开方式」**：文章页 → 用 XX 打开 → 更多打开方式 → 点你的 App。**用户只点 1 下**，最省事；
  - **路径 ③「选择手机中的应用」**：同上位置 → 选择手机中的应用 → 系统分享面板里选你的 App（2 下）。这条路不限于微信，**别的 App 分享一段带链接的文字也能进来**。
  两条路交给我们**都是文章网址**，直接调已有的剪藏接口（`POST /api/clip`），**抓取仍在服务器，手机不做抓取**。
- **② 在 FlowUs 里的位置**：FlowUs 手机 App 支持系统分享（对应路径 ③）；**路径 ② 的「打开方式」直达 FlowUs 没有**，是我们多出来的。
- **③ 你怎么验收**：在微信里打开一篇公众号文章 → 「更多打开方式」里能看到我们的 App → 点一下 → 知识库里出现这条记录（标题/公众号名/正文都在）= 对了。再用别的 App 分享一条带链接的文字，同样能进来 = 路径 ③ 也对。
- **④ 两条路要挂的牌子**（安装清单，各挂一次即可，互不冲突）：
  `VIEW` + `DEFAULT` + `BROWSABLE` + `http/https`（进路径 ② 的列表）；`SEND` + `text/plain`（进路径 ③ 的分享面板）。
- **⑤ 必须处理的边界**：挂了「打开链接」的牌子后，用户点**任何**链接的「打开方式」里都会出现我们 → **不是目标站点时必须转交给系统浏览器**；挂了「接收文本」的牌子后，所有分享纯文字的场合都会出现我们 → 文本里没有网址时安静退出。
- **⑥ 硬前置**：手机必须能访问到剪藏服务（现在只绑电脑的 `127.0.0.1:8787` + SSH 隧道，**手机连不上**）。要么局域网方案，要么服务上云对外开。
- **⑦ 取证与施工细节**：见《手机端入口调研-微信三种路径实证.md》（含系统日志原文、截屏、三种路径对账）。**「微信转发 → 其他应用」那条（给的是聊天记录 zip）已明确搁置**，不在此条范围内。

**M3-07 手动新建一条** ｜ P0

- **① 这是什么**：最朴素的方式——在表里点「＋新建」，自己填一条。
- **② 在 FlowUs 里的位置**：多维表底部「＋新建」。
- **③ 你怎么验收**：点新建 → 填标题 → 表里多一行 = 对了。

## 六、模块五：检索与连接（微件级明细）

**M5-01 全局搜索** ｜ P0

### 6.1 高亮与批注

**M6-01 原文划线高亮** ｜ P1

- **① 这是什么**：在原文（剪藏进来的正文）里划重点，不同颜色分类。

**M6-02 我的批注** ｜ P1

**M6-03 高亮汇总** ｜ P1

- **③ 你怎么验收**：翻出汇总 → 看到各篇文章里划过的句子，点一条能跳到原文那一段 = 对了。
