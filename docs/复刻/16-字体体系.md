# 16 字体体系（观复 · Lore）

- 状态：**推荐稿 v1.0**（2026-11-18）
- 上游：[14-前端设计规范-总纲.md](14-前端设计规范-总纲.md) §4.3
- 适用：Web / Windows / 安卓 / 扩展 / 官网 / 安装包
- 证据：`ops/观测/专项/flowus-styles.json`（FlowUs 字号实测）、`app/src/design/fonts.ts`（现有字体主题）、`app/src/styles/index.css`（现有字号变量）

---

## 1. 结论摘要

1. **推荐「宋体标题 + 黑体正文」**：页面标题与编辑器 H1/H2 用思源宋体/Noto Serif SC 600，正文与 UI 用思源黑体/Noto Sans SC 400/500。它让观复一眼区别于 FlowUs/Notion 的全黑体，又不牺牲正文可读性。
2. **UI 正文 14/22，编辑器正文 16/28**；页面标题 36/48（桌面）/28/36（手机）；官网首屏 44/56。
3. **字重只用 400/500/600**，不用 700；中文标题字重 600 已足够，700 会“喊”。
4. **等宽用 JetBrains Mono 13/20**；表格数字用 `font-variant-numeric: tabular-nums`。
5. **全部可打包字体均为 OFL**：Noto Sans SC、Noto Serif SC、LXGW WenKai、JetBrains Mono；雅黑/苹方只作系统回退，不嵌入。
6. **性能预算**：UI 黑体 3 个字重 + 宋体 2 个字重，woff2 子集后合计 ≤ 6MB；阅读宋体按需懒加载，不阻塞首屏。
7. **中文排版**：行长 36~44 字（内容宽 708 / 16px ≈ 44em）；段间距 12px；标题上 1.5em、下 .5em；不用首行缩进。
8. **旧字体主题保留**：`fonts.ts` 的六套主题继续可用，但默认 `noto`；新增 `serif` 标题开关，默认开启。

## 3. 候选方案

### 3.1 A. 宋体标题 + 黑体正文（推荐）

| 角色 | 字体 | 字重 | 字号/行高 |
| --- | --- | --- | --- |
| 页面标题 H1 | Noto Serif SC / 思源宋体 | 600 | 36/48 |
| 编辑器 H2 | Noto Serif SC | 600 | 28/36 |
| 编辑器 H3 | Noto Sans SC | 600 | 22/30 |
| 正文/UI | Noto Sans SC | 400 | 14/22 |
| 编辑器正文 | Noto Sans SC | 400 | 16/28 |
| 强调 | Noto Sans SC | 500 | 继承 |
| 代码 | JetBrains Mono | 400 | 13/20 |

- 气质：书卷、克制、有品牌记忆；宋体标题在中文知识库里很少见，辨识度高。
- 风险：宋体在小字号下笔画细，不能用于正文；必须保证 600 字重与足够字号。
- 性能：宋体只加载 600 一个字重，且只覆盖标题常用字，子集后 ~1.2MB。

### 3.2 B. 全黑体（最稳）

| 角色 | 字体 | 字重 | 字号/行高 |
| --- | --- | --- | --- |
| 标题 | Noto Sans SC | 600 | 36/48 |
| 正文/UI | Noto Sans SC | 400 | 14/22 |
| 编辑器正文 | Noto Sans SC | 400 | 16/28 |

- 气质：干净、现代、与 FlowUs/Notion 同语言；实现与性能最稳。
- 风险：品牌辨识度弱；容易“像别人”。

### 3.3 C. 文楷正文（最有文学感）

| 角色 | 字体 | 字重 | 字号/行高 |
| --- | --- | --- | --- |
| 标题 | LXGW WenKai | 600 | 36/48 |
| 正文/UI | LXGW WenKai | 400 | 15/26 |
| 编辑器正文 | LXGW WenKai | 400 | 17/30 |

- 气质：手写感、温度、适合随笔/日记。
- 风险：文楷的笔画与字重不适合密集 UI/表格；14px 下清晰度不足；只适合作为**阅读模式**可选字体，不适合全局默认。

### 3.4 对比

| 维度 | A 宋黑 | B 全黑 | C 文楷 |
| --- | --- | --- | --- |
| 品牌辨识 | 高 | 低 | 高 |
| 长文可读 | 高 | 高 | 中 |
| 表格/UI 适配 | 高 | 高 | 低 |
| 性能 | 中（多 1 个字族） | 低 | 中 |
| 实现风险 | 低 | 最低 | 中 |

**推荐 A**；把 C 作为阅读模式的可选字体保留。

## 4. 字体族与回退栈

```css
--gf-font-ui:
  "Noto Sans SC", "Source Han Sans SC", "PingFang SC",
  "Microsoft YaHei", system-ui, -apple-system, "Segoe UI", sans-serif;

--gf-font-display:
  "Noto Serif SC", "Source Han Serif SC", "Songti SC",
  "SimSun", "Noto Sans SC", serif;

--gf-font-reading:
  "Noto Serif SC", "Source Han Serif SC", "Songti SC",
  "SimSun", serif;

--gf-font-mono:
  "JetBrains Mono", "Cascadia Code", "SFMono-Regular",
  Consolas, "Liberation Mono", monospace;
```

规则：
- `--gf-font-display` 只用于 H1/H2/官网大标题；回退到黑体时保持 600。
- `--gf-font-reading` 只在「阅读模式」或用户选择宋体时启用；默认编辑器正文仍用 UI 黑体（16/28）。
- 代码/行内代码用 mono；行内代码字号 `0.9em`，不加粗。
- 不全局启用 `-webkit-font-smoothing: antialiased`（会让中文变细）；仅在 macOS 的深色模式可局部使用。

## 6. 排版规则

- **行长**：中文正文 36~44 字；内容宽 708 / 16px = 44.25em，正好。超过 46 字要加宽边距或分栏。
- **段间距**：编辑器段落之间 8px；列表项之间 4px；标题上 1.5em、下 .5em。
- **对齐**：左对齐，不用两端对齐（中文两端对齐会产生难看的字距）。
- **首行缩进**：不用。网页/知识库用段间距区分段落。
- **标点**：中文全角标点；中英文之间由内容作者加半角空格，不用 CSS 自动加（兼容性不稳）。
- **数字**：表格、统计、时间用 `font-variant-numeric: tabular-nums`；正文可用比例数字。
- **断行**：`overflow-wrap: anywhere` 只用于长 URL/代码；正文 `word-break: normal`；标题 `text-wrap: balance`（支持时）。
- **强调**：加粗 500/600，不用斜体（中文斜体是伪斜体）；强调色只给链接/关键状态。
- **可读性**：正文对比 ≥4.5:1；不用 12px 以下正文；不用全大写中文。

## 7. 授权与打包

| 字体 | 授权 | 可嵌入 | 用途 | 备注 |
| --- | --- | --- | --- | --- |
| Noto Sans SC | SIL OFL 1.1 | ✅ | UI/正文 | 可子集、可商用 |
| Noto Serif SC | SIL OFL 1.1 | ✅ | 标题/阅读 | 可子集、可商用 |
| Source Han Sans/Serif | SIL OFL 1.1 | ✅ | 同 Noto | 与 Noto 同源，二选一避免重复 |
| LXGW WenKai | SIL OFL 1.1 | ✅ | 阅读模式 | 体积较大，按需加载 |
| JetBrains Mono | SIL OFL 1.1 | ✅ | 代码 | 子集 Latin |
| Microsoft YaHei | 微软专有 | ❌ | 系统回退 | 不嵌入安装包 |
| PingFang SC | 苹果专有 | ❌ | 系统回退 | 不嵌入 |
| MiSans | 小米免费商用（需遵守声明） | ⚠️ | 可选 | 存档授权说明，不默认 |
| HarmonyOS Sans | 华为免费商用（需遵守声明） | ⚠️ | 可选 | 存档授权说明，不默认 |

**打包策略**：
- 桌面/Web 内置：Noto Sans SC 400/500/600 + Noto Serif SC 600，woff2 子集（常用 7000 字 + Latin）。
- 阅读模式：LXGW WenKai 400 懒加载，用户切换时再下载。
- 安卓：优先系统 Noto Sans CJK；标题宋体可下载或使用系统 serif；不把 6MB 字体塞进 APK。
- 扩展：不打包字体，使用系统栈；popup 体积优先。
- 官网：只预加载 Hero 用到的宋体 600 子集 + 正文黑体 400；`font-display: swap`。
- 安装包：不嵌入字体，NSIS 用系统字体；品牌字标用 SVG 路径，不依赖字体。

## 8. 性能预算

| 资产 | 目标 | 说明 |
| --- | --- | --- |
| Noto Sans SC 400 | ≤1.6MB woff2 | 子集常用字 |
| Noto Sans SC 500 | ≤1.6MB | 可与 400 合并可变字体 |
| Noto Sans SC 600 | ≤1.6MB | 标题/强调 |
| Noto Serif SC 600 | ≤1.2MB | 仅标题 |
| JetBrains Mono 400 | ≤120KB | Latin 子集 |
| 首屏字体总请求 | ≤3 个 | 避免字体瀑布 |
| FOIT | 0 | `font-display: swap` + 回退栈 |

优先使用**可变字体**（Noto Sans SC Variable）把 400/500/600 合成一个文件；若体积不可控，再拆静态字重。

## 9. 三端与全触点差异

| 触点 | 字体策略 | 差异 |
| --- | --- | --- |
| Windows | 内置 Noto Sans/Serif 子集；标题宋体 | 自绘标题栏文字 12/16 500；窗口控制符号用 SVG 不用字体 |
| Web | 同 Windows；`font-display: swap` | 首次加载可能看到回退黑体，需用 `size-adjust` 减少跳动 |
| 安卓 | 系统 Noto Sans CJK；标题可回退 serif | 不内置大字体；Compose `FontFamily` 映射；字号用 sp |
| 扩展 | 系统栈，不打包 | popup 13/20；按钮 13/20 500 |
| 官网 | 预加载 Hero 宋体 + 正文黑体 | 首屏字体 ≤2 请求；不用 700 |
| 安装包 | 系统字体 + SVG 字标 | NSIS 不支持 woff2；不要依赖宋体 |

## 10. 落地映射

### 10.1 `app/src/design/fonts.ts`

- 保留 `FONT_THEMES` 六套；新增 `DISPLAY_FONT = "noto-serif"` 与 `READING_FONT` 选项。
- `DEFAULT_FONT_THEME` 仍为 `noto`；新增 `DEFAULT_DISPLAY_SERIF = true`。
- `fontStackOf(id)` 增加 `display` 参数，返回 `--gf-font-display` 或 `--gf-font-ui`。

### 10.2 `app/src/styles/index.css`

```css
:root {
  --gf-font-ui: "Noto Sans SC", "Source Han Sans SC", "PingFang SC",
    "Microsoft YaHei", system-ui, sans-serif;
  --gf-font-display: "Noto Serif SC", "Source Han Serif SC", "Songti SC",
    "SimSun", "Noto Sans SC", serif;
  --gf-font-mono: "JetBrains Mono", "Cascadia Code", Consolas, monospace;
  --gf-text-body: 14px; --gf-leading-body: 22px;
  --gf-text-body-lg: 16px; --gf-leading-body-lg: 28px;
}
```

- `body` 从 14px 保持；编辑器容器显式 16/28。
- 页面标题类 `.page-title` 使用 `font-family: var(--gf-font-display); font-weight: 600; font-size: 36px; line-height: 48px;`。
- 旧 `--font-size-body: 16px` 与 `--line-height-body: 26px` 标记废弃，映射到 `--gf-text-body-lg`。

### 10.3 安卓

- `Type.kt` 定义 `GfTypography`：`bodyLarge 16sp/28sp`、`bodyMedium 14sp/22sp`、`headlineLarge 28sp/36sp`、`displaySmall 36sp/48sp`。
- 字体族：`FontFamily(Font(R.font.noto_sans_sc))` 可选；默认 `FontFamily.SansSerif`。
- 标题 serif 用 `FontFamily.Serif`，不内置宋体文件。

## 11. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| `--font-size-body: 16px` / `26px` | `--gf-text-body-lg: 16/28` | 编辑器正文行高略增，长文更松 |
| `body` 14px | 保持 14/22 | UI 密度不变 |
| 页面标题（约 36/48） | 36/48 宋体 600 | 标题气质变化最大，需预览 |
| 侧栏 14/22 | 14/22 | 不变 |
| 无 mono | JetBrains Mono 13/20 | 代码块更清晰 |
| 无 display 字体 | Noto Serif SC 600 | 新增 ~1.2MB 字体资产 |

**验收断言**：
1. 页面标题、H2 使用 `--gf-font-display`；正文不使用宋体。
2. 字重只出现 400/500/600；无 700。
3. 编辑器正文 16/28；UI 正文 14/22；标签 12/18。
4. 行长 36~44 字；708px 内容宽下不超 46 字。
5. 首屏字体请求 ≤3；FOIT 为 0；回退时布局偏移 CLS <0.02。
6. 安装包内不含雅黑/苹方；OFL 字体附带 LICENSE。
7. 表格数字 `tabular-nums` 对齐。

## 13. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 字体是最需要“眼见为实”的维度：宋体标题在 36px 和 40px 下气质完全不同；思源宋体 600 与系统宋体回退的粗细差异，只有并排才能看出；14/22 与 16/28 的行长感受，也必须用真实中文段落比较。预览稿要同时给出 A/B/C 三套、标题/正文/表格/代码/侧栏五类样本，以及“宋体加载失败”的回退态，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「字体体系」分区。
