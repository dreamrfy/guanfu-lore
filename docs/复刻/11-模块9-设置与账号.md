## 1. 入口结构

**桌面**：工作区行 ⌄ → **空间切换菜单**（70 号）→「空间设置」→ **设置弹层**（居中大弹层 ~950×660，左侧竖导航 + 右侧内容 + 右上 ×）。
- 空间切换菜单（70 号证据）：头部分组名「两相欢」+ 当前空间卡（头像 40 + 空间名/「免费版」+ ✓ 选中 + 左缘拖拽点阵）+ **＋ 创建新空间 / ↑ 升级空间（链接蓝）/ ⚙ 空间设置 / ⟵ 退出登录**
- ⚠️ 「空间设置」与「退出登录」相邻（41px 间距）——自动化必须 DOM 定位+文本核对（坑 #12 的由来）

**手机**：底栏第 5 项 ⋯（`btnPreferences`，72dp 槽位，带红点角标）→ **设置全屏 bottom sheet**（顶栏 取消/设置）。

### 2.1 账号设置（74 号）
头像（上传头像）/ 昵称（输入框）/ 邮箱（换绑邮箱钮）/ 手机号（1998528716 + 修改手机号钮）/ 学生教师认证（立即认证，解锁福利）/ 登录密码（修改密码钮）/ 设备管理（查看登录设备，管理钮）/ 保存 + 取消。
→ **观复槽位**：头像/昵称保留；邮箱/手机/认证/设备管理按需简化（观复自建账号体系）。

### 2.2 通用设置（75 号）
- 通用：**主题**（跟随系统 ⌄）/ **语言**（简体中文 ⌄）/ **FlowUs AI · AI 模型**（Auto ⌄）
- 通知偏好 5 个 toggle（全开）：**协作通知 / 分享通知 / 自动化通知 / 订阅通知 / 收件箱通知**（每个带一句说明文案）
- 设置剪藏保存位置：选择空间（两相欢的空间 ⌄）
- （下方可滚动，未逐项截完）
→ **观复槽位**：主题/语言保留；**「AI 模型」原位替换为「AI 供应商设置」**（观复独有）；通知偏好按观复能力裁剪；剪藏保存位置 → 收集箱设置。

### 2.3 空间设置（71 号）
空间头像（40 圆角 + 上传空间头像钮）/ 空间名（输入框）/ 空间域名（"你的分享链接专属地址…格式 flowus.cn/"，输入英文域名）/ 公开主页（🔒 请先设置空间域名 + `免费版` 徽章）/ 日期设置（每周起始日 周一 ⌄，"仅影响日历显示方式"）/ 分享页通知提醒（toggle 开）/ 保存 + 取消。

### 2.4 公开分享（76 号）
「页面头部」标题 + 「所有已分享页面」列表（空）+ 右上「仅限本人」checkbox。用户无已分享页面 → 列表空态。

## 4. 三端差异

| # | 项 | 桌面 | 手机 |
| --- | --- | --- | --- |
| 1 | 入口 | 工作区 ⌄ → 空间设置 | 底栏第 5 项（带红点角标） |
