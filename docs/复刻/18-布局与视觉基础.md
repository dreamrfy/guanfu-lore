## 1. 结论摘要

1. **4px 基础网格**：间距只取 2/4/6/8/12/16/20/24/32/40/48/64/80/96；6 只用于图标与文字间距，2 只用于发丝线。
2. **桌面外壳沿用实测值**：侧栏 228、页签栏 38、页面顶条 48、内容宽 708、右栏 320、工具条 44。
3. **断点 600/900/1024/1200/1440**：<900 侧栏变抽屉；900~1023 侧栏变 64 图标轨；≥1200 右栏可常驻。
4. **圆角五档**：4 标签、6 按钮/输入、8 卡片/菜单、12 弹窗、16 大卡片；不做 2px 微圆角，也不做全圆角卡片。
5. **阴影三级 + 边框**：浅色用阴影表达浮层，深色用边框；不允许“阴影 + 粗边框 + 大圆角”三重叠加。
6. **z-index 六层**：0/10/100/200/300/400/500；禁止组件里写 9999。
7. **密度两档**：舒适（默认，表格行 40）与紧凑（行 32）；手机行高 40、触摸 44。
8. **内容优先**：文档正文 708 定宽居中；多维表全宽；设置页 720 定宽；官网 1120 十二列。

## 3. 间距

### 3.1 阶梯

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `--gf-space-0-5` | 2 | 发丝线、图标内偏移 |
| `--gf-space-1` | 4 | 标签内边距、图标与文字微调 |
| `--gf-space-1-5` | 6 | 图标与文字、按钮内左右 |
| `--gf-space-2` | 8 | 行内间距、紧凑卡片 |
| `--gf-space-3` | 12 | 表单字段、卡片内 |
| `--gf-space-4` | 16 | 卡片内边距、列表分组 |
| `--gf-space-5` | 20 | 页面块间距 |
| `--gf-space-6` | 24 | 区块间距、设置分组 |
| `--gf-space-8` | 32 | 大区块、页面上下 |
| `--gf-space-10` | 40 | 空态、官网段落 |
| `--gf-space-12` | 48 | 页面左右（桌面） |
| `--gf-space-16` | 64 | 官网大段 |
| `--gf-space-20` | 80 | 首屏 |
| `--gf-space-24` | 96 | 官网分区 |

### 3.2 组合规则

- **卡片**：内边距 16；紧凑 12；大卡 24。卡片间距 12（列表）/16（网格）。
- **表单**：标签与控件 6；控件之间 12；字段组之间 24；错误文案距控件 4。
- **列表**：行内左右 8；行与行 0（用分隔线或 hover）；分组标题上 16、下 4。
- **页面**：标题下 16；正文段落 8；区块之间 32；页面底部 64。
- **按钮组**：间距 8；主次按钮并排时主在右（中文阅读习惯）或左（表单提交）——表单统一右。
- **图标与文字**：16 图标 6；20 图标 8；不要用空格字符对齐。

## 4. 布局外壳

### 4.1 桌面（≥1024）

```
┌──────────────────────────────────────────────┐
│ 页签栏 38（窗口控制 46×38 在右）              │
├──────────┬───────────────────────────────────┤
│ 侧栏 228 │ 页面顶条 48                        │
│          ├───────────────────────────────────┤
│          │ 内容区（文档 708 居中 / 表格全宽） │
│          │                         右栏 320 │
└──────────┴───────────────────────────────────┘
```

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| 页签栏 | 高 38 | 左控制区 228；页签 180×38；新建 28×28；窗口控制 46×38 |
| 侧栏 | 宽 228 | 可折叠到 0；折叠按钮在顶条 |
| 页面顶条 | 高 48 | 面包屑/标题 + 动作；底边 1px |
| 工具条 | 高 44 | 编辑器/视图工具；可 sticky |
| 内容区 | max 708（文档） | 左右 padding 48；表格全宽 padding 48 |
| 右栏 | 宽 320 | 属性/评论/AI；≥1200 常驻，否则浮层 |

### 4.2 平板（900~1023）

- 侧栏变成 **64px 图标轨**：只显示图标，hover/点击展开浮层 228。
- 内容 padding 32；右栏改为浮层 320。
- 页签栏保留；页面顶条 48。

### 4.3 手机（<900）

- 侧栏变抽屉 **280**（FlowUs 实测 264.7，观复取 280 更从容）；遮罩 `--gf-overlay`。
- 顶部 48：☰ + 标题 + 分享/更多。
- 底部固定栏 **64**（FlowUs 72dp；观复 64 更轻）：主页/搜索/新建/AI/我的，图标 24 + 文字 11。
- 内容 padding 16；文档正文 16/28；表格横向滚动，首列 sticky。
- 右栏/设置子页用底部动作面板，最大高 80vh，圆角 16 顶部。
- 键盘弹出时底部栏隐藏，工具条贴键盘。

### 4.4 扩展

- popup 固定 **320×480**（现有 300 宽，改为 320 更从容）；内边距 16。
- 注入按钮 32×32，距右下 20；展开面板 360×520。
- 选项页 640 定宽，居中。

### 4.5 官网

- 容器 max 1120；12 列，gutter 24；左右 margin 48/24/16。
- 首屏高 `min(720px, 100vh)`；内容垂直居中偏上。
- 功能区三列（≥1024）/两列（768）/单列（<768）。

## 5. 断点

| 名称 | 宽度 | 行为 |
| --- | --- | --- |
| xs | 0~599 | 手机；单列；底部栏；抽屉 |
| sm | 600~899 | 大手机/小平板；单列或两列；底部栏 |
| md | 900~1023 | 平板；侧栏图标轨 64；内容 padding 32 |
| lg | 1024~1199 | 桌面；侧栏 228；右栏浮层 |
| xl | 1200~1439 | 桌面宽；右栏可常驻 |
| 2xl | ≥1440 | 宽屏；内容仍 708 居中，两侧留白 |

规则：
- 断点用 `min-width`，移动优先；不针对具体设备。
- 容器查询用于卡片/表格组件（`@container`），避免组件依赖视口。
- 打印：隐藏侧栏/顶条/底栏，内容宽 100%，黑白友好（见 21）。

## 6. 圆角、描边、阴影

### 6.1 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--gf-radius-xs` | 4 | 标签、徽标、代码行内 |
| `--gf-radius-sm` | 6 | 按钮、输入、菜单项、侧栏行 |
| `--gf-radius-md` | 8 | 卡片、菜单容器、图片 |
| `--gf-radius-lg` | 12 | 弹窗、抽屉顶部 |
| `--gf-radius-xl` | 16 | 大卡片、移动端底部面板 |
| `--gf-radius-full` | 999 | 胶囊、头像、开关 |

规则：同层容器圆角一致；子元素圆角 ≤ 父容器；不要给表格单元格加圆角。

### 6.2 描边

- 默认 1px；高 DPI 用 `0.5px` 时以 `1px` 为准，避免消失。
- 颜色：`--gf-border`；输入框/浮层用 `--gf-border-strong`。
- 分隔线：列表用 1px `--gf-border`；表格用 1px，横线优先，竖线可省。
- 焦点：2px `--gf-primary` + 2px offset；不用 `outline: none`。
- 选中：2px `--gf-primary` 或 1px + 浅底；不要同时用三种指示。

### 6.3 阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--gf-shadow-xs` | `0 1px 2px rgba(20,19,17,.06)` | 卡片、输入聚焦 |
| `--gf-shadow-sm` | `0 2px 6px rgba(20,19,17,.08)` | 下拉、popover |
| `--gf-shadow-md` | `0 8px 24px rgba(20,19,17,.12)` | 模态、右栏浮层 |
| `--gf-shadow-lg` | `0 20px 48px rgba(20,19,17,.18)` | 大模态、命令面板 |

深色：阴影透明度减半，浮层加 1px `--gf-border-strong`；不要用纯黑大阴影。

## 7. 层级（z-index）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--gf-z-base` | 0 | 内容 |
| `--gf-z-sticky` | 10 | sticky 表头、工具条 |
| `--gf-z-dropdown` | 100 | 下拉、菜单 |
| `--gf-z-popover` | 200 | popover、tooltip 容器 |
| `--gf-z-modal` | 300 | 模态、抽屉 |
| `--gf-z-toast` | 400 | toast、通知 |
| `--gf-z-tooltip` | 500 | tooltip 最上层 |

规则：只用这六层；组件内不写 `z-index: 9999`；嵌套浮层用父级 +1 的局部堆叠上下文。

## 8. 密度

| 模式 | 行高 | 字号 | 内边距 | 用途 |
| --- | --- | --- | --- | --- |
| 舒适（默认） | 40（表格/列表） | 14/22 | 12/16 | 大多数场景 |
| 紧凑 | 32 | 13/20 | 8/12 | 多维表、长列表 |
| 手机 | 40 | 14/22 | 12/16 | 触摸 |
| 大屏 | 44 | 14/22 | 16/20 | 展示/演示 |

切换放在「设置 → 外观 → 密度」，默认舒适；表格视图可单独切紧凑。

## 9. 滚动条

- 宽 8px；轨道透明；滑块 `rgba(43,42,39,.18)`，hover `.28`。
- 深色滑块 `rgba(255,255,255,.18)`，hover `.28`。
- macOS 用系统 overlay；Windows 用自定义细滚动条。
- 横向滚动容器加 `overscroll-behavior-x: contain`，避免带动页面。

## 10. 对齐与光学

- 图标在按钮内用 flex 居中，不靠 padding 硬凑。
- 文本基线：同一行不同字号用 `align-items: baseline`。
- 数字列右对齐 + `tabular-nums`；文本列左对齐。
- 复选框与第一行文字基线对齐，不与整块垂直居中。
- 20px 图标在 32px 按钮内视觉居中；16px 图标在 28px 按钮内略偏上 0.5px（光学修正）。
- 侧栏 emoji 18px，与 14px 文字基线对齐；不用 20px emoji（过大）。

## 11. 三端与全触点差异

| 触点 | 差异 | 处理 |
| --- | --- | --- |
| Windows | 自绘标题栏、窗口控制 46×38、无系统圆角 | 标题栏高 38；最大化时留 8px 拖拽边 |
| Web | 浏览器滚动条、地址栏 | 100dvh；`env(safe-area-inset-*)` |
| 安卓 | 状态栏/导航栏、键盘 inset | `WindowInsets`；底部栏随键盘隐藏；触摸 44 |
| 扩展 | 页面注入、popup 小窗 | 固定 320；Shadow DOM；不继承宿主字体 |
| 官网 | 12 列、首屏满高 | 1120 容器；图片 `aspect-ratio`；无横向滚动 |
| 安装包 | NSIS 固定像素 | 164×314 侧栏图；150×57 头图；不缩放 |

## 12. 落地映射

```css
:root {
  --gf-space-1: 4px;  --gf-space-2: 8px;  --gf-space-3: 12px;
  --gf-space-4: 16px; --gf-space-6: 24px; --gf-space-8: 32px;
  --gf-space-12: 48px; --gf-space-16: 64px;
  --gf-radius-sm: 6px; --gf-radius-md: 8px; --gf-radius-lg: 12px;
  --gf-shadow-sm: 0 2px 6px rgba(20,19,17,.08);
  --gf-z-modal: 300; --gf-z-toast: 400;
  --gf-sidebar-width: 228px; --gf-content-width: 708px;
}
```

- 布局用 CSS Grid：`grid-template-columns: var(--gf-sidebar-width) minmax(0,1fr)`；不要用 float。
- 内容区 `max-width: var(--gf-content-width); margin-inline: auto; padding-inline: var(--gf-space-12);`。
- 断点用 `@media (min-width: 900px)` 等；组件用 `@container`。
- 安卓用 `Scaffold` + `NavigationRail`（64dp）/`ModalNavigationDrawer`（280dp）；`WindowSizeClass` 映射断点。

## 13. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| 侧栏 228 | 228 | 不变 |
| 内容 708 | 708 | 不变 |
| 顶条 44/48 混用 | 48 | 统一 |
| 圆角 6/8 混用 | 4/6/8/12 | 统一阶梯 |
| 阴影随意 | 三级 | 浮层更克制 |
| z-index 9999 | 六层 | 减少遮挡 bug |

**验收断言**：
1. 所有 margin/padding 是 4 的倍数（6/2 例外仅用于图标/发丝线）。
2. 1200 宽下侧栏 228、内容 708、右栏 320 可同时成立。
3. 375 宽无横向滚动；表格可横滚且首列 sticky。
4. <900 侧栏为抽屉；900~1023 为 64 图标轨。
5. 圆角只出现 4/6/8/12/16/999。
6. z-index 只出现六层值。
7. 触摸目标 ≥44×44（安卓/移动 Web）。

## 15. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 布局的数值容易写对，但“松紧”只有看真实界面才知道：228 侧栏配 708 内容，在 1200 窗口里是否偏挤；48 顶条配 38 页签栏，是否头重脚轻；手机 64 底栏是否够点。预览稿要能切换 1200/768/375 三档、舒适/紧凑两档、侧栏展开/折叠，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「布局与视觉基础」分区。
