前端设计规范 · 总纲

推荐 A

一套“安静的知识库”视觉：内容优先、chrome 退后、纸墨质感、克制动效。所有 token 分三层：Primitive 原始值 → Semantic 语义 → Component 组件；组件只读语义层，页面不写裸 hex。

内容优先

侧栏 228、顶栏 48、正文 708；装饰不抢正文。页面里唯一的大字号是标题。

安静

低饱和中性色 + 一个主色 + 一个朱砂强调；不做渐变按钮、发光、玻璃拟态。

可读

正文 16/28，行长 ≤44em；中文用黑体，标题用宋体；对比度正文 ≥4.5:1。

一致

4px 网格、6/8/12 圆角、三档阴影；同一动作在三端同一文案。

可逆

删除进回收站；同步冲突不静默覆盖；AI 操作可撤销。

可访问

键盘可达、焦点可见、减少动效、200% 缩放不破版、触摸 44。

推荐 A

中性色负责 90% 的界面，主色只给“当前/主操作”，朱砂只给 AI 与需要人注意的点。正文不用纯黑，浅色底不用纯白大面积；深色不用纯黑，靠三层表面和描边分层。

字体体系

推荐 A

界面用黑体保证小字号清晰，标题用宋体建立“编目/典籍”的气质，阅读模式可选文楷。只用 400/500/600 三档；中文不做负字距，大标题最多 -0.02em。

动效与交互状态

克制

动效只做三件事：说明“从哪来”、确认“发生了什么”、提示“正在发生”。只动 transform / opacity / color，不动 width/height/top/left；同时最多两处；焦点环不做过渡。
