# 15 颜色体系（观复 · Lore）

- 状态：**推荐稿 v1.0**（2026-11-18）
- 上游：[14-前端设计规范-总纲.md](14-前端设计规范-总纲.md) §4.1/§4.2
- 适用：Web / Windows / 安卓 / 扩展 / 官网 / 安装包
- 证据：`ops/观测/专项/flowus-styles.json`（FlowUs 浅色实测）、`ops/观测/windows/17-单元格编辑器-标签选择.png`（标签色板目测）、`app/src/styles/index.css:6-40`（观复原生 token）

## 1. 结论摘要

1. **推荐「墨蓝 · 宣纸」**：主色 `#2F5D8A`，强调 `#B4472E`，暖纸底 `#F7F6F2`，墨字 `#2B2A27`。
2. **中性色是暖灰，不是冷灰**：色相偏 40°（纸黄），避免 FlowUs/Notion 的冷白“办公软件感”。
3. **品牌色只做三件事**：主操作、当前选中、链接。其余大面积用中性色；强调色只给 AI/洞察/重要提醒。
4. **语义色双轨**：`-soft` 浅底 + 深字（正文可用 ≥4.5:1），`base` 用于图标/描边/填充；警告与橙标签的正文色需比 base 更深。
5. **标签 9 色**：灰/蓝/青/绿/琥珀/橙/红/粉/紫；浅色 10% 底 + 30% 边 + 深字，深色 18% 底 + 35% 边 + 亮字。
6. **深色不是反色**：底 `#171716`，面 `#20201E`，浮层 `#262624`；用边框替代阴影，图片不反色。
7. **对比度全部达标**：正文/辅助/主色/语义色 ≥4.5:1；大字号与图标 ≥3:1；三级文字只用于非必要信息。
8. **禁止组件直接写十六进制**：一律引用 `--gf-*`；旧 `--primary #2383e2` 迁移到 `#2F5D8A`。

使用规则：
- 标签是**分类**，不是状态；状态用语义色 + 图标/文字，不只靠颜色。

## 5. 候选方案

### 5.1 A. 墨蓝 · 宣纸（推荐）

- 主色 `#2F5D8A`，强调 `#B4472E`，底 `#F7F6F2`，面 `#FFFFFF`，字 `#2B2A27`。
- 气质：纸墨、学者、安静、耐看。
- 适合：长文阅读、知识管理、中文内容。
- 代价：首屏不如亮蓝“有活力”；需要靠留白和排版撑质感。

### 5.2 B. 青瓷 · 雾灰

- 主色 `#2C6E6A`，强调 `#C08A2E`，底 `#F4F6F5`，面 `#FFFFFF`，字 `#232826`。
- 气质：清冷、现代、东方；比 A 更“设计感”。
- 风险：青色与 success 太近，数据表状态易混；暖度不足，长文略冷。

### 5.3 C. 玄墨 · 极简

- 主色 `#1F6FEB`，强调 `#7C3AED`，底 `#FFFFFF`，面 `#FFFFFF`，字 `#1F1F1F`。
- 气质：工具、效率、接近 Notion/Linear。
- 风险：辨识度低；纯白底久看不如 A 舒适；紫色强调偏“AI 产品模板感”。

### 5.4 三套对比

| 维度 | A 墨蓝 | B 青瓷 | C 玄墨 |
| --- | --- | --- | --- |
| 辨识度 | 高 | 中高 | 低 |
| 长文舒适 | 高 | 中 | 中 |
| 与 FlowUs 差异 | 大 | 大 | 小 |
| 数据可视化兼容 | 高 | 中（青/绿冲突） | 高 |
| 品牌叙事 | 强（观复/纸墨） | 中（青瓷） | 弱（通用工具） |
| 实现成本 | 低 | 低 | 低 |

**推荐 A**。

## 9. 三端与全触点差异

| 触点 | 差异 | 处理 |
| --- | --- | --- |
| Windows | 自绘标题栏、窗口控制；无系统 Mica | 标题栏用 `--gf-bg-app`，底边 1px `--gf-border`；不用透明模糊 |
| Web | 浏览器 chrome、可能白底闪 | `html` 背景先设为 `--gf-bg-app`；主题脚本内联防闪 |
| 安卓 | Material 3 动态色可能污染 | 关闭 dynamicColor；状态栏/导航栏跟随主题；`WindowInsets` 用同底色 |
| 扩展 | 注入页面背景不可控 | popup 用固定 token；注入按钮加 1px 白/黑描边 + 阴影，保证任何背景可见 |
| 官网 | 需要更强对比与营销感 | 首屏可用深墨底 + 白字；正文仍用暖纸；CTA 用主色 |
| 安装包 | NSIS 不支持透明度/圆角 | 用实色 `#F7F6F2` / `#2F5D8A`；位图 24 位；不依赖字体 |

### 10.2 Tailwind 4

在 `@theme` 中登记 `--color-gf-*`，组件只用 `bg-gf-surface`、`text-gf-secondary` 这类语义类；禁止 `bg-[#2F5D8A]` 直接写值。

### 10.3 安卓 Compose

`GfColors.kt` 定义 `lightColorScheme` / `darkColorScheme`；`primary = Color(0xFF2F5D8A)`，`background = Color(0xFFF7F6F2)`，`surface = Color(0xFFFFFFFF)`；关闭 `dynamicColor`。

### 10.4 扩展/官网

扩展 `popup.html` 的 `:root` 复制同一组变量；官网用 `--gf-*` 并增加 `data-theme="dark"`。官网现有 `--accent #4f46e5` 全部替换为 `#2F5D8A`。

## 11. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| `--primary #2383e2` | `#2F5D8A` | 主按钮、链接、选中态整体变墨蓝 |
| `--text-secondary #91918e` | `#6B6A64` | 辅助文字变深，对比从 3.1 提升到 5.0 |
| `--bg #ffffff` | 内容面仍白；应用底 `#F7F6F2` | 侧栏与内容区出现暖色层次 |
| `--bg-secondary #f7f7f5` | `#FBFAF7` | 侧栏更暖 |
| 官网 `#4f46e5` | `#2F5D8A` | 官网与 app 统一 |
| 扩展 `#2383e2` | `#2F5D8A` | 扩展与 app 统一 |

**验收断言**：
1. 所有文本/背景组合对比度 ≥4.5:1（大字号/图标 ≥3:1），脚本遍历 `--gf-*` 组合。
2. 组件源码中不出现 `#` 开头的颜色字面量（除 token 文件与封面渐变）。
3. 深色模式下图片、视频、封面不反色；代码块底 `#121211`。
4. 标签文字在浅/深色下均 ≥4.5:1；状态不能只靠颜色区分。
5. 主题切换无白闪；`prefers-color-scheme` 生效。

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 颜色是最容易“数值正确、观感不对”的维度：同一个 `#2F5D8A` 放在暖纸底、冷白底、深色底上，饱和度和重量感完全不同；标签色在真实表格里并排出现时，也要看是否互相打架。预览稿要同时展示 A/B/C 三套、浅/深两态、正文/表格/标签/按钮/代码块五类场景，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「颜色体系」分区。
