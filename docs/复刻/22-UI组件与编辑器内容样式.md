## 1. 结论摘要

1. **组件不追求多，追求一套用到底**：24 个基础组件 + 8 个编辑器专用组件，覆盖 90% 界面。
2. **按钮/输入默认高 32**，小 28，大 36；圆角 6；图标按钮 28/32/36；触摸端 44。
3. **编辑器正文 16/28，页面标题 36/48 宋体**；标题层级 28/22/18/16；中文行长 708px ≈ 44 字。
4. **块间距 4px，标题上留白 24/16/12**；块手柄 20×20，悬停出现；`/` 菜单宽 280。
5. **表格/多维表行高 36（紧凑）/40（默认）**；表头 13/20 secondary；单元格 14/22。
6. **所有组件必须有 default/hover/active/focus/disabled/loading/error 状态**；不能只有默认态。
7. **编辑器样式用覆盖层实现**：不改 BlockNote 源码，用 `.bn-*` 变量 + 自定义块组件。
8. **组件 API 以语义命名**：`variant="primary|secondary|ghost|danger"`、`size="sm|md|lg"`，不传颜色。

### 4.4 特殊块

- **Callout**：4 色（灰/黄/红/蓝），左 4px 色条 + 浅底 + emoji 20；圆角 6；内容 16/28。
- **代码块**：顶部工具行 32（语言选择、自动换行、复制）；行号 12 mono tertiary；背景 `--gf-bg-sunken`；深色独立主题。
- **书签**：卡片高 96；左图 96×96 或图标；标题 14/22 500；URL 12/18 secondary。
- **多维表内嵌**：标题行 36；视图页签 36；表格行 36；底部“新建记录”。
- **封面**：高 200；渐变 6 套；图片 `object-fit: cover`；右上三按钮（更换/移除/ reposition）悬停出现。
- **页图标**：60px；emoji 或 Lucide 32；点击打开选择器。
- **引用区**：底部 1px 分隔；折叠标题 13/20 secondary；“引用了本页 N”。

## 5. 组件候选

| 方案 | 特征 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 纸墨编辑（推荐）** | 宋体标题 + 黑体正文；16/28；36/48 页标题 | 有辨识度、长文舒适 | 宋体在小字号不适合 UI |
| B. 全黑体（FlowUs 忠实） | 全 Noto Sans；16/24；40/64 页标题 | 熟悉、实现简单 | 与 FlowUs 太像，缺品牌 |
| C. 紧凑工具 | 15/24；32/40；行高 32 | 一屏信息多 | 长文累，中文显挤 |

**推荐 A**；UI 控件仍用黑体，只有页面标题与编辑器 H1~H4 用宋体，形成“内容/工具”分层。

## 7. 落地映射

- 组件目录建议：`app/src/ui/`（Button/Input/Menu/Dialog/Toast…），`app/src/editor/blocks/` 保留现有。
- CSS：BEM 类 + `--gf-*` token；禁止组件内写死颜色/圆角。
- BlockNote：用 `theme` 变量覆盖字体/颜色；自定义块用现有 `callout.tsx`、`bookmark.tsx`、`collectionBlock.tsx` 扩展。
- 表格：现有 `.grid` 类改名/扩展，保持行为；新增 `data-density`。
- 安卓：Compose `GfButton`、`GfTextField`、`GfMenu`；尺寸用 dp，字体 sp。
- 扩展：复用 `button`/`input` 基础样式，popup 宽度 320。

## 8. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| 页标题 40/64 | 36/48 宋体 | 更雅、更省空间 |
| 正文 16/26 | 16/28 | 长文更松 |
| H1 块 40 | 28 | 层级更合理 |
| 圆角 4/6 混用 | 4/6/8/12 | 统一 |
| 组件状态不全 | 全状态 | 需补 CSS |

**验收断言**：
1. 所有按钮有 6 态；禁用态可识别。
2. 输入框 focus 环 2px；错误态有图标+文案。
3. 页标题 36/48；正文 16/28；H1 28/36（DOM 断言）。
4. 表格行高 36/40 可切；列宽可拖。
5. 块手柄 20×20，悬停出现；`/` 菜单 280 宽。
6. 图片圆角 8；代码块 13 mono；Callout 4 色。
7. 组件无硬编码颜色（CSS 扫描）。
8. 安卓触摸目标 ≥44dp；1.3 倍字体不截断。

## 10. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 组件规格表只能告诉你“高 32、圆角 6”，但按钮里的 14px 字是偏紧还是偏松、表格 36 行高在 1200 宽里是否拥挤、宋体标题和黑体正文放在一起是否协调，必须把真实中文排出来看。预览稿要把 24 个基础组件、8 个编辑器块、A/B/C 三套排版并排展示，并支持深浅色，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「UI 组件与编辑器」分区。
