## 四、【暂定】与未覆盖

1. **Ctrl+Shift+V**：Chrome/WebView2 会把它当“粘贴为纯文本”，真实按键到不了页面；实现保留该键（Tauri/部分环境可用），桌面浏览器实际用 **Ctrl+Alt+V**。【暂定】后续在 Tauri 真机再核一次。
2. **安卓分享 Sheet**：属 A13，暂停等 UI 重做；本轮只做 Web/桌面。
3. **微信服务号转发**：服务端剪藏箱承接（W121 弹层里「服务器剪藏箱」可导入）；服务号资质/配置由用户自带，不在本轮 UI 范围。
4. **收集箱页打开时不占页签**：`openCollection` 会把 `activeTabId` 置空，表格不是页签；顶栏保留上一个页签但不误导为主区内容。若后续要做“表格页签”另开任务。
5. **失败后的离线队列**：当前失败保留输入框里的链接并给 [重试]，没有做“联网后自动抓取”的持久队列；27 号 §3.1 的离线队列留给安卓/后续批次。

## 五、走查中修掉的真问题

1. **W94 主页挡住表格**：`activeTabId === HOME_TAB` 时即使 `activeCollectionId` 已设置，主区仍渲染 AI 首页 → 收集箱/表格打不开。改为 `activeTabId === HOME_TAB && !activeCollectionId`（W120）。
2. **从表格点回当前页签无效**：`openTab` 在 `activeTabId === id` 时提前 return，表格态清不掉。已修（W120）。
3. **离线快照中文乱码**：blob HTML 没有 `<meta charset="utf-8">`，浏览器按 GBK 解析。`ensureUtf8Meta` 统一补声明（W123）。
4. **记录详情下拉/日历全部展开**：`CellEditor` 在记录详情里把 select/date 编辑器直接铺开，属性区占满面板。增加 `mode="panel"`，默认收起、点一下再展开（W123）。
