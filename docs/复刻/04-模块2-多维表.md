## 1. 视图体系

### 1.1 六种视图的渲染（均已实测）

| 视图 | 形态要点 |
| --- | --- |
| **表格** | 桌面：表头 **37px 吸顶**、数据行 **38px**、列宽固定 px、横向滚动；手机：**卡片式行**（`No.` + 标题 + 标签 chips + 行尾 `‣‣‣`）+ 列尾「统计」 |
| **看板** | 按某字段分组列（列头：组名 + 计数 + 「‣」），卡片=页面标题，每列底部「创建记录」 |
| **画廊** | 卡片网格（卡片显示页面标题） |
| **目录**（列表） | 纯标题列表 + 「创建记录」，无表头/列/卡片装饰 |
| **时间轴** | 顶部「2026年11月」+「月 ⌄」单位 +「‹ 今天 ›」+ 日期刻度（含"今天"红线）；左侧记录列表面板（带 `≪` 折叠） |
| **日历** | 顶部「2026年11月」+「今天」+ 星期表头（一~日）+ 日期格 |

其它：**空表**主体只有「创建记录」+ 每列列尾「统计」，**空态文案**为「无记录，点击创建新记录，或调整视图筛选设置」。

### 1.2 视图管理

- **手机**：点「当前视图名 ▾」→ **管理视图**面板：分段 `本页视图 | 全部视图`；视图行（高 50dp）右侧有独立按钮 → **视图编辑面板**
- **桌面**：页内**标签栏** `表格|时间轴|…|＋`（当前项下划线），超出显示「**3 更多…**」；点标签右侧按钮 → 视图编辑浮层
- **视图编辑面板/浮层**：视图类型（可就地切换，**切换后视图名会跟着类型变**）+ **拷贝视图** + **删除视图**
- **删除视图**：点「删除视图」→ 弹窗「**是否确认删除该视图？**」+ 确定（红字红边）/ 取消
  ⚠️ 手机上这个删除控件**自动化点不动**（点中心/右侧/先收键盘都无效，也无长按/左滑菜单）——推测是特殊手势控件

### 1.3 视图设置

**桌面浮层**（400×482）页签：`视图 | 属性 | 筛选 | 排序 | 分组 | 子记录`
「视图」页签 11 项：**视图名称**（输入框）/ 视图类型（下拉）/ 自适应行高（开关）/ 显示序号（开关）/ 每页大小（50条）/ 加载方式（滑动加载）/ 打开记录方式（整页打开）/ 显示页面图标（开关）/ 复制引用视图链接 / 拷贝视图 / 删除视图

**手机底部面板** 8 项（项高 50dp）：属性 / 分组 / 每页大小 / 筛选 / 排序 / 子记录 / 自适应行高（开关）/ 显示序号（开关）

**每页大小**选项：**10 / 20 / 30 / 50 / 100 / 不限**

## 2. 字段（属性）体系

**类型全量（16 种）**
- 基本（11）：文本 · 数字 · 勾选框 · 单选 · 多选 · 日期 · **人员** · 文件媒体 · 网址链接 · 邮箱 · 电话
- 高级（6 可见）：**公式 · 关联 · 汇总** · 创建时间 · 创建人 （列表还可向下）

**新建字段**：视图设置 → 属性 → 创建新属性 → 编辑属性（字段名 / **属性类型** / 显示 / 删除）
**删除字段**：属性面板点字段 → 编辑属性 → 删除 → 弹窗「**删除属性 / 确认删除 / 取消**」✅ 实测成功
**编辑属性面板**（已有字段）还带 **升序 / 降序**（把"按此字段排序"的快捷入口放进字段编辑器）

**记录页的「属性行菜单」**（点属性**名字**，桌面）：更换类型 / **日期格式**（日期专有）/ 设置属性 / 显示 / 拷贝副本 / 删除

## 3. 单元格编辑器（按字段类型）

| 类型 | 交互 | 实测 |
| --- | --- | --- |
| 文本 | **双击**就地编辑 | 格内变可编辑区，**行高 37→60px** |
| 单选/多选 | **单击**单元格/chip → 下拉面板 | 面板 320×292：已选 chips + 「**选择或创建一个选项**」+ 选项列表 |
| 日期 | 点**值区域** → 月历 | 面板 282×291：`2026年11月` + 星期表头 一~日 + 日期网格 |
| 图标/Emoji | 点**带图标的单元格** | 页签 `Emoji / Icons / 上传 / 链接` + `随机选择 / 清除` + 搜索 + 8 个分类 |
| 系统字段（创建时间/创建人） | 单击**无反应**（不可编辑） | — |
| 人员 | **未直接取样**（见 §9） | 由 `@` 菜单的成员列表代替取证 |

**桌面单元格语义**：单击 = **选中**（蓝框）；双击 = 编辑。列尾还有 **48px 宽**的「＋ 新建列」。

## 4. 筛选 / 排序 / 分组

| 面板 | 实测内容 |
| --- | --- |
| **筛选** | 标题「筛选属性」；顶部「**筛选符合下方：全部 / 条件 / 已失效**」；两个入口 **创建筛选条件** / **创建筛选条件组**（支持条件树） |
| **排序** | 标题「排序」+ 右侧状态「**已生效**」；每条排序占 **3 行**（字段 / 方向「选项正序」/ 删除） |
| **分组** | 分组条件（可多条，如「状态」）+ 隐藏无记录分组；看板视图下还有 **分组颜色** 与 **可见分组 / 全部隐藏** |

> 「**已失效**」页签说明：条件会引用已删除的字段 → 观复存条件时必须存**字段 id**，不能存字段名。

## 5. 列头菜单（桌面：右键列头）

**全量 11 项**（行高 32px，面板宽 238；选择型列为例）：
`更换类型 ▸` / `管理选项` / `在左侧插入` / `在右侧插入` / `升序` / `降序` / `筛选` / `隐藏` / `冻结列` / `拷贝副本` / `删除`

- **按类型变化**：文本列多出 **重命名输入框** 与 **显示页面图标（开关）**；选择列多出 **更换类型 / 多选开关 / 管理选项**
- **「更换类型」是二级菜单**（▸，行尾显示当前类型，例「文本 ▸」）
- 手机端**没有列头菜单**（见 02 号文档第 8 条）

## 6. 记录页

- 桌面：点「创建」**直接新建一条记录**并打开记录页（**不是菜单**）；面包屑 `学习进度 / 无标题`；
  属性区（字段名 + 值，未填显示 **未填写 / 未关联**）+「**＋ 添加属性**」；底部「按回车开始编辑，或模板」
- 手机：表格里点行 → 展开/进入记录；记录页同样按"字段名 + 值"排列
