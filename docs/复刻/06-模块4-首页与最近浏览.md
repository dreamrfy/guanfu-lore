# 06 模块 4 · 首页与最近浏览（终稿）

- 状态：**已收口**（2026-11-17 观测；桌面 + 手机实测，网页端由桌面 webview DOM 覆盖）
- 基准与约束见 [01-基准与约束.md](01-基准与约束.md)；三端差异见 [02-三端形态差异总表.md](02-三端形态差异总表.md)
- 证据（本地，不进仓库）：`ops/观测/windows/33~35-*`、`ops/观测/android/70~76-*`
- 单位：安卓 1dp = 3px（1080×2400@480dpi）；桌面 CSS px（webview 1200×762、dpr=1，整窗含 38px 页签栏）
- **本轮关键定性（纠正模块 1 的一处旧记录）**：
  1. **桌面/网页端没有独立的「最近浏览」页面**——`/recent` 路由不存在（404 空态页）。侧栏图标行 5 钮 = **主页 / FlowUs AI / 搜索 / 通知 / 更多**（03 号文档原记录「主页/最近/搜索/通知/更多」有误，第二个图标是 FlowUs AI 笑脸）。
  2. **桌面/网页的「主页」= FlowUs AI 对话页**（`/chat`）：居中 AI logo + 6 能力 chips + 大输入框。主页钮当前已是主页态时点击无反应。
  3. **手机端的主屏 = 最近浏览**：抽屉层顶部就是「最近浏览」横向卡片轮播，下方才是空间页面/个人页面树。
- 观复的取舍提示：观复没有商业 AI 对话页作为主页的需求——**主页槽位建议换成"最近浏览+收藏/快速访问"**（原位替换，等用户拍板）；本规格照录 FlowUs 形态。

## 1. 桌面 / 网页端：主页（=FlowUs AI chat）

**入口**：侧栏图标行第 1 个「主页」钮（32×32 @x=8,y=54，内容层坐标；整窗坐标 y=92）。tooltip「主页」。

**页面形态**（`flowus.cn/chat`，页签标题「FlowUs AI」）
- 主区整体居中一列（约 560 宽）：
  - 顶部 AI logo（/■(oo)> 组合图形，约 200×56 @y≈128）
  - 能力 chips 一行 6 个：**图片 / 视频 / 幻灯片 / 研究 / 多维表 / 可视化**（等距，y≈205，高 24）
  - 大输入框（圆角 ~12，宽约 690，高约 130）：占位文案「问任何问题，输入 / 选择技能」
  - 输入框底部工具行：`＋` / `🌐 仅网络 ⌄`（左）；`✨ 1,997`（积分）/ `Auto ⌄`（模型）/ `🎤`（右）
  - 输入框下「连接应用以访问更多数据或执行操作」+ 第三方应用图标一排（Google Drive 等 4 个 + ⌄）
- 侧栏「FlowUs AI」行高亮；无页面顶栏（分享/评论那排不出现——因为不是文档页）

**交互**
- 主页钮：跳 `/chat`；已在主页时点击无反应（激活态圆角灰底不消失）
- 主页不是文档页：无顶栏动作排、无面包屑；页签标题变「FlowUs AI」
- AI 能力 chips 与输入框细节属**模块 8（AI）**范围，本模块只记主页形态

**未取**
- 输入框聚焦后的技能面板（`/` 选择技能）——属模块 8
- 积分/模型选择下拉——属模块 8
- 连接应用列表展开——商业化/第三方集成，观复不复刻（01 号文档范围排除）

## 5. 手机端：主屏 = 最近浏览 + 页面树（实测）

**入口**：打开 App 即是；或页面态点底栏 ☰（`btnOpenDrawer`）/从左缘右滑。

**结构**（自上而下，抽屉层 x=0..950dp/3≈316dp 可视宽——**注意抽屉未全屏展开时右侧露出下层页面**）

| 区块 | 实测（px→dp） |
| --- | --- |
| 工作区行 | 头像 20×20dp + 空间名 + 切换 ⇅；y 57..80dp |
| 「最近浏览」标题 | 17px 字号（module1 分组标题 12sp 级别）；y 80..133dp，行高 52dp |
| 最近卡片区（横向 Recycler） | y 133..261dp；**卡片 134×108dp、间距 16dp、左右页边 16dp** |
| 卡片内容 | cover 图（134×62dp 圆角 8）+ icon 32×32dp 居中叠放 + 标题字 20dp 高（单行截断） |
| 「空间页面 ⌄」组头 | y 271..311dp，行高 40dp，右「＋」 |
| 页面行 | 40dp（对齐模块 1） |
| 底部 | 知识库广场 / 模板中心 / 回收站 / 帮助（对齐模块 1） |

**交互（实测）**
- 点卡片 → 直接打开该页面（全屏页面态，顶部出现 btnBack+标题栏）
- 横滑卡片区 → 分页滚动（Recycler 横向，卡片逐张露出，左缘可见半张裁切卡）
- 长按卡片 → 可长按标记存在（`(click,long)`），**菜单未取**（避免误触长按拖拽）
- 卡片数量多时继续横滑——上限/分页点指示器**未取**（当前仅 4 张，未出翻页 UI）

**与桌面的本质差异**：手机把「最近浏览」做进**主屏**（开 App 第一眼），桌面根本没有这个功能——手机以浏览消费为主，桌面以 AI 生成与文档编辑为主。

## 6. 三端差异

| # | 项 | 桌面客户端/网页 | 手机 |
| --- | --- | --- | --- |
| 1 | 主页 | **FlowUs AI chat**（`/chat`，非文档页，无顶栏） | 无主页概念——开屏即主屏 |
| 2 | 最近浏览 | **无**（无入口、无 `/recent` 路由） | **主屏顶部卡片轮播**（134×108dp，横向分页） |
| 3 | 通知 | 图标行铃铛 → 顶部浮层列表 | 未见独立通知入口（未取，可能在 ⋯） |
| 4 | 开屏第一眼 | 上次页面或主页 | 主屏（最近浏览 + 页面树） |
| 5 | 404/空态 | 居中「🎉 欢迎使用」+「＋ 创建新页面」 | 未取 |

**实现提示（我们的栈）**：
- 观复 Web/桌面（React）：路由加 `/`（主页）与 `/recent`；主页原位替换 AI chat 槽位为「最近浏览 + 快速入口」网格（样式可抄手机端卡片 134×108 的比例）；侧栏图标行第 1 钮=主页。
- 观复手机（Compose）：主屏抽屉顶部加横向卡片轮播（`LazyRow`，卡片 134×108dp、间距 16dp）。
- 「最近浏览」数据源：观复已有 `pages` 表 + 打开时间戳（若无则加 `lastOpenedAt` 列），取最近 10~20 条。
