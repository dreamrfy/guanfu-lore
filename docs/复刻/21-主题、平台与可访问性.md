## 1. 结论摘要

1. **主题三态：浅色 / 深色 / 跟随系统**，默认跟随系统；手动选择按设备持久化。
2. **切换 200ms 颜色过渡**，用 `data-theme` 控制，首屏内联脚本防止闪白。
3. **深色不是反色**：三级表面 + 1px 边框表达层级；图片、视频、封面、代码高亮保持原色或单独暗色主题。
4. **平台差异只调外壳**：Windows 自绘标题栏、Web 浏览器 chrome、安卓 edge-to-edge + 48dp 触摸、扩展 popup 320、官网响应式。
5. **WCAG 2.2 AA 为底线**：正文 ≥4.5:1，大字/图形 ≥3:1，焦点可见，键盘全可达。
6. **可访问性修正**：`--gf-text-tertiary` 只用于图标/分隔/禁用，不用于正文、标签、占位符；占位符改用 secondary。
7. **触摸目标 ≥44×44**（安卓/移动 Web），桌面最小 28×28；WCAG 2.2 的 24×24 是底线，不是目标。
8. **减少动效、200% 缩放、屏幕阅读器**三项必须实现，不能只写文档。

## 3. 主题模型

### 3.1 三态

| 模式 | 行为 | 存储 |
| --- | --- | --- |
| 浅色 | 强制 `data-theme="light"` | `localStorage.gf-theme = "light"` |
| 深色 | 强制 `data-theme="dark"` | `"dark"` |
| 跟随系统 | 移除 `data-theme`，用 `@media (prefers-color-scheme: dark)` | `"system"`（默认） |

- 切换入口：设置 → 外观；Windows 标题栏菜单也可切换；安卓跟随系统 + 应用内覆盖。
- 首屏：`<html data-theme="...">` 由内联脚本在 CSS 前设置，避免闪白。
- `meta name="theme-color"`：浅色 `#F7F6F2`，深色 `#171716`。
- 系统主题变化时，若为“跟随系统”，实时响应（`matchMedia` 监听）。

### 3.3 深色内容规则

- **图片/视频/封面**：不反色、不降亮度；仅加 1px `rgba(255,255,255,.08)` 边框防止融入背景。
- **代码块**：独立暗色语法主题（背景 `#121211`，文字 `#E6E3DC`，关键字 `#C792EA`，字符串 `#A5D6A7`，注释 `#74716A`）。
- **嵌入/网页**：保持原样；外框用深色边框；不强制 `filter: invert()`。
- **阴影**：深色下 `box-shadow` 减半，改用 `border` 表达层级。
- **品牌插画**：提供深色版；没有则用透明底 + 浅色描边，不反相。

### 3.4 主题候选

| 方案 | 行为 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 系统优先 + 手动覆盖（推荐）** | 默认跟随系统，可强制浅/深 | 尊重系统，切换简单 | 需要首屏脚本 |
| B. 手动双主题 | 默认浅色，手动切深 | 实现最简 | 忽略系统，晚上刺眼 |
| C. 系统 + 定时 + 高对比 | 加日落切换、高对比 | 最周到 | 复杂度高，易出 bug |

**推荐 A**；高对比作为后续独立开关，不并入主题。

## 4. 平台矩阵

| 平台 | 外壳 | 关键尺寸 | 主题 | 输入 |
| --- | --- | --- | --- | --- |
| Windows | Tauri 自绘标题栏 | 标题/页签栏 38；窗口按钮 46×38；最小 900×600 | 三态；Mica 不用 | 鼠标/键盘/触控板 |
| Web | 浏览器 chrome | 最小 360；内容 708；侧栏 228 | 三态；`theme-color` | 鼠标/键盘/触摸 |
| 安卓 | Compose edge-to-edge | 状态栏/导航栏透明；底部栏 72dp；抽屉 264.7dp | 三态；系统栏图标反色 | 触摸/手势/键盘 |
| 扩展 | popup 320×480 | 注入按钮 32×32；侧栏 400 | 跟随系统，无手动 | 鼠标/键盘 |
| 官网 | 响应式单页 | 内容 880；首屏 44px | 浅/深，跟随系统 + 切换 | 鼠标/触摸 |
| 安装包 | NSIS MUI2 | 侧图 164×314；头图 150×57 | 仅浅色 | 鼠标/键盘 |

### 4.1 Windows

- 自绘标题栏高 38，左侧 228 为拖拽区 + 页签，右侧三个窗口按钮 46×38。
- 双击标题栏最大化/还原；`-webkit-app-region: drag`；按钮 `no-drag`。
- 贴边/分屏遵循系统；不做自定义磁贴。
- 字体优先 `Microsoft YaHei UI` 作为 Noto 缺失时的回退；不嵌入雅黑。
- 高 DPI：100%/125%/150%/200% 下 1px 边框不消失（用 `0.5px` 或 `box-shadow`）。

### 4.2 Web

- 浏览器地址栏/书签栏不归我们管；页面从 y=0 开始。
- 滚动条：WebKit `8px`，圆角 4，thumb `rgba(43,42,39,.18)`；Firefox `scrollbar-width: thin`。
- 移动 Web：`viewport-fit=cover`，安全区 `env(safe-area-inset-*)`。
- PWA：`theme-color`、`apple-mobile-web-app-status-bar-style`。

### 4.3 安卓

- edge-to-edge：状态栏透明，内容延伸；顶部加 `statusBarsPadding()`。
- 底部导航栏：5 项 ×72dp；手势导航条留 16dp。
- 触摸目标 ≥44dp（WCAG 2.2 最低 24dp，但移动端用 44）。
- 字体缩放：`sp` 随系统 0.85~1.3；布局用 `dp`，文字用 `sp`；1.3 倍不截断。
- 深色：`isSystemInDarkTheme()` + 应用内覆盖；系统栏图标 `WindowInsetsController` 反色。

### 4.4 扩展

- popup 320×480；不随网页主题；跟随系统深浅。
- 注入按钮：Shadow DOM 隔离，避免网页 CSS 污染；z-index 2147483000。
- 权限提示：先解释再请求；拒绝后给“如何开启”。

### 4.5 官网/安装包

- 官网：浅/深 + 系统；无 `localStorage` 阻塞；首屏不闪。
- 安装包：NSIS 仅浅色；侧图/头图用品牌色；不用网络字体。

## 5. 可访问性（WCAG 2.2 AA）

### 5.1 对比度

> 按 WCAG 2.x 相对亮度公式计算，保留一位小数；开发前用 `scripts/wcag-contrast.mjs` 复算。

| 前景/背景 | 比值 | 等级 | 用途 |
| --- | --- | --- | --- |
| `#2B2A27` / `#F7F6F2` | ≈13.6:1 | AAA | 正文 |
| `#2B2A27` / `#FFFFFF` | ≈14.8:1 | AAA | 正文 |
| `#6B6A64` / `#FFFFFF` | ≈5.4:1 | AA | 辅助文字 |
| `#6B6A64` / `#F7F6F2` | ≈5.0:1 | AA | 辅助文字 |
| `#9B9A93` / `#FFFFFF` | ≈2.8:1 | 不合格 | 仅图标/禁用 |
| `#2F5D8A` / `#FFFFFF` | ≈7.2:1 | AAA | 主色文字/按钮 |
| `#FFFFFF` / `#2F5D8A` | ≈7.2:1 | AAA | 主按钮文字 |
| `#B4472E` / `#FFFFFF` | ≈4.8:1 | AA | 强调文字 |
| `#3F7A5A` / `#FFFFFF` | ≈4.9:1 | AA | 成功文字 |
| `#A86B1F` / `#FFFFFF` | ≈4.6:1 | AA | 警告文字 |
| `#B23B3B` / `#FFFFFF` | ≈5.9:1 | AA | 错误文字 |
| `#E6E3DC` / `#171716` | ≈12.8:1 | AAA | 深色正文 |
| `#A8A59C` / `#171716` | ≈7.5:1 | AAA | 深色辅助 |
| `#7FA8CC` / `#171716` | ≈7.9:1 | AAA | 深色主色 |
| `#D98A6E` / `#171716` | ≈7.1:1 | AAA | 深色强调 |

**规则**：
- 正文/标签/占位符不得用 `--gf-text-tertiary`；占位符用 `--gf-text-secondary`。
- 禁用态文字可低于 4.5:1（WCAG 豁免），但需与可用态明显区分。
- 大字（≥18.66px 粗体或 ≥24px）可用 3:1。
- 图形/图标边界 ≥3:1；焦点环 ≥3:1。

### 5.2 焦点

- `:focus-visible`：2px `--gf-primary` 环 + 2px offset；圆角跟随元素。
- 不用 `outline: none`；鼠标点击不显示焦点环，键盘显示。
- 焦点顺序 = 视觉顺序；弹层打开时焦点移入，关闭后回到触发器。
- 跳转链接：“跳到主要内容”，仅键盘聚焦时出现。

### 5.4 屏幕阅读器

- 语义结构：`header/nav/main/aside/footer`；页面标题 `h1` 唯一。
- 图标按钮必须有 `aria-label`（如“关闭页签”“更多操作”）；纯装饰图标 `aria-hidden="true"`。
- 动态区域：toast `role="status"` + `aria-live="polite"`；错误 `role="alert"`。
- 弹窗：`role="dialog"` + `aria-modal="true"` + `aria-labelledby`；焦点陷阱；Esc 关闭。
- 加载：`aria-busy="true"`；完成后更新。
- 表单：`<label for>`；描述 `aria-describedby`；错误 `aria-invalid="true"`。
- 树/表：`role="tree"/"treeitem"`、`role="grid"`；行/列头正确。
- 语言：`<html lang="zh-CN">`；英文术语包 `<span lang="en">`。

### 5.5 缩放与重排

- 200% 缩放不丢内容；320 CSS px 宽无横向滚动（WCAG 1.4.10）。
- 不用固定高度裁切文字；用 `min-height`。
- 文本间距可调（行高 1.5、段距 2em、字距 0.12em）不破版。

### 5.6 目标尺寸与颜色独立

- 触摸目标 ≥44×44；桌面 ≥28×28；相邻目标间距 ≥8。
- 状态不能只靠颜色：成功/失败加图标 + 文字；标签色加名称；图表加纹理/直接标注。
- 链接在正文中加下划线（不能只靠颜色）。

### 5.7 错误预防与恢复

- 删除二次确认；危险按钮红色 + 具体动词。
- 表单离开前提示未保存；自动保存草稿。
- 提供撤销（Ctrl+Z）与回收站 30 天。
- 错误信息可复制；不丢失用户输入。

## 7. 落地映射

```css
:root { color-scheme: light; }
:root[data-theme="dark"] { color-scheme: dark; }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* 深色 token */ }
}
```

- React：`ThemeProvider` 读写 `localStorage.gf-theme`；`matchMedia('(prefers-color-scheme: dark)')` 监听。
- 安卓：`AppCompatDelegate`/Compose `isSystemInDarkTheme()`；DataStore 存覆盖。
- 扩展：`matchMedia` + `storage.sync` 存偏好。
- 官网：`prefers-color-scheme` + 手动 class；首屏内联脚本。
- 安装包：固定浅色，不读系统。

## 8. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| 深色 `#191919/#202020` | `#171716/#20201E` | 更暖、层次更清 |
| 主色 `#2383e2` | `#2F5D8A` | 全面替换 |
| 无 reduced-motion | 支持 | 无障碍 |
| tertiary 用于正文 | 仅图标/禁用 | 对比度达标 |
| 无焦点环 | 2px 环 | 键盘可达 |

**验收断言**：
1. 浅/深/系统三态切换无闪白；刷新后保持。
2. 正文对比度 ≥4.5:1；脚本扫描全部 token 组合。
3. 键盘可完成：打开页面、搜索、新建、删除确认、关闭弹层。
4. 焦点环在深色/浅色都可见；不被 `overflow:hidden` 裁剪。
5. 200% 缩放无横向滚动；320px 宽可用。
6. `prefers-reduced-motion` 下无位移动画。
7. 图标按钮有 `aria-label`；toast 有 `aria-live`。
8. 安卓 1.3 倍字体不截断；触摸目标 ≥44dp。

## 10. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 深色不是把浅色反过来：同样的墨蓝，在 `#171716` 上要提亮到 `#7FA8CC` 才清楚；暖纸底在深色下要变成三层近黑，否则卡片会糊成一片。这些只有并排看、真的切一遍，才知道是否舒服。预览稿要提供浅/深/系统三态、200% 缩放、减少动效、键盘焦点演示，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「主题、平台与可访问性」分区。
