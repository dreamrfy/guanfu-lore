## 一、方案（用户 2026-11-21 拍板）

| 决策点 | 结论 |
| --- | --- |
| 域名 | **`share.guanfu.app`**（一次性定终态，不用 clip 域、不再造新子域模式） |
| DNS | AI 用现有 Cloudflare token 建 CNAME → 同一隧道（clip 同源同服务） |
| 匿名策略 | 22 位随机 token 不可枚举；链接**永久有效直到关闭**；`noindex`（meta+X-Robots-Tag 双保险）；暂无密码 |
