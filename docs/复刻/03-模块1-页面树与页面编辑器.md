## 1. 侧栏 / 页面树

**入口**：手机 = 页面左下角 ☰（`btnOpenDrawer`）或从左缘右滑；桌面/网页 = 常驻左栏。

**结构（两端一致）**
- 顶部：工作区行（头像方块 + 空间名 + ⌄ 切换）＋「＋」新建
- 图标行（桌面）：**5 个 32×32**（主页 / 最近 / 搜索 / 通知 / 更多）
- 「FlowUs AI」行（桌面 179×32，右侧 24×24 历史记录）
- 分组：**空间页面 ⌄** / **个人页面 ⌄**（组头右侧各有 设置、新建 两个 20×20）
- 页面行：图标 + 名称（＋「▸」展开子页、「…」行菜单、「＋」新建子页）
- 底部：桌面 = **空间容量卡**（观复换成独有功能）；手机 = 知识库广场 / 模板中心 / 回收站 / 帮助

**尺寸实测**

| 项 | 手机 | 桌面/网页 |
| --- | --- | --- |
| 侧栏宽 | 抽屉 **264.7dp** | **228** |
| 页面行高 | **40dp** | **32** |
| 工作区行 | — | 211×38 @(8,8)，圆角 6；头像 26×26 圆角 4 |
| 页面 emoji 图标 | 随行高 | **18×18** @x=18 |
| 页面名起点 | x=66dp | x=41（字号 14） |
| 分组标题 | 行 40dp | 字号 **12**、行 32 |
| 行内右侧按钮 | `iv_more`/`iv_create` 各 **36×40dp** | 20×20（悬停出现） |

**交互**
- 点行 → 打开页面；点「＋」→ 在该页下新建子页；点「…」→ 行菜单（见 §2）
- 点组头 → 折叠/展开；组头「＋」→ 该组下新建根页
- **手机长按行：无菜单**（实测 1s 长按无反应）——所有行操作都在「…」里
- 拖动排序 / 拖入子级：**未取**

**子页实测**：页面信息 = 创建者/创建时间/最后编辑者/最后编辑时间；页面动态 = 「某人在某时创建了…」；页面历史 = **FlowUs 付费能力**（"升级后即可找回"）。
**字体及布局设置** = 默认字体（息流/霞鹜文楷/思源宋体，后两个带 Pro）＋ 页面布局（紧密，Pro）。
**导出页面** = 格式 PDF ／ 页面尺寸 A4·A3 ／ 显示比例 100%。

## 6. 编辑器

**工具条（手机，贴键盘）**：8 槽，槽 **46×44dp**，顺序
`✨AI ｜ ⊕插入 ｜ ↺↻撤销重做 ｜ Aa文字样式 ｜ ≡对齐列表 ｜ 🖼图片 ｜ "/"（26×44）｜ ▦多维表`，槽间有 6×30px 分隔。

**斜杠 / 块类型菜单（手机）**：**两列网格**，图标片约 64×64px + 文案；输入后出现「输入块名称进行搜索」→ **支持搜索过滤**；实测可见：正文 / 待办列表 / 页面 / 引用页面 / 标题1 / 标题2 …
（该浮层**不暴露给 uiautomator**，靠截图取证。）

**块菜单（手机）**：块右侧**点状手柄** → 底部动作面板
- 快捷行 4 项（各 76dp 宽）：**AI辅助 / 转换为 / 副本 / 删除**
- 列表（项高 50dp）：剪切 / 复制 / 移动到 / 全选
- 「转换为」是二级面板（**未取**）

**桌面**：块左侧 gutter 两个 **20×20**（拖拽手柄 + 插入），另有 **24×24** 块类型 pill；菜单是纵向悬浮列表。

**其他交互**：缩进（→ 变上一兄弟子块 / ← 提为父块下一个兄弟）、长按 ≡ 跨层级拖拽排序（均已在观复 A07 实现并实测）。

## 7. 页面详情 / 子页 / 引用区

- 手机：页面详情即页面本身（标题 + 属性/正文）；子页在侧栏树里展开
- 桌面：页尾常驻三行引用区：**引用当前页面 / 提及的页面引用 / 引用建议 Beta**
- 观复现状：A09 只做了"引用了本页"一段（简化），需按上面三段结构重做
