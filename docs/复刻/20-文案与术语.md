## 1. 结论摘要

1. **语气「克制、准确、温和」**：像一位靠谱的编辑，不像客服，也不像营销号。
2. **一句话说清“发生了什么 + 下一步”**；错误文案再加“为什么/错误码”，不责怪用户。
3. **统一用「你」**，不用「您」；不用感叹号、emoji、网络梗、夸张词（“极致/颠覆/一键起飞”）。
4. **动词开头**：按钮用“新建页面/保存/删除”，不用“确定/提交/操作”。
5. **术语唯一**：页面、块、多维表、视图、属性、记录、空间、收集箱、剪藏、标签、引用、同步、凭证、AI 供应商。
6. **破坏性操作说后果**：“删除「XX」？30 天内可在回收站恢复。”
7. **空态不卖萌**：承认空 + 给一个动作；可以有一句轻文学，但不能妨碍理解。
8. **三端同一套词**：Windows/Web/安卓/扩展只改“窗口/浏览器/手机/当前页”等必要名词。

## 3. 语气三选一

### 3.1 A. 克制书面（推荐）

> “还没有记录。点右上角「新建记录」开始。”
> “没能保存。检查网络后重试。”
> “已收进收集箱，稍后整理。”

- 特点：短句、动词明确、不亲昵、不冷漠；允许一句轻文学，但不牺牲信息。
- 适合：知识库、长文、专业用户。

### 3.2 B. 亲切口语

> “这里还空着，点右上角建一条吧。”
> “保存没成功，检查下网络再试试？”
> “剪好啦，先放收集箱。”

- 特点：像朋友；适合个人产品，但容易显得不专业，且翻译/多端一致性差。

### 3.3 C. 极简标签

> “暂无记录”
> “保存失败”
> “已剪藏”

- 特点：最短；适合高密度工具，但缺少下一步，空态显得冷。

**推荐 A**；营销页可略偏 B，产品内保持 A。

## 4. 写作规则

1. **一句一件事**：超过 40 字拆成两句；避免从句套从句。
2. **动词优先**：按钮/菜单以动词开头；名词化（“进行保存”）禁止。
3. **具体**：说“检查网络”，不说“出错了”；说“API Key 无效”，不说“认证失败”。
4. **不责怪**：不说“你输入错了”，说“这个地址格式不对，示例：https://…”。
5. **不夸张**：不用“极致/颠覆/革命性/一键/轻松/秒级”；官网也用事实。
6. **不卖萌**：不用“呀/啦/哦/～/🥳”；空态可有一句“空，也是一种整理。”但不堆。
7. **不省略主语到歧义**：AI/同步等异步操作要说明“谁在做什么”。
8. **中英混排**：中文与英文/数字之间加半角空格（“30 天”“API Key”）；中文标点用全角。
9. **省略号**：用“……”，不用“...”。
10. **引号**：UI 元素用「」，正文引用用“”；英文用 `code`。

## 5. 术语表

| 术语 | 定义 | 允许 | 禁止 |
| --- | --- | --- | --- |
| 页面 | 知识库中的一篇内容，可含块/子页 | 页面 | 文档、笔记、文件（作页面时） |
| 块 | 页面中的最小内容单元（段落/标题/图片…） | 块 | 元素、组件、模块 |
| 多维表 | 带属性、视图、记录的结构化数据表 | 多维表 | 数据库、表格（指多维表时） |
| 视图 | 多维表的一种展示方式（表格/看板/画廊/日历/列表） | 视图 | 页面、标签页 |
| 属性 | 多维表的列定义（文本/数字/日期/标签…） | 属性 | 字段、列（作定义时） |
| 记录 | 多维表中的一行 | 记录 | 条目、行（作名词时） |
| 空间 | 顶层内容容器（个人空间/知识库） | 空间 | 工作区、笔记本、文件夹 |
| 收集箱 | 剪藏/快速捕捉的暂存区 | 收集箱 | 收件箱、Inbox（中文界面） |
| 剪藏 | 把网页/微信文章收进收集箱 | 剪藏 | 收藏、保存网页（作功能名时） |
| 标签 | 跨页面的分类标记 | 标签 | 分类、标记（作名词时） |
| 引用 | 页面 A 提到页面 B 的反向链接 | 引用/反向链接 | 链接（作 backlink 时） |
| 提及 | 在正文中 @ 某个页面/人 | 提及 | @、mention（中文界面） |
| 模板 | 可复用的页面/多维表结构 | 模板 | 样板、模版 |
| 回收站 | 已删除内容的暂存区 | 回收站 | 垃圾桶、废纸篓 |
| 快速访问 | 侧栏顶部的常用页面入口 | 快速访问 | 收藏夹、书签 |
| 同步 | 多设备间同步数据 | 同步 | 云同步（除非强调云端） |
| 凭证 | 同步/存储/AI 的密钥与连接信息 | 凭证 | 密码、Token（作统称时） |
| AI 供应商 | 提供模型的服务的商（OpenAI/Anthropic/Ollama…） | AI 供应商 | AI 服务商、模型商 |
| API Key | 供应商的访问密钥 | API Key | 密钥（可混用，但首次出现写全） |
| 提示词 | 给 AI 的指令文本 | 提示词 | Prompt（中文界面） |
| 技能 | 观复内置的 AI 能力（总结/改写/提炼…） | 技能 | 插件、工具（作 AI 技能时） |
| 对话 | 与 AI 的多轮交流 | 对话 | 聊天、会话 |
| 问答 | 基于知识库的 RAG 问答 | 问答 | 搜索（作 AI 问答时） |

**大小写**：产品名「观复 · Lore」；英文 Lore 首字母大写；API Key、AI、URL、PDF 全大写；文件名/路径用 `code`。

## 6. 微文案矩阵

### 6.1 按钮

| 场景 | 推荐 | 避免 |
| --- | --- | --- |
| 新建页面 | 新建页面 | 新建、创建、添加 |
| 新建多维表 | 新建多维表 | 新建表格（易混） |
| 新建记录 | 新建记录 | 添加行、新建条目 |
| 保存 | 保存 | 确定、提交 |
| 取消 | 取消 | 关闭（取消操作时） |
| 删除 | 删除页面 / 删除记录 | 删除、确定 |
| 恢复 | 恢复 | 还原、撤销删除 |
| 重试 | 重试 | 再试一次（可用，但按钮短） |
| 连接 | 连接 | 保存并测试（太长） |
| 断开 | 断开连接 | 解绑、取消授权 |
| 复制链接 | 复制链接 | 分享（不是分享时） |
| 导出 | 导出 | 下载（导出格式时用导出） |
| 导入 | 导入 | 上传（导入文件时用导入） |

### 6.2 空态

| 场景 | 文案 | 动作 |
| --- | --- | --- |
| 空页面 | 从一篇空白开始。 | 输入 / 或按 `/` 插入块 |
| 空多维表 | 还没有多维表。新建一个，把信息排成你看得懂的样子。 | 新建多维表 |
| 空记录 | 还没有记录。点右上角「新建记录」开始。 | 新建记录 |
| 空收集箱 | 收进来，慢慢整理。 | 去剪藏 / 安装扩展 |
| 空搜索 | 没找到。换个词试试。 | 清除筛选 |
| 空回收站 | 空，也是一种整理。 | 返回 |
| 空 AI | 问点什么，或让我总结这一页。 | 示例问题 |
| 空同步 | 还没有连接设备。连接后，内容会在设备间同步。 | 连接设备 |

### 6.3 错误

公式：**发生了什么 + 为什么（可选）+ 下一步 + 错误码（可选，放详情）**。

| 场景 | 文案 |
| --- | --- |
| 保存失败 | 没能保存。检查网络后重试。 |
| 同步失败 | 同步暂停了。检查网络或重新登录后重试。 |
| 剪藏失败 | 没能抓取这一页。可能需要登录，或页面不允许抓取。 |
| AI Key 无效 | 这个 API Key 无效。检查是否复制完整，或换一个 Key。 |
| AI 额度不足 | 供应商返回额度不足。充值或换一个供应商后再试。 |
| 文件过大 | 文件超过 50 MB，换一个小一点的文件。 |
| 导入格式不支持 | 这个文件格式暂不支持。支持 Markdown、HTML、CSV。 |
| 数据库打开失败 | 库没能打开。可能是浏览器存储被清理；可从备份恢复。 |
| 冲突 | 两台设备都改了同一页。选一个版本保留，另一个会存为副本。 |

规则：不显示堆栈、不显示英文异常；技术细节放“查看详情”，可复制。

### 6.4 确认

| 场景 | 文案 |
| --- | --- |
| 删除页面 | 删除「页面名」？30 天内可在回收站恢复。 |
| 删除记录 | 删除这条记录？此操作不可撤销。 |
| 清空回收站 | 清空回收站？里面的内容将无法恢复。 |
| 断开同步 | 断开连接？本机内容会保留，其他设备不再同步。 |
| 删除 AI 供应商 | 删除「供应商名」？使用它的技能将不可用。 |

### 6.5 加载/成功

| 场景 | 文案 |
| --- | --- |
| 启动 | 正在打开你的库…… |
| 同步 | 正在同步…… / 已同步 · 刚刚 |
| 剪藏 | 抓取中…… / 已收进收集箱 |
| AI | 正在思考…… / 已停止 |
| 保存 | 已保存 / 已保存到本机 |
| 复制 | 已复制 |
| 连接 | 已连接 |

### 6.6 引导

| 步骤 | 文案 |
| --- | --- |
| 欢迎 | 欢迎来到观复。先建一个空间，或导入已有的内容。 |
| 选 AI | 选一个 AI 供应商。Key 只保存在本机。 |
| 剪藏 | 安装浏览器扩展，或在微信里转发文章给观复。 |
| 同步 | 连接同步后，手机和电脑看到同一份内容。 |

## 7. 数字、日期、单位

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 相对时间 | <1 分钟“刚刚”；<1 小时“N 分钟前”；<24 小时“N 小时前”；<7 天“昨天/星期X”；≥7 天绝对日期 | 刚刚 / 5 分钟前 / 昨天 14:30 / 2026-11-18 |
| 绝对日期 | `YYYY-MM-DD`；时间 `HH:mm` | 2026-11-18 14:30 |
| 数量 | 千分位；≥1 万用“万” | 1,234 / 1.2 万 |
| 文件大小 | 1024 进制；空格 | 12 MB / 1.4 GB |
| 百分比 | 数字 + %，不空格 | 68% |
| 快捷键 | `Ctrl` + `K`；Mac `⌘ K` | Ctrl K |
| 版本 | `v1.0.0` | v1.0.0 |

## 8. 三端与全触点差异

| 触点 | 差异 | 示例 |
| --- | --- | --- |
| Windows | 用“窗口/最小化/关闭” | 关闭窗口 |
| Web | 用“浏览器/标签页” | 在新标签页打开 |
| 安卓 | 用“手机/返回” | 按返回键退出 |
| 扩展 | 用“当前页/网页” | 剪藏当前页 |
| 官网 | 可略偏营销，但事实准确 | “数据留在你自己的设备上。” |
| 安装包 | 用“安装/卸载/目录” | 选择安装目录 |

## 9. 落地映射

- `app/src/i18n/strings.ts`：所有文案集中；key 用 `domain.action`（如 `page.empty`、`sync.error.network`）。
- 插值：`{name}` / `{count}`；不拼接句子，用完整模板。
- 复数：中文无复数，但数量词要正确（“1 条记录/2 条记录”）。
- 错误：`error.title` + `error.detail` + `error.code`；UI 只显示 title，详情折叠。
- 扩展/官网：复制同一套术语；官网英文版另立术语表，不直译中文文学句。
- 安卓：`strings.xml` 同名 key；不要硬编码中文。

## 10. 迁移影响与验收断言

| 旧文案 | 新文案 | 原因 |
| --- | --- | --- |
| “新建表格” | “新建多维表” | 与表格块区分 |
| “确定” | 具体动词 | 明确后果 |
| “保存失败” | “没能保存。检查网络后重试。” | 给下一步 |
| “暂无数据” | 场景化空态 | 更友好 |
| “您” | “你” | 统一语气 |
| “...” | “……” | 中文标点 |

**验收断言**：
1. 所有按钮以动词开头；无“确定/提交”。
2. 错误文案含下一步；无堆栈/英文异常。
3. 术语表词在 UI 中无禁用同义词（脚本扫描）。
4. 空态均有一个动作。
5. 中文标点全角；中英之间半角空格。
6. 三端同一功能同一词。

## 12. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 同一句空态文案，放在 96px 插画下、14px 灰色小字里、还是 16px 正文里，语气完全不同；“克制书面”与“亲切口语”的差别，也只有并排读一遍才能选。预览稿要把 8 个空态、4 个错误、4 个确认、3 套语气并排展示，用户确认后再改源码。
