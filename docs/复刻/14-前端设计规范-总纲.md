## 1. 结论摘要

1. **专项基准「墨蓝 · 宣纸」**：暖纸底 + 墨色文字 + 靛蓝主色 + 朱砂强调。它比 FlowUs 的亮蓝、Notion 的黑白更有辨识度，也更适合中文长文阅读。**注：后续已另出两套应用预览（天青·汝窑主方向 / 赭墨·敦煌候选），最终视觉方向待用户拍板，本稿作为基础规范继续有效。**
2. **主色 `#2F5D8A`**，强调色 `#B4472E`；浅色底 `#F7F6F2`，深色底 `#171716`。所有颜色以语义变量 `--gf-*` 交付，禁止组件直接写十六进制。
3. **UI 字体思源黑体/Noto Sans SC，阅读字体思源宋体/Noto Serif SC，等宽 JetBrains Mono**；UI 正文 14/22，编辑器正文 16/28，页面标题 36/48。全部可打包字体均为 OFL。
4. **图标统一 Lucide，20px 默认、16px 行内、1.75 描边**；保留四库切换能力，但默认只暴露 Lucide，避免风格混杂。
5. **布局以 4px 为基础单位**：侧栏 228、顶条 48、页签栏 38、内容宽 708、右栏 320；圆角 4/6/8/12；阴影三级；z-index 六层。
6. **动效克制**：80/120/160/240/320ms 五档，标准曲线 `cubic-bezier(.2,0,0,1)`；只做位移、透明度、颜色，不做视差与自动播放。
7. **文案语气「克制、准确、温和」**：不用感叹号、不卖萌、不责怪用户；术语表统一「页面/块/多维表/视图/属性/记录/收集箱/剪藏」。
8. **全触点统一**：扩展、官网、安装包都使用同一套 token；官网从现有靛紫 `#4f46e5` 迁到墨蓝，扩展从 `#2383e2` 迁到墨蓝。

## 2. 设计定位与原则

### 2.1 一句话

> **纸墨之间，观复万物。** 一个安静、可信、可以长期居住的个人知识库。

观复不是团队协作工具，也不是炫技的 AI 产品。它的界面应该像一张好纸：不抢内容，但经得起细看；有温度，但不复古；有秩序，但不僵硬。

### 2.2 六条原则

| 原则 | 含义 | 反例（不要） |
| --- | --- | --- |
| 内容先于界面 | 正文、标题、数据是主角；外壳退到背景 | 大面积渐变、重阴影、彩色卡片墙 |
| 克制而有温度 | 暖纸底、墨色字、少量朱砂；不用纯黑纯白对撞 | 纯 `#000` 正文、纯 `#FFF` 卡片堆叠 |
| 一致而不单调 | 同一语义同一 token；靠层级和留白制造节奏 | 每个页面一套主色、每个模块一种圆角 |
| 可读性优先 | 中文正文 16/28，行长 ≤ 44em，对比度 ≥ 4.5:1 | 12px 正文、浅灰字、长行满屏 |
| 本地优先、可信 | 同步/凭证/AI Key 的状态必须可见、可撤销 | 偷偷上传、状态不明、失败无提示 |
| 可访问 | 键盘可达、焦点可见、减少动效、色盲友好 | 只靠颜色区分状态、焦点环被移除 |

### 2.3 品牌方向三选一

| 方向 | 关键词 | 主色 | 气质 | 风险 |
| --- | --- | --- | --- | --- |
| **A. 墨蓝 · 宣纸（推荐）** | 纸、墨、靛青、朱砂 | `#2F5D8A` | 学者气、安静、耐看 | 比 FlowUs 暗，首屏不够“亮” |
| B. 青瓷 · 雾灰 | 青瓷、雾、竹 | `#2C6E6A` | 清冷、现代、东方 | 青色在数据可视化里易与成功色混淆 |
| C. 玄墨 · 极简 | 黑、白、一束蓝 | `#1F6FEB` | 工具感、效率、接近 Notion/Linear | 辨识度低，容易“像别人” |

**推荐 A**。理由：① 观复的名字与“观复”出处（《道德经》“万物并作，吾以观复”）天然适合纸墨叙事；② 暖中性底比纯白更耐长时间阅读，也与 FlowUs/Notion 的冷白拉开差异；③ 靛蓝在中文界面里少见，既专业又不科技蓝；④ 朱砂只用于 AI/洞察/重要提醒，形成记忆点。

## 3. Token 架构

采用三层：

```
Primitive（原始值） → Semantic（语义） → Component（组件）
#2F5D8A            → --gf-primary      → --gf-button-primary-bg
```

- **Primitive** 不直接进组件；只出现在 token 文件与文档附录。
- **Semantic** 是组件唯一允许引用的层；命名规则 `--gf-<类别>-<语义>[-<状态>]`。
- **Component** 只在必要时新增，且必须引用 Semantic。
- 现有 `app/src/styles/index.css` 的 `--bg/--text/--primary` 等旧变量保留一个迁移周期，逐步映射到 `--gf-*`；映射表见 §7。

## 8. 治理

- **唯一事实源**：本套文档 + HTML 工作台；开发落地时生成 `app/src/styles/tokens.css`，两者数值必须一致。
- **变更流程**：提案（改哪份文档）→ HTML 预览 → 用户拍板 → 改文档与 tokens → 开发迁移 → 回归断言。
- **版本**：文档 v1.0 为推荐稿；用户确认后升 v1.1 冻结，再进入开发。
- **废弃**：旧 `docs/design/*-v0.1.md` 保留作历史，不再作为实现依据；冲突时以本套为准。
- **验收**：颜色对比度用脚本跑；间距/圆角/字号用 DOM 断言；HTML 工作台三档视口自检。
