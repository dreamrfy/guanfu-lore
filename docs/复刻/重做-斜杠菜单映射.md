# 重做批 · `/` 斜杠菜单映射表（观测全量 → BlockNote 能力 → 本期范围）

> 三栏口径：
> - **原生**：BlockNote 0.57 自带块型或自带斜杠项，直接可用（只需对齐文案/快捷码）。
> - **自定义**：BlockNote 无此块型，需要在 `app/src/editor/blocks/` 新建自定义块（schema 已扩展过 callout/bookmark/collectionBlock）。
> - **不做**：本期（重做批）不做，原因写在备注里；文案仍照录进菜单但必须**诚实置灰或不出现在菜单**——不允许出现点了没反应的项。
>
> BlockNote 0.57 原生块型（`@blocknote/core` defaultBlockSpecs）：Paragraph / Heading(1–6，界面开放到 4) / ListItem（项目·编号·待办·折叠）/ Quote / Code / Divider / Table / Image / Video / Audio / File / PageBreak。
