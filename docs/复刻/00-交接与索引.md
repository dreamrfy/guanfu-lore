## 一、当前阶段与红线（先读这段）

**阶段：FlowUs 前端表现观测与规格撰写。** 目标是让观复三端（Web / Windows 桌面 / 安卓）
在**界面形态与交互逻辑**上对齐 FlowUs 对应端 95%（只换图标与字体）。

**四条红线（违反即返工）**
1. **只观测、写规格；不改任何代码、不动现有实现。** 本轮归档也只在 `docs/`、`README`、`开发状态`、任务表里写字。
2. **FlowUs 的截图 / 控件树 / 录屏只留本地**（`ops/观测/`）；公开仓库只放我们自己写的文字与观测工具。
3. **用户真实账号可自由增删改**（已授权），但**账号密码类页面不抓不留**；抓到含密钥/个人资料的页面要**当场删除**。
4. **删除类自动化必须先核对目标名称**（名称框/标题），核对不上就停手——本轮差点误删用户原有视图。

**代码侧的定性（用户 2026-11-17 拍板）**：安卓 A03–A09 的**内核保留复用**（Room 数据层、同步引擎、编辑内核），
**UI 层待重做**；**A10–A15 暂停**，不在旧 UI 上继续堆功能。重做顺序：**Web + 桌面先行，安卓跟齐**。

## 六、踩过的坑（新会话别重复踩）

| # | 坑 | 正确做法 |
| --- | --- | --- |
| 1 | `adb shell input text` 里的**空格会被吞**（要写 `%s`） | 该命令里用 `%s` 代替空格 |
| 2 | git-bash 会把 `/sdcard/...` 转成 Windows 路径 | 加 `export MSYS_NO_PATHCONV=1` |
| 3 | `/tmp` 是 git-bash 的虚拟路径，**`adb push` 认不了** | 临时文件放仓库内 `ops/tmp/` |
| 4 | 含中文的 `.ps1` 被 PowerShell 读成乱码（找不到路径） | 保存为 **UTF-8 with BOM** |
| 5 | GDI+ 存图到含中文的路径会报错 | 写 `MemoryStream` 再 `WriteAllBytes`（见 `shot-window.ps1`） |
| 6 | PowerShell `>` 重定向会给二进制加 BOM，截图坏掉 | 用 `cmd /c "adb ... > file"` |
| 7 | 切主题后**立刻截图会拍到旧主题** | **先采像素再命名**（本轮据此纠正过一次误标） |
| 8 | Tabbit 的 `page.screenshot()` 会卡在"等字体加载"超时 | 改用 `context().newCDPSession(page)` 的 `Page.captureScreenshot` |
| 9 | 桌面客户端 CDP 的 `page` 目标是外壳，**内容在 `webview` 目标里** | 选 `url` 含 `flowus` 的那个目标 |
| 10 | 桌面端视图/坐标在多次点击之间会被切走 | 每步点击前**重新读一次 DOM 坐标**，不要复用旧坐标 |
| 11 | 手机上视图行的**长按/左滑都没有菜单**，删除控件点不动 | 记住这是特殊控件；文档已标注，别硬试 |
| 12 | **弹层菜单截图坐标 ≠ 实际位置**（2026-11-17 事故：把「退出登录」当成「空间设置」点了，用户被登出） | 弹层菜单项必须**先读 DOM 中心坐标 + `elementFromPoint` 核对文本**，两步都通过才点击；绝不拿截图坐标硬算弹层项（弹层有动画偏移）；相邻危险项（空间设置/退出登录仅差 41px）加倍核对。参考 `set-03-ws-settings.mjs` 的 ABORT 机制 |
| 13 | **AI 侧边面板会把侧栏折叠**（面板展开时侧栏被覆盖，出现左上 `«`；收面板后侧栏不自动恢复） | 面板收起后用 DOM 重新定位侧栏展开钮（内容层 ~30,24）并**截图确认**工作区行可见，再继续后续点击 |
| 14 | 手机 `adb input text` **不支持中文**（会写入 URL 编码或乱码） | 中文输入要么换英文关键词、要么走输入法广播；搜索观测用英文关键词即可（liunx） |
