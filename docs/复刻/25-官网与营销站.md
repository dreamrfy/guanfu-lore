## 1. 结论摘要

1. **一句话定位**：“AI 原生的块式个人知识库，数据归你。”
2. **首屏只做三件事**：说清是什么、给一张真产品图、给一个下载按钮；不堆功能图标。
3. **主色从靛紫 `#4f46e5` 迁到墨蓝 `#2F5D8A`**，与主应用一致；暖纸底 `#F7F6F2`，标题用宋体。
4. **信息架构 8 段**：首屏 → 信任条 → 四个能力 → 三步上手 → 为什么是观复 → 本地优先/开源 → 下载 → FAQ/页脚。
5. **功能段只讲四件事**：剪藏（微信/网页）、块式编辑、多维表、AI（自带 Key）；每段一张真截图 + 一句人话。
6. **不做假数据、不做 stock photo、不做 3D 插画**；用产品截图、线稿和真实界面。
7. **深浅色都做**，默认跟随系统；首屏 44/56 宋体，正文 16/28。
8. **下载区覆盖 Windows / 安卓 / Web**，标明版本、大小、签名、更新方式；不放“即将推出”的空按钮。

## 4. 首屏

### 4.1 文案候选

| 方案 | H1 | 副标题 | 按钮 |
| --- | --- | --- | --- |
| **A（推荐）** | 万物并作，<br>吾以观复。 | AI 原生的块式个人知识库。剪藏、整理、提炼，数据始终在你自己手里。 | 下载桌面版 / 打开 Web 版 |
| B | 你的第二大脑，<br>安静地长出来。 | 把微信文章、网页、灵感收进一个库，用 AI 帮你提炼。 | 免费下载 / 看功能 |

## 5. 能力段

每段结构：小标签（12/18 主色）→ 标题 28/36 宋体 → 说明 16/28 → 3 条要点（图标 20 + 14/22）→ 产品截图/线稿。

| # | 能力 | 标题 | 说明 | 截图 |
| --- | --- | --- | --- | --- |
| 1 | 剪藏 | 微信、网页，一键收进来。 | 转发文章给观复，或点浏览器扩展；正文、图片、来源一起保存。 | 收集箱双栏 |
| 2 | 块式编辑 | 像写纸，像搭积木。 | 标题、待办、引用、代码、表格、多维表，都是块。 | 文档页 |
| 3 | 多维表 | 把信息排成你看得懂的样子。 | 表格、看板、画廊、日历，同一份数据换视图。 | 多维表 |
| 4 | AI | 你的 Key，你的模型。 | 自带 OpenAI/Anthropic/Gemini/Ollama；总结、改写、问答，内容只发给你选的供应商。 | AI 面板 |

## 7. 为什么是观复

| 差异 | 文案 | 证据 |
| --- | --- | --- |
| 数据自持 | 库在你自己的磁盘/对象存储里；导出是 Markdown，不是锁定格式。 | 开源仓库 |
| 中文长文 | 宋体标题、16/28 正文、44em 行长；为中文阅读调过。 | 字体规范 |
| AI 可控 | 不绑定供应商；Key 只存本机；可关、可换、可删。 | 设置页 |
| 微信剪藏 | 公众号文章转发即入库，保留来源与图片。 | 收集箱 |

## 11. SEO / 性能 / 隐私

- `<title>`：观复 · Lore — AI 原生的块式个人知识库
- `description`：剪藏微信文章与网页，用块式编辑和多维表整理，自带 AI Key，数据本地优先、开源可导出。
- OG/Twitter 图 1200×630；`og:type=website`；canonical。
- 结构化数据：`SoftwareApplication`（name, applicationCategory, operatingSystem, offers price 0）。
- 性能：首屏 ≤ 150KB（不含截图）；字体子集化；截图 WebP/AVIF；懒加载；LCP < 2.5s。
- 隐私：无第三方分析、无 cookie 横幅、无聊天插件；如需统计，用自建、无 cookie 的方案并在隐私页说明。
- 可访问性：对比度 AA、键盘可达、跳过导航、图片 alt、`prefers-reduced-motion`。

## 13. 落地映射

- `website/index.html`：单文件保留；CSS 变量替换；加入深色 `prefers-color-scheme` + 手动切换。
- 字体：自托管 Noto Serif SC / Noto Sans SC 子集（woff2），或先用系统宋体回退；不要 Google Fonts（隐私/可用性）。
- 图标：内联 Lucide SVG（20/24），去掉 emoji。
- 截图：`website/assets/`，1200×760 WebP；深色版各一张。
- 下载链接：构建时替换 `{{VERSION}}`、`{{WIN_URL}}`、`{{APK_URL}}`、`{{SHA256}}`。
- 分析：默认无；如启用，自建且无 cookie。

## 14. 迁移影响与验收断言

| 旧 | 新 | 影响 |
| --- | --- | --- |
| `#4f46e5` | `#2F5D8A` | 全站换色 |
| 44/800 黑体 | 44/56 宋体 | 字体加载/回退 |
| emoji 功能图标 | Lucide | 替换 4 处 |
| 无深色 | 有 | 新增 CSS |
| 占位下载 | 真下载 | 构建注入 |
| 无 FAQ | 8 条 | 新增 |

**验收断言**：
1. 1200/768/375 三档无横向滚动。
2. 深浅色对比度 AA；产品图不反色。
3. 首屏 LCP < 2.5s（本地 3G 模拟）。
4. 下载三卡都有版本/大小/校验；无空按钮。
5. 导航键盘可达；跳过导航可用。
6. 无第三方请求（字体/分析/图标）。
7. OG 图与 title/description 正确。
8. 所有截图来自真实应用。

## 16. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 官网首屏是“一句话 + 一张图 + 两个按钮”，但宋体 44px 与黑体 44px 的气质差很远；暖纸底与纯白底放在一起，才知道哪个更像观复。预览稿要把 A/B/C 三套首屏文案、深浅色、1200/768/375 三档并排展示，用户确认后再改 `website/index.html`。
