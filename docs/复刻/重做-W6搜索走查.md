## 三、快捷键实测（W84 · shortcuts-check，浏览器侧）

| 快捷键 | 规格语义 | 实测 | 结论 |
| --- | --- | --- | --- |
| Ctrl+P | 全局搜索 | 浮层开、输入框聚焦；Escape 关 | ✅ |
| Ctrl+\ | 侧栏折叠/展开 | 折叠态 false → true → false 往返还原 | ✅ |

| 抢键守卫 | 表单输入框里不抢键 | 标题输入框（INPUT）中 Ctrl+P 不开浮层；**编辑器正文（contenteditable）放行**——写作中按 Ctrl+P 找页面是主场景 | ✅ |

### 本轮修掉的三个真问题（如实记录）

1. **跳页断言错**：`openTab` 对已打开页是「聚焦既有页签」而非新开页签——脚本原断言页签数增长，
   改为断言 `.tab--active` 文案命中目标页。
2. **抢键守卫豁免反了**：`shortcuts.ts` 原为 `isEditingText && combo !== "Ctrl+P"` 跳过守卫，
   与文件头声明（输入框里 Ctrl+P 不开面板）相反；改为 INPUT/TEXTAREA 让键、contenteditable 放行，
   并把两版语义都写进脚本固化。
3. **空格触发被挤掉**：PageEditor 落地块级三键时入口改成了「无 Ctrl 直接 return」，空行按空格唤起
   AI 小框（不带 Ctrl 的老行为）随之失效；重构为 Ctrl 分支 + 普通键分支并行，两条路径都实测。

### 待办（诚实标注）

- W84 规格要求「浏览器与 Tauri 双验」：本轮浏览器侧全过；Tauri 桌面端留待打包批（`tauri:build`）后
  用同脚本跑一遍。块级 A/B/F/Del 单键与文本输入冲突，规格层已标【暂定】不落地。
- `Ctrl+T` / `Ctrl+J` 的语义级属推测级（shortcuts.ts 头部有逐条标注），以实测可用为准。
