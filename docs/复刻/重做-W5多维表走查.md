## 三、本轮修掉的真实缺陷

1. **列头菜单改名丢失**（W77 走查时发现）：菜单的 `mousedown` 外部关闭会先卸载输入框，
   `onBlur` 还没触发 → 改名没写库。改为 `onChange` 也提交一次（W66 的列名框、W76 的属性名框同修）。
2. **属性行菜单被裁掉**（W76）：弹层放在 `.record__label` 里，而它有 `overflow: hidden`，
   绝对定位的弹层被裁没了。锚点改挂 `.record__prop`。
3. **记录页不认 `hidden`**（W76）：「隐藏」只对网格生效，记录页仍显示该属性。
   记录页改为同样过滤 `!f.hidden`。
4. **正文判空用错口径**（W76）：按数组长度判空不成立——`PageEditor` 挂载时会写一个空段落进来。
   改为按「有没有真文字」判。
