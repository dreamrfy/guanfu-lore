# 17 图标体系（观复 · Lore）

- 状态：**推荐稿 v1.0**（2026-11-18）
- 上游：[14-前端设计规范-总纲.md](14-前端设计规范-总纲.md) §4
- 适用：Web / Windows / 安卓 / 扩展 / 官网 / 安装包
- 证据：`ops/观测/专项/flowus-styles.json`（FlowUs 图标尺寸统计）、`ops/观测/windows/34-sidebar-icons.json`（侧栏图标按钮）、`app/src/design/icons.tsx`、`app/src/design/icons.generated.json`

## 1. 结论摘要

1. **统一 Lucide**，默认 20px / 1.75 描边；行内 16px / 1.5；大图标 24/32。保留四库切换，但默认只暴露 Lucide。
2. **只用 SVG，不用图标字体**：可继承 `currentColor`、可访问、可按需打包、无字体闪烁。
3. **图标是“标点”，不是插画**：工具栏/侧栏/按钮用线性图标；空态/功能页才用较大线稿插画。
4. **尺寸阶梯 16/20/24/32**；12px 只用于徽标/小箭头，9px 禁用（FlowUs 的 9px 图标是历史遗留，不跟）。
5. **点击区域独立于图标尺寸**：桌面 28/32/36，触摸 ≥44×44；图标 20 时按钮 32。
6. **语义映射唯一**：同一动作全产品只用一个图标名；新增图标先进 `ICONS` 映射，再进组件。
7. **品牌/第三方图标不改色**：微信/B 站/AI 供应商用官方 SVG 或单色简化版；不用微信 logo 做“剪藏”图标，避免商标混淆。
8. **图标与文字二选一**：图标按钮必须有 `aria-label`/tooltip；有空间时优先“图标 + 文字”。

## 3. 候选方案

### 3.1 A. Lucide（推荐）

- 1500+ 图标，ISC 许可，24×24 网格，默认 2px 描边，圆角端点。
- 风格：中性、线性、几何，适合工具型界面。
- 优点：覆盖全、风格稳、与 BlockNote/React 生态契合；可按 1.75 描边统一。
- 缺点：部分中文场景图标（剪藏、收集箱、多维表）需自绘补充。

### 3.2 B. MingCute

- 圆润、友好，Apache-2.0，约 3000 图标。
- 优点：更“亲和”，适合个人产品；圆角与暖纸底气质合。
- 缺点：圆润线条在密集表格/工具栏里显得软；与宋体标题的“书卷感”不完全一致。

### 3.3 C. Phosphor

- 6 种字重（thin/light/regular/bold/fill/duotone），MIT。
- 优点：可做“线性 + 填充”双态；品牌感强。
- 缺点：体积与选择成本高；duotone 容易花；团队需要严格约束字重。

### 3.4 对比

| 维度 | Lucide | MingCute | Phosphor |
| --- | --- | --- | --- |
| 覆盖 | 高 | 高 | 高 |
| 风格稳定 | 高 | 中 | 中（多字重易乱） |
| 与宋体标题 | 高（几何对书卷） | 中（圆润） | 高 |
| 实现成本 | 低 | 低 | 中 |
| 默认推荐 | ✅ | 备选 | 备选 |

**推荐 A**；MingCute 保留为可选主题，Phosphor 不默认暴露。

## 4. 尺寸与描边

| 场景 | 图标尺寸 | 描边 | 点击区域 | 示例 |
| --- | --- | --- | --- | --- |
| 行内（跟随 14px 文字） | 16 | 1.5 | — | 链接前的小图标、标签 |
| 工具栏/侧栏/按钮 | 20 | 1.75 | 28/32/36 | 新建、搜索、设置 |
| 页面头/卡片头 | 24 | 1.75 | 32 | 分享、评论、更多 |
| 空态/功能入口 | 32 | 1.5 | 40 | 空收集箱、AI 入口 |
| 大空态/插画 | 96/160 | 1.5 | — | 空页面、404 |
| 徽标/箭头 | 12 | 1.5 | — | 下拉箭头、快捷键提示 |

规则：
- 20px 是默认；不要在同一行混用 18/22 等非阶梯尺寸。
- 描边随尺寸微调：16→1.5，20→1.75，24→1.75，32→1.5（放大后线条相对变粗，需减细）。
- 图标与文字间距 6px（16px 图标）/8px（20px 图标）。
- 图标垂直居中用 `display:inline-flex; align-items:center`，不用 `vertical-align: middle` 硬调。
- 图标不缩放位图；全部 SVG，`shape-rendering: geometricPrecision`。

## 6. 图标按钮

| 尺寸 | 图标 | 按钮 | 圆角 | 用途 |
| --- | --- | --- | --- | --- |
| sm | 16 | 28×28 | 6 | 行内操作、标签删除 |
| md | 20 | 32×32 | 6 | 工具栏、侧栏、页面头 |
| lg | 20 | 36×36 | 8 | 触摸/大按钮 |
| touch | 20 | 44×44 | 8 | 安卓/iPad |

状态：
- default：`color: --gf-text-secondary`，透明底。
- hover：底 `--gf-bg-hover`，字 `--gf-text-primary`。
- active/pressed：底 `--gf-bg-active`，字 `--gf-primary`。
- selected：底 `--gf-bg-selected`，字 `--gf-primary`。
- disabled：`--gf-text-disabled`，`cursor:not-allowed`，无 hover。
- focus-visible：2px `--gf-primary` 焦点环 + 2px offset。

## 7. 空态插画（8 张）

统一规格：96×96 或 160×120，1.5 描边，线稿 + 单色浅底；颜色 `--gf-text-tertiary` + `--gf-primary-soft`；不用渐变、不用 3D。

| 场景 | 画面 | 文案（见 20/23） |
| --- | --- | --- |
| 空页面 | 一张纸 + 一支笔 | 从一篇空白开始。 |
| 空多维表 | 网格 + 一颗种子 | 还没有表格。 |
| 空记录 | 几行卡片 + 加号 | 还没有记录，点右上「新建记录」开始 |
| 空收集箱 | 敞开的盒子 + 一片叶子 | 收进来，慢慢整理。 |
| 空搜索 | 放大镜 + 空白纸 | 没找到。换个词试试。 |
| 空回收站 | 垃圾桶 + 折纸 | 空，也是一种整理。 |
| 空 AI | 对话气泡 + 星点 | 问点什么，或让我总结这一页。 |
| 空同步 | 两朵云 + 虚线 | 还没有连接设备。 |

## 8. 品牌与第三方图标

- **微信剪藏**：自绘「文章 + 剪刀」线性图标，不用微信绿色 logo；如需标识来源，用 16px 微信单色 logo + 文字“微信”。
- **B 站**：官方单色/彩色 SVG，按官方规范留白，不拉伸。
- **AI 供应商**：OpenAI/Anthropic/Gemini/Ollama 用官方 SVG；无法确认授权时用通用 `bot` + 文字，不用近似 logo。
- **文件类型**：PDF/图片/视频/音频/代码/压缩包用 Lucide `file-*` + 扩展名文字，不画拟物图标。
- **应用图标**：见 26，单独设计，不复用界面图标。

## 9. 三端与全触点差异

| 触点 | 差异 | 处理 |
| --- | --- | --- |
| Windows | 标题栏图标 16px，窗口控制用 SVG 12px | 不随系统缩放失真，用 `vector-effect` |
| Web | 浏览器缩放 125%/150% | SVG 矢量；按钮尺寸用 rem/px 不混 |
| 安卓 | 触摸 44dp、系统返回/分享图标 | 用 Material 图标仅限系统级；业务图标仍 Lucide |
| 扩展 | 注入按钮 32px + 1px 描边 | 页面背景不可控，加白/黑双描边 |
| 官网 | 功能卡图标 24/32，线性 | 不用 emoji 当图标（现有官网要改） |
| 安装包 | NSIS 位图图标 16/32/48 | 需要多尺寸 ICO，不用 SVG |

## 10. 落地映射

- `app/src/design/icons.tsx`：`ICON_SETS` 保留四库；`DEFAULT_ICON_SET = "lucide"`；`ICONS` 扩展 §5 全表；`Icon` 组件增加 `size`（16/20/24/32）与 `strokeWidth` 自动映射。
- `app/src/design/icons.generated.json`：由 `tools/gen-icons.mjs` 重新生成；只打包用到的图标。
- `tools/check-icons.mjs`：校验四库都存在、语义名无重复、无 9px 尺寸。
- 组件：`IconButton` 统一 28/32/36 三档；`EmptyState` 统一插画尺寸。
- 安卓：`GfIcons.kt` 用 `painterResource` 导入 SVG→VectorDrawable；尺寸 16/20/24dp，触摸 44dp。

## 11. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| Lucide 默认 2px | 20px 时 1.75 | 图标略细，更精致 |
| 混合 16/20/24 | 阶梯 16/20/24/32 | 统一视觉节奏 |
| 9px 小图标 | 移除 | 不再出现不可读图标 |
| 四库默认可选 | 默认只 Lucide | 减少风格混杂 |
| 官网 emoji 图标 | 线性 SVG | 官网更专业 |

**验收断言**：
1. 所有图标为 SVG，无 icon font；`currentColor` 继承。
2. 尺寸只出现 16/20/24/32；无 9/12（12 仅箭头）。
3. 图标按钮有 `aria-label` 或可见文字；触摸目标 ≥44。
4. 同一语义只映射一个图标名；`ICONS` 无重复值。
5. 空态插画统一 1.5 描边、两色以内。
6. 第三方 logo 不变形、不近似、不滥用。

## 13. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 图标的差异在单张图上很小，但放进侧栏、工具栏、表格行、空态里，风格是否统一一眼就能看出；1.5 与 1.75 描边、圆角与方角、20 与 24 尺寸，也需要并排比较。预览稿要展示 Lucide/MingCute/Phosphor 三套在同一界面里的效果，以及 16/20/24/32 四档和 8 张空态插画，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「图标体系」分区。
