## 二、判定口径

- 每个模块切换 `html[data-theme]` 为 `light` / `dark`，各截一张 1200×762 图。
- 同时对模块关键选择器取 `getComputedStyle`（背景/文字/边框），要求至少一个表面随主题变化，避免“只是标签变了、样式没变”。
- 结果：8/8 模块通过；共 16 张截图 + 1 张 4×4 拼图。

## 三、走查结论

1. **没有发现硬编码浅色残留**：令牌守卫（`npm run check`）已保证组件无写死颜色；本轮真实渲染复核，深色下首页、编辑器、表格、收集箱、搜索、AI 面板、设置、分享面板均为深色表面，文字可读。
2. **浅色未退化**：切换回浅色后各模块保持原有观感；深/浅往返无残留样式。
3. **弹层类（搜索/设置/分享）**：遮罩与卡片都跟随主题，没有出现“深色页面里弹白卡”。
4. **已知边界**：
