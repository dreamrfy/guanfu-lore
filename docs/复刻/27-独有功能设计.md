## 1. 结论摘要

1. **三块独有功能共用一条主线**：收进来（剪藏/收集箱）→ 用起来（AI 供应商）→ 带着走（同步与凭证）。
2. **微信剪藏提供三条入口**：安卓分享 Sheet、微信服务号转发、复制链接粘贴；桌面用扩展/粘贴，不假装能读微信。
3. **收集箱是“待整理”而不是“第二仓库”**：每条只有四个动作——打开原文、转页面、归档、删除；AI 摘要/标签是辅助。
4. **AI 供应商“自带 Key”**：OpenAI/Anthropic/Gemini/Ollama/OpenAI 兼容五类；Key 只存本机钥匙串，不进同步、不进日志。
5. **同步默认关闭**：仅本机是默认；S3 兼容/WebDAV/自建服务三选一；凭证与加密口令分离。
6. **冲突不静默覆盖**：文本按块三方合并，属性按字段，无法判定时生成冲突副本并让用户选。
7. **所有失败都有下一步**：凭证错误、跨域、配额、加密口令错、文章已删，各有文案与动作。
8. **三端一致、能力分级**：桌面全功能；安卓分享入口最强；Web 无钥匙串，Key 只驻留会话或加密保存。

# 第一部分 · 微信剪藏与收集箱

## 2. 目标与边界

| 项 | 内容 |
| --- | --- |
| 目标 | 从微信看到一篇文章，到进入观复收集箱，≤5 秒、≤2 次点击 |
| 不丢 | 离线先存链接；联网后抓正文；失败可重试 |
| 不脏 | 去广告/导航/推荐；保留标题、作者、封面、正文、图片、来源 |
| 不重复 | 同一 canonical URL 只保留一条；重复时打开已有 |
| 不越权 | 只处理用户主动分享/粘贴的链接；不读取微信聊天记录 |
| 不做 | 公众号批量采集、自动关注、绕过付费墙、下载视频 |

## 3. 入口与流程

### 3.1 安卓分享 Sheet（主入口）

1. 微信文章右上 `⋯` → 分享 → **观复**。
2. 观复收到 `text/plain` 或 `text/html` 的 URL，弹出底部面板（高 200）：
   - 封面 64 + 标题“正在收进收集箱…” + 进度条 2px。
3. 抓取成功 → 面板变为“已收进收集箱” + 标题 + [打开] [继续]；2s 后自动收起。
4. 失败 → “没能抓取这篇。链接已保存。” + [重试] [打开原文]。
5. 离线 → “已保存链接，联网后自动抓取。”；队列 badge +1。

**Intent filter**：`ACTION_SEND`，`text/plain`、`text/html`；`ACTION_VIEW` 对 `mp.weixin.qq.com` 可选（谨慎，避免抢默认）。

### 3.2 微信服务号转发

1. 用户把文章转发给“观复”服务号。
2. 服务号回复：“收到，正在抓取…”
3. 成功：“已收进收集箱：《标题》”；失败：“这篇没能抓取，试试复制链接到观复。”
4. App 同步后在收集箱出现；通知可关。

> 该入口依赖用户自带的服务端/服务号配置；文档只定义交互与文案，不定义公众号资质。

### 3.3 复制链接 / 桌面

- 桌面：`Ctrl+Shift+V` 打开“快速剪藏”对话框；粘贴 URL → 抓取 → 收集箱。
- 浏览器扩展：见 24 号文档。
- 手机剪贴板识别：复制 `mp.weixin.qq.com` 链接后打开观复，首页顶部提示“检测到链接，收进收集箱？”（可关）。

### 3.4 去重

- 规则：`canonicalUrl` 去掉 `from`、`isappinstalled`、`scene`、`clicktime` 等追踪参数；再比 `contentHash`（正文前 2KB + 标题）。
- 命中：不新建；提示“这篇已经在收集箱里。” + [打开]；若旧条目失败，允许覆盖重试。
- 同 URL 不同内容（公众号改稿）：保留旧版，新增“更新”按钮，用户确认后替换。

## 5. 数据模型

```ts
type ClipStatus = 'queued' | 'fetching' | 'pending' | 'archived' | 'failed';

interface Clip {
  id: string;
  url: string;
  canonicalUrl: string;
  title: string;
  author?: string;
  source: 'wechat' | 'web' | 'extension' | 'paste' | 'share';
  cover?: string;
  excerpt?: string;
  contentHtml: string;      // 清洗后
  contentText: string;      // 纯文本，用于搜索/AI
  images: string[];         // 本地缓存或远端
  tags: string[];
  status: ClipStatus;
  error?: { code: string; message: string };
  contentHash?: string;
  readingProgress?: number;
  aiSummary?: { bullets: string[]; quotes: string[]; suggestedTags: string[] };
  pageId?: string;          // 转为页面后
  createdAt: number;
  updatedAt: number;
  archivedAt?: number;
}
```

- 索引：`canonicalUrl` 唯一；`status`、`createdAt`、`tags` 复合索引。
- 正文截断 200KB；图片只存前 50 张，其余保留远程 URL。
- 原始 HTML 可保留 7 天用于重解析，之后只留清洗后内容。

## 6. 抓取与清洗

| 步骤 | 规则 |
| --- | --- |
| 取 URL | 只接受 http/https；拒绝 `javascript:`、`file:` |
| 取正文 | 微信 `#js_content`；通用 Readability；失败回退 `article`/`main` |
| 去噪 | 去掉 script/style/nav/footer/广告/推荐/二维码 |
| 图片 | `data-src` 优先；懒加载；失败占位；不下载视频 |
| 编码 | UTF-8；乱码时按 charset 重试 |
| 标题 | `og:title` → `h1` → `title`；去“ - 微信公众平台” |
| 作者 | `og:article:author` → 公众号名 |
| 封面 | `og:image` → 首图 |
| 安全 | 渲染时 sanitize；禁止 script/iframe/on*；外链 `rel=noopener` |
| 限额 | 200KB；超时 15s；重试 2 次（指数退避） |

| 抓取中 | 正在收进收集箱… |
| 成功 | 已收进收集箱 |
| 失败 | 没能抓取这篇。链接已保存。 |

## 8. 边界与失败

| 场景 | 处理 |
| --- | --- |
| 文章已删除/付费墙 | 保存标题/URL/摘要；标“仅链接”；提示打开原文 |
| 图片防盗链 | 服务端代理下载；失败占位 |
| 超长文 | 截断 200KB；提示“已截断” |
| 视频/音频 | 保留链接与封面，不下载 |
| 公众号改稿 | 检测 hash 变化；提示更新 |
| 重复分享 | 去重；打开已有 |
| 微信反爬 | 回退到“仅链接”；建议用浏览器打开后扩展剪藏 |
| 无网络 | 队列；联网重试 |
| 存储满 | 提示清理/导出；不静默失败 |

## 9. 隐私

- 只处理用户主动分享/粘贴的 URL；不读取微信聊天记录、不监听剪贴板（仅在用户打开 app 时读一次，且可关）。
- 正文与图片存本地；如同步，走用户自己的存储。
- 服务号入口由用户自建/配置；观复不运营中心服务器。

# 第二部分 · AI 供应商设置

## 10. 目标与原则

| 原则 | 说明 |
| --- | --- |
| 自带 Key | 用户自己的账号/额度；观复不代充值、不转卖 |
| 不锁定 | 五类供应商；随时换；模型名可手填 |
| 本机保存 | Key 进系统钥匙串；不进同步、不进日志、不进导出 |
| 说清去向 | 每次请求显示“内容将发送到 [供应商]” |
| 可失败 | 401/403/429/超时都有下一步 |
| 可分级 | 对话/摘要/嵌入/重排可分别选模型 |

## 11. 供应商类型

| 类型 | Base URL 默认 | 认证 | 模型示例 |
| --- | --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | Bearer | gpt-4.1, gpt-4.1-mini |
| Anthropic | `https://api.anthropic.com` | x-api-key | claude-sonnet-5-5, claude-haiku-5-5 |
| Google Gemini | `https://generativelanguage.googleapis.com` | key | gemini-2.5-pro/flash |
| Ollama | `http://127.0.0.1:11434` | 无 | llama3.3, qwen2.5 |
| OpenAI 兼容 | 用户填 | Bearer | DeepSeek/Moonshot/Qwen/vLLM 等 |

> 模型名不写死；优先从 `/models` 拉取，失败允许手填。

| --- | --- | --- |

## 13. Key 存储

| 平台 | 方式 |
| --- | --- |
| Windows | Windows Credential Manager（Tauri keyring/stronghold） |
| macOS | Keychain |
| 安卓 | EncryptedSharedPreferences / Keystore |
| Web | 默认不持久化（仅会话）；可选“用口令加密保存在本机”，明确风险 |
| 扩展 | 不存 AI Key；只存剪藏 Token |

- 日志脱敏：`sk-...`、`Bearer`、`x-api-key` 一律打码。
- 导出：默认不含 Key；如导出配置，需用户勾选并二次确认。
- 删除供应商：删 Key + 配置；提示“相关 AI 功能将不可用”。

## 14. 错误与文案

| HTTP/场景 | 文案 | 下一步 |
| --- | --- | --- |
| 401 | API Key 无效或已过期。 | 去更新 Key |
| 403 | 这个 Key 没有权限使用该模型。 | 换模型/检查权限 |
| 404 | 找不到这个模型。 | 手动输入正确模型名 |
| 429 | 请求太频繁或额度用完。 | 稍后重试/换供应商 |
| 5xx | 供应商暂时不可用。 | 重试/换供应商 |
| 超时 | 连接超时。 | 检查网络/代理/Base URL |
| CORS（Web） | 浏览器阻止了跨域请求。 | 用桌面版/本地代理 |
| Ollama 未启动 | 本机 Ollama 没有响应。 | 启动 Ollama/检查端口 |
| 模型不支持 | 这个模型不支持对话/嵌入。 | 换模型 |

## 15. 隐私与成本

- 每次对话底部：“内容将发送到 OpenAI（gpt-4.1）。Key 只保存在本机。”
- 首次使用弹一次说明；之后可关。
- Token 估算：输入/输出/本月累计；不承诺精确账单。
- 不自动上传全库；RAG 只上传检索到的片段（可显示片段数）。
- 关闭 AI：设置总开关；关闭后隐藏 AI 入口，不删配置。

# 第三部分 · 同步与凭证

## 16. 目标与模式

| 模式 | 说明 | 默认 |
| --- | --- | --- |
| 仅本机 | 不同步；可手动导出/导入 | ✅ |
| S3 兼容 | AWS S3 / Cloudflare R2 / MinIO / B2 | — |
| WebDAV | Nextcloud / 坚果云 / 自建 | — |
| 自建服务 | 观复 server，URL + Token | — |

- 同步是可选；不开启不打扰。
- 同步内容：页面/块/多维表/标签/收集箱/设置（不含 Key）。
- 附件：单独开关；大文件按需。

## 17. 设置向导

| 步 | 内容 | 校验 |
| --- | --- | --- |
| 1 选择模式 | 4 卡片 | — |
| 2 填凭证 | endpoint/bucket/region/key/secret 或 URL/账号/密码 | 格式 |
| 3 测试连接 | 写入/读取/删除临时文件 | 15s 超时 |
| 4 加密口令 | 可选但推荐；强度条；确认 | ≥12 字符 |
| 5 首次同步 | 上传/下载/合并；进度；冲突数 | 可暂停 |
| 6 完成 | 设备名；自动同步开关 | — |

**加密**：Argon2id 派生 + AES-256-GCM；口令不存服务器；忘记无法恢复（二次确认）。
**凭证存储**：同 AI Key，进系统钥匙串；不进同步/日志/导出。

| 类型 | 策略 |
| --- | --- |
| 文本块 | 三方合并（base/local/remote）；无冲突自动合 |
| 属性/单元格 | 按字段比较；不同字段各自保留 |
| 同字段不同值 | 生成冲突副本；用户选 |
| 删除 vs 编辑 | 保留编辑；提示“一端已删除” |
| 附件 | 内容 hash 相同去重；不同保留两份 |

**界面**：左右对比（本机/远端）+ 合并结果；[保留本机] [保留远端] [合并]；AI 建议合并（可选，显示“AI 建议”标签）。
**批量**：全部保留本机/远端；逐条仍需确认高风险项。

## 20. 设备与凭证管理

| 功能 | 说明 |
| --- | --- |
| 设备列表 | 名称/平台/最后活跃/版本；当前设备标记 |
| 重命名 | 本地名称，不影响其他设备 |
| 移除设备 | 远端撤销 token；该设备下次同步失败并要求重新授权 |
| 轮换密钥 | 重新生成访问密钥；旧密钥失效 |
| 断开同步 | 保留本机/删除本机副本；远端不动 |
| 删除远端 | 二次确认输入“删除”；不可恢复 |

## 25. 迁移影响与验收断言

| 旧 | 新 | 影响 |
| --- | --- | --- |
| 剪藏弹窗 | 收集箱双栏 | 新页面/路由 |

| Key 存 localStorage | 钥匙串 | 迁移与清理 |

**验收断言**：
1. 安卓分享一篇文章，5 秒内出现在收集箱；离线有队列。
2. 同一 URL 二次分享不新建，打开已有。
3. 收集箱四状态可见；失败可重试。
4. 转页面后保留来源/标签/封面，且能跳回原文。
5. AI 供应商五类都能配置；测试连接有延迟/模型。
6. Key 不出现在日志、导出、同步包；删除后功能不可用。
7. 401/429/超时各有文案与下一步。
8. 同步默认关闭；开启向导 6 步可完成。
9. 冲突不静默覆盖；可逐条/批量解决。
10. 卸载/断开同步不会误删本地数据（有确认）。
11. Web 端 Key 不持久化（或口令加密明示风险）。
12. 所有失败状态有“重试/去设置/查看日志”之一。
