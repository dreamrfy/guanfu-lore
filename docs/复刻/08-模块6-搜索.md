## 1. 桌面 / 网页端：全局搜索面板 ⭐

**入口**（三个，均实测）：
1. 顶栏右侧放大镜（内容层 x≈1170, y≈33）
2. 侧栏图标行第 3 钮 🔍（32×32 @x=98, y=54）
3. **快捷键 Ctrl+P**（tooltip 文案「**快速查找 Ctrl+P**」——顶栏放大镜 hover 可见；Ctrl+F 无页内搜索，被 Ctrl+P 覆盖）

**面板形态**（居中浮层，宽约 800，y≈88..512）：
- 大输入框（左 🔍 + 占位「在页面中搜索」；输入中左端变 spinner、右端出 × 清空钮）
- 页签/过滤行：**页面**（选中）｜**对话**｜`A` **只搜索标题**｜👤 **创建者 ⌄**｜范围 chip（如 `📄 学习进度 ×`，蓝底可移除）｜**＋**（加范围）
- 默认态列表：**「在 [当前页] 中问 AI」**行（AI 问答入口）+ **「最近浏览」分组**（图标+标题，含已删除页面——**回收站内容仍在最近浏览里**）
- 输入后：AI 行变「**问问 AI「关键词」**」；结果区按范围过滤

**实测交互**：
- 范围 chip 锁定单页时搜「配置」→ 零结果（只剩问问 AI 行）→ **chip 生效**
- 「只搜索标题」开关点击后过滤范围变化（53 号截图）
- 「对话」页签切换后列表变对话历史（54 号截图，用户账号无对话记录→近似空态）
- Escape 关闭面板

**未取**：chip × 的精确点击坐标与移除后行为、创建者下拉展开、「＋」加范围流程、结果条目的 hover 态与「打开」按钮（曾在 52 号截图中出现于结果行右缘）。

## 2. 手机端：全局搜索页 ⭐（数据最全的一端）

**入口**：底部固定栏第 2 项 🔍（`btn_search` [216,2190][432,2292] = 72×34dp 槽位）；主屏抽屉内的搜索框（`search_container`，抽屉态 304×48dp）点击进同一页。

**页面形态**（`86/90/91/94` 号证据）：
- 顶栏：左「**取消**」+ 居中标题「**搜索**」（48dp）
- 输入框：描边圆角、左 🔍、占位「**在 两相欢的空间 中搜索**」；有值时右端 ×（328×36dp）
- **「最近浏览」**分组（=搜索历史）+ 右侧「**清除**」；条目=图标+标题+**父页路径副标题**（子页显示「学习进度」）
- 输入关键词后出现：
  - **「排序： 按匹配度 ⌄」**（左）+ **「≡ 筛选」**（右，蓝色文字）
  - **「只搜索标题」**开关行（CompoundButton 35×40dp @右侧）
  - **「搜索结果」**标题 + 右侧**「63条结果」**计数
- 结果条目（三行结构）：**页面标题**（粗）+ **面包屑路径**（`微信公众号剪藏` 或 `归档历史材料 /.../ 每日循环任务`）+ **命中内容片段**（正文匹配行，标题模式无此行）

**实测交互**：
- 搜「liunx」→ **63 条**（全文匹配含正文子串；标题匹配=「liunx命令」页）
- 开「只搜索标题」→ **1 条**（只剩标题命中的页面）✅ 开关生效实锤
- 「排序」底部面板 3 项：**按匹配度 / 按最后编辑时间-最近到最早 / 按最后编辑时间-最早到最近**
- 「筛选」底部面板（94 号截图全量）：
  - **快速筛选**：我创建的页面 / 上周编辑过的页面 / 在当前页面内搜索
  - **自定义筛选**：创建人 / 创建时间 / 最后编辑时间 / 在指定页面内搜索
- 「取消」/返回键退出

**页内搜索（多维表内）**：目录视图顶部有 **表格内搜索框**（304×48dp 圆角胶囊「🔍 搜索」）——只搜本表记录（83 号截图）。文档页无独立页内搜索（走全局搜索的「在当前页面内搜索」筛选）。

## 3. 快捷键（实测）

| 快捷键 | 行为 | 证据 |
| --- | --- | --- |
| **Ctrl+P** | 打开全局搜索面板（tooltip「快速查找 Ctrl+P」） | 60、_searchstate |
| Ctrl+F | 无独立页内搜索（顶栏搜索钮出现 tooltip，未打开独立条） | 60 号探针 |
| Escape | 关闭搜索面板 | 多次实测 |

## 4. 三端差异

| # | 项 | 桌面/网页 | 手机 |
| --- | --- | --- | --- |
| 1 | 入口 | 顶栏放大镜 + 侧栏 🔍 + **Ctrl+P** | 底栏 🔍 + 主屏搜索框 |
| 2 | 面板形态 | 居中浮层（页签行+过滤行） | **全屏页**（顶栏「取消/搜索」） |
| 3 | 范围过滤 | **chip**（默认锁当前页，可 × / ＋） | 筛选面板「在当前/指定页面内搜索」 |
| 4 | 结果结构 | 图标+标题（+行缘「打开」） | **三行：标题+面包屑+命中片段** |
| 5 | 排序 | 未取（面板内未见排序钮） | 「按匹配度 ⌄」3 项 |
| 6 | 搜索历史 | 最近浏览分组（混结果） | 独立「最近浏览+清除」区 |
| 7 | 计数 | 无计数条 | 「N条结果」 |
| 8 | 页内搜索 | 无独立 Ctrl+F | 多维表内嵌搜索框；文档页靠筛选 |

## 5. 实现落点（观复的栈）

- **数据层**：观复已有全文搜索（`db.ts` FTS）；需补：命中片段提取（`content_tv` 三行结构）、面包屑路径、结果计数、按匹配度/编辑时间排序。
- **桌面（React）**：全局搜索浮层（顶栏放大镜 + `Ctrl+P`）——范围 chip 默认锁当前页（与 FlowUs 一致）或默认全空间（待用户拍板，FlowUs 默认锁当前页是从顶栏入口进入的语境）；「只搜索标题」「创建者」过滤。
- **手机（Compose）**：全屏搜索页 + 搜索历史（需新表 `searchHistory`）+ 排序/筛选底部面板。
- **AI 问答入口**：搜索面板首行「问问 AI「关键词」」——观复接自家 RAG（`ragAsk.ts` 已有底子），入口形态照抄。
