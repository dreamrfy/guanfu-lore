# 01 基准与约束（观复 · 对标 FlowUs）

> **这是护栏文档**：做观复前端之前先读它，不要凭自己的理解发挥。
> 所有条目都是 2026-11-16 / 11-17 与用户逐条确认过的；未确认的一律不许自作主张。
> 上一版本：`docs/复刻基准与约束-v1.md`（已并入本文，见 git 历史）。

---

## 一、我们对标什么

- **对标产品：FlowUs（息流）**。观复三端 = **学它的前端表现与交互逻辑**，不是复制它的代码。
- **不复制代码、不换栈**：Web/桌面继续 React + BlockNote；安卓继续 Kotlin + Compose；
  数据层/同步层沿用我们自己的实现（Dexie / Room、自建同步协议）。
  规格里只写"在我们自己的栈里怎么落地"。
- **Notion 的位置**：只在两个专项里出场（颜色美化、文案对比），**不作为实现基准**。
- **三端一致**：交互逻辑三端一体；界面各自贴合 FlowUs 对应端——手机端允许必要的移动化适配，
  但不能变成"另一个样子"。

## 二、保真度

| 维度 | 结论 |
| --- | --- |
| 布局 / 间距 / 圆角 / 尺寸 / 层级 | **像素级对齐**（观测时量尺寸、取像素） |
| 图标、字体 | **允许不同**（换我们自己的） |
| 颜色 | 专项已完成：`15-颜色体系` + 两套视觉预览（天青·汝窑主方向 / 赭墨·敦煌候选）；最终数值待统一换皮 |
| 文案 | 专项已完成：`20-文案与术语`；界面文案按规范执行，最终随统一换皮复核 |
| 深色主题 | **两套都要对齐**（深色下描边、反色、斑马纹都不同） |

## 三、范围

- **不做**：团队空间 / 协作 / 模板市场 / FlowUs 的商业化界面（套餐、空间容量、升级）/
  **收集表**（2026-11-17 用户拍板：它是"生成对外收集链接"的外向能力，与协作同类）。
- 商业化界面腾出的槽位（左下角容量卡、头像菜单、设置里的套餐页）→
  **用观复独有功能原位替换**（收集箱与剪藏入口、AI 供应商设置、同步与凭证）。
- 观复独有、FlowUs 没有的功能（微信剪藏、企业微信接收、AI 供应商设置）：
  **单独设计一版交用户拍板**，不进 95% 对照表。

## 四、流程与验收

1. 先交《复现规格》——先交一个模块样本，格式与粒度获认可后**一批一模块**推进。
2. 规格 → 前端专项（颜色/文案/字体/图标等，S01–S15）+ 独有功能设计稿 → 重做。**已完成（2026-11-18）**。
3. **重做顺序：Web + 桌面先行（同一套代码），安卓跟齐。**
4. 重做验收线：**界面逐屏并排对照通过 + 功能真能用**（新建/编辑/保存/同步/搜索/回收站）。

## 五、当前阶段与红线（2026-11-17 制定；2026-11-20 对齐）

- **当前阶段 = 重做施工（Web + 桌面）**：观测 10/10 已完成；前端专项 S01–S15 已完成（`14`–`27`），两套视觉预览已出（天青·汝窑主方向 / 赭墨·敦煌候选）；重做批 79/90，W120/W121 已完成；剩 W122–W123、W9、W11。
- **以下红线 1–4 是观测阶段的历史约束**（重做期仍保留证据红线；新增 UI 一律走令牌，见 `ops/看门狗-v7提示词.md` 规则 8）：
- **红线 1：新会话只观测、写规格；不改任何代码、不动现有实现。**
- **红线 2：FlowUs 界面截图 / 控件树 / 录屏只留本地**（`ops/观测/`），**不进公开仓库**；
  仓库只放我们自己写的文字规格与观测工具（`ops/观测/_tools/`）。
- **红线 3：用户真实账号可自由增删改**（已授权），但**账号密码类页面不抓、不留**；
  已抓到的含密钥/个人资料的页面要**即时删除**（本轮已删过两屏）。
- **红线 4：删除类自动化必须先核对目标名称**（名称框/标题），核对不上就停手——
  本轮有一次差点误删用户原有视图。

## 六、安卓端既有成果的定性（2026-11-17 用户拍板）

- **保留内核**：A03–A09 的 Room 数据层、同步引擎（对齐 web `sync.ts` 五要点）、编辑内核**保留复用**。
- **UI 重做**：现有 Compose 界面在 web + 桌面规格落地后，按 FlowUs 形态重做。
- **A10–A15 暂停**：不在旧 UI 上继续堆功能（详见 `开发任务表-v3.4-全功能批.md` 的标注）。

## 七、"最容易做错"清单（跨模块，防复发）

1. 把桌面的**常驻侧栏**照搬到手机（手机是抽屉 + 遮罩）。
2. 把桌面的**段首悬浮工具条**照搬到手机（手机是"贴键盘的固定工具条"）。
3. 把桌面的**块左侧悬浮菜单**照搬到手机（手机是"块右侧点状手柄 → 底部动作面板"）。
4. 把 `/` 菜单在手机上也做成纵向列表（手机是**两列网格** + 搜索）。
5. 给手机做**列头菜单**（手机没有；字段编辑在"视图设置 → 属性 → 字段"）。
6. 忘记手机底部固定栏五项（☰ / 搜索 / 新建页面 / AI / 偏好设置）。
7. 把视图切换在手机上做成**页内标签栏**（手机是"当前视图名 ▾"下拉 → 管理视图）。
8. 忘记分组结构是「空间页面 / 个人页面」两级，而不是一锅平铺。
9. 把"单击单元格"做成进入编辑（桌面是**单击选中、双击编辑**）。
10. 把"视图删除"做成行内按钮（三端都在**视图设置面板底部**，且带确认弹窗）。
