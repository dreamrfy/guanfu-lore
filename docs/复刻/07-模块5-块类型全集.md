## 1. `/` 菜单（桌面）全量清单 ⭐ 本模块核心成果

**形态**：编辑器内输入 `/` → 悬浮面板（宽约 278，高约 305 可视，内容可滚动 ~5000px 即全量很长）。每组有**分组标题**（12px 灰字）；每项 = **图标 pill（20×20 圆角灰底）+ 名称 + 右侧灰色斜杠快捷码**（如 `/zw`）。键盘 ↓ 可遍历（虚拟滚动），首项默认高亮。**支持输入过滤**（输入块名搜索）。

**条目计数**：约 **100 种**入口（含"XX页面"变体——在同一块位置建子页面型数据视图）。另菜单底部有「**转换为**」分区（= 右键菜单转换面板的镜像，见 §4）。

**与手机端差异**（对照 09 号证据）：手机两列网格只展示**常用子集**（正文/待办列表/页面/引用页面/标题1/标题2…），支持搜索输入全部类型；桌面是全量单列 + 分组 + 快捷码。→ 复刻时手机可保持两列网格子集 + 搜索达全量。

## 4. 交互与行为记录

1. `/快捷码` 精准命中类型（如 `/h1`）——输入码时菜单实时过滤。
2. `/` 菜单回车选中后**光标留在新块内**可直接输入内容。
3. 观测中发现：连续插入时新块有时插在光标块**之前**（对"末块插入"的操作顺序敏感）——复刻时注意"选中块后输入 / 应在该块**下方**插入新块"的语义（FlowUs 实际是**替换当前块**类型为菜单选中项；空块时表现为插入）。
4. 删除页面：行右键「删除」→ **无确认弹窗**，直接进回收站；页面顶部出红色横幅「🗑 当前页面已删除 + 恢复 + 彻底删除」（44 号证据）。**子页被连带删除**（删除父页时整棵子树进回收站）。
5. 新建子页浮层（42 号证据）：侧栏行「＋」→ 类型选择 = 页面（↵）/ AI 写作 / 文件夹 / 思维导图 / 模板 / 导入 + 多维表区（表格/看板/画廊/目录/时间轴/日历）——**桌面也有类型选择**（此前模块 1 记录手机专属四选一，桌面实际更多项）。
6. 回收站入口在侧栏底部「更多」弹层内（y=734 行）。

## 6. 实现落点（观复的栈）

- **块引擎**：BlockNote 原生支持 正文/标题1~6/待办/项目/编号/引述/代码/图片/表格/分割线 等；需**自扩**：着重块（callout）、折叠列表（details）、简单表格、网页书签、行内公式/日期/人员、分割线样式。
- **`/` 菜单**：BlockNote 自带 slash menu 可定制分组与快捷码——照录 FlowUs 分组结构 + 快捷码（观复可保留自家快捷码）。
- **右键菜单/转换为**：BlockNote 的 BlockColors/替换 API；颜色面板需自做（未取形态，重做时补采）。
- **媒体上传面板**：观复走自己的资产链路（assetId），面板形态照 FlowUs（上传/引用两页签）。
- **页面删除横幅**：红色横幅 + 恢复/彻底删除按钮 + 回收站页——观复有回收站需求（软删除），交互照此。
