- 证据：`ops/观测/专项/flowus-styles.json`（FlowUs transition 实测）、`app/src/styles/index.css`（现有过渡）、`app/src/shell/*`（交互实现）

## 1. 结论摘要

1. **五档时长**：80（微反馈）/120（hover）/160（菜单/展开）/240（抽屉）/320（页面）；默认 160。
2. **三条曲线**：标准 `cubic-bezier(.2,0,0,1)`、进入 `cubic-bezier(0,0,.2,1)`、退出 `cubic-bezier(.4,0,1,1)`；只有拖拽落位用轻微 spring。
3. **只动 transform / opacity / color**；不动 width/height/top/left（除非用 grid-template-rows 做展开）。
4. **焦点环不做过渡**：键盘用户需要立即看到；`focus-visible` 直接出现。
5. **不做“到处都在动”**：同一屏幕同时最多 2 处动效；列表项不做逐项入场。
6. **减少动效优先**：`prefers-reduced-motion: reduce` 下全部降到 0.01ms，保留状态变化，不做位移/缩放。
7. **主题切换 200ms 颜色过渡**，但不高亮全屏；图片/封面不参与。
8. **AI 流式输出不逐字动画**：只显示光标/进度，文字直接出现，避免阅读干扰。

## 3. 时长与曲线

| Token | 值 | 用途 |
| --- | --- | --- |
| `--gf-duration-instant` | 80ms | 按下、勾选、微反馈 |
| `--gf-duration-fast` | 120ms | hover、颜色、图标切换 |
| `--gf-duration-base` | 160ms | 菜单、popover、展开、tab |
| `--gf-duration-slow` | 240ms | 抽屉、右栏、底部面板 |
| `--gf-duration-page` | 320ms | 页面切换、路由 |
| `--gf-ease-standard` | `cubic-bezier(.2,0,0,1)` | 大多数 |
| `--gf-ease-enter` | `cubic-bezier(0,0,.2,1)` | 进入 |
| `--gf-ease-exit` | `cubic-bezier(.4,0,1,1)` | 退出 |
| `--gf-ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 拖拽落位、开关 |

规则：退出比进入快一档（如 160 进 / 120 出）；不要所有场景都用 300ms。

## 5. 交互状态机

所有可交互组件至少定义以下状态：

| 状态 | 视觉 | 触发 | 备注 |
| --- | --- | --- | --- |
| default | 默认 | — | — |
| hover | 底色 `--gf-bg-hover` | 指针 | 触摸设备不依赖 |
| active/pressed | 底色加深 / scale .98 | 按下 | 80ms |
| focus-visible | 2px 主色环 + 2px offset | 键盘 | 不用鼠标时出现 |
| selected | 底色 `--gf-bg-selected` + 主色文字/边 | 选中 | 持久 |
| disabled | 文字 `--gf-text-disabled`，无 hover | 禁用 | `aria-disabled` |
| loading |  spinner/骨架 + 文字“处理中…” | 异步 | 禁止重复提交 |
| error | 危险色边框 + 图标 + 文案 | 校验失败 | 不用抖动 |
| success | 成功色图标 + 160ms 淡入 | 完成 | 2s 后可消退 |
| readonly | 无边框/浅底，文字正常 | 只读 | 仍可聚焦复制 |

### 5.1 按钮

- primary：底 `--gf-primary`，字白；hover `--gf-primary-hover`；active `--gf-primary-active`。
- secondary：底透明，边 `--gf-border-strong`；hover 底 `--gf-bg-hover`。
- ghost：无底无边；hover 底 `--gf-bg-hover`。
- danger：底 `--gf-danger`，字白；hover 加深 8%。
- 禁用：透明度不降低到 0.4（会看不清），用 `--gf-text-disabled` + `--gf-bg-sunken`。

### 5.2 菜单/弹层

- 打开：先计算位置，再加 `data-open`，避免从 (0,0) 飞入。
- 关闭：点击外部、Esc、选择项；关闭后焦点回到触发器。
- 嵌套菜单：父菜单保持，子菜单 120ms 进入；不要同时关闭父菜单。

### 5.3 加载

- <300ms 的操作不显示 spinner（避免闪烁）。
- >300ms 显示；>3s 加“仍在处理…”；>10s 给取消。
- 骨架屏用于首屏/列表；不用整页 spinner。
- 按钮 loading 时保留宽度，图标替换为 spinner，文字可保留。

### 5.4 错误/成功

- 错误：红色图标 + 文案 + 解决动作；不用 alert；表单错误在字段下方。
- 成功：绿色勾 + 短文案；toast 3s；不要全屏庆祝动画。
- 破坏性操作：二次确认，按钮文字明确“删除页面”，不用“确定”。

## 6. 减少动效

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

- 保留颜色/透明度变化（瞬时），去掉位移、缩放、旋转、视差。
- 骨架屏改为静态浅底。
- 不自动播放视频/GIF；用户点击后才播放。
- 提供应用内开关「设置 → 外观 → 减少动效」，与系统同步。

## 7. 性能规则

- 只动画 `transform` / `opacity`；颜色动画可接受，但避免大面积重绘。
- 需要动画的元素加 `will-change: transform`，动画结束后移除。
- 不在滚动事件里做动画；用 `IntersectionObserver`。
- 列表 >50 项不做逐项入场；虚拟列表。
- 弹层用 `position: fixed` + portal，避免父级 overflow 裁剪。
- 拖拽用 pointer events，`touch-action: none` 仅作用于手柄。

## 8. 三端与全触点差异

| 触点 | 差异 | 处理 |
| --- | --- | --- |
| Windows | 窗口最小化/还原、贴边 | 不做窗口动画；用系统 |
| Web | 路由切换、浏览器后退 | 200ms 淡入；不拦截后退 |
| 安卓 | 系统返回、共享元素 | 共享元素 240ms；返回手势跟随 |
| 扩展 | popup 打开/关闭 | 不做入场；关闭即时 |
| 官网 | 滚动入场 | 只做 1 次 160ms 淡入；不用视差 |
| 安装包 | NSIS 页面切换 | 系统默认；不自定义动画 |

## 9. 落地映射

```css
:root {
  --gf-duration-fast: 120ms;
  --gf-duration-base: 160ms;
  --gf-duration-slow: 240ms;
  --gf-ease-standard: cubic-bezier(.2,0,0,1);
  --gf-ease-enter: cubic-bezier(0,0,.2,1);
  --gf-ease-exit: cubic-bezier(.4,0,1,1);
}
.button { transition: background-color var(--gf-duration-fast) var(--gf-ease-standard),
                      color var(--gf-duration-fast) var(--gf-ease-standard); }
```

- React：用 CSS transition；需要进出场用 `data-state="open|closed"` + CSS，不引入重型动画库。
- 复杂拖拽可用 `@dnd-kit` 自带过渡；落位用 spring。
- 安卓：`animateFloatAsState` / `AnimatedVisibility`，时长 120/160/240；`LocalMotionDurationScale` 尊重系统减少动效。
- 扩展：popup 不做动画；注入按钮 120ms 颜色。

## 10. 迁移影响与验收断言

| 旧值 | 新值 | 影响 |
| --- | --- | --- |
| 通用 120/160 混用 | 五档 | 交互更统一 |
| 无 reduced-motion | 全面支持 | 无障碍达标 |
| 可能存在的 height 动画 | grid-rows | 减少卡顿 |
| 页面切换滑动 | 200ms 淡入 | 更安静 |

**验收断言**：
1. 所有 transition 使用 `--gf-duration-*` / `--gf-ease-*`，无魔法数字。
2. `prefers-reduced-motion` 下无位移/缩放动画。
3. 焦点环无过渡，键盘可见。
4. 菜单/弹层关闭后焦点回到触发器。
5. 动画只涉及 transform/opacity/color（检查 CSS）。
6. 同一屏幕同时动效 ≤2 处。

## 12. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 动效的时长差 40ms，静态图完全看不出来；菜单是“弹出”还是“淡入”、抽屉是“滑入”还是“淡入”、按下是否有 0.98 缩放，只有真的点一遍才知道是否轻快。预览稿要给每个场景一个可重复触发的按钮，并提供“减少动效”开关，用户确认后再改源码。
