## 1. 结论摘要

1. **9 类页面模式**：首页、文档页、多维表、搜索、收集箱、AI、设置、分享只读、回收站；每类给桌面/手机两套骨架。
2. **首页是“继续工作”而非仪表盘**：最近页面 + 快速新建 + 收集箱摘要 + AI 建议，四块足够，不做数据大屏。
3. **文档页三段**：封面/图标/标题 → 正文 708 → 引用区；右侧面板按需出现。
4. **多维表四段**：标题 → 视图页签 → 工具条 → 数据区；记录用右侧面板，不跳页。
5. **空态 = 线稿 96 + 一句标题 + 一句说明 + 一个动作**；不用表情包、不用大面积插画。
6. **内容视觉以“纸墨”为底**：6 套封面渐变、9 色标签、4 色 Callout、32 个线性页图标。
7. **加载用骨架，不用整页 spinner**；离线/错误有独立状态，不白屏。
8. **手机不做桌面缩小版**：底部五项、抽屉、底部面板、卡片式记录。

## 3. 页面模式

### 3.1 首页 / 继续工作

**目标**：3 秒内回到上次的工作，或开始新的一页。

```
┌ 侧栏 228 ┬──────────────────────────────┐
│           │ 下午好，[名字]        28/36  │
│           │ 继续上次，或从空白开始。14/22 │
│           │ ┌ 继续写 ─┐ ┌ 新建页面 ┐ ┌ 剪藏 ┐ │
│           │ 最近页面（列表 5~8 条，行 40）│
│           │ 快速访问（卡片 3 列）          │
│           │ 收集箱摘要（N 条待整理）       │
│           │ AI 建议（1~2 条，可关）        │
└───────────┴──────────────────────────────┘
```

| 区块 | 内容 | 空态 |
| --- | --- | --- |
| 问候 | 按时间“早上好/下午好/晚上好”；无名字则“欢迎回来” | — |
| 继续写 | 最近编辑的 1 页，显示标题 + 摘要 + 时间 | 隐藏 |
| 快速动作 | 新建页面 / 新建多维表 / 剪藏当前页 | — |
| 最近 | 5~8 条，标题 + 图标 + 时间 | “还没有最近页面。” |
| 快速访问 | 3~6 个卡片，图标 + 标题 | “把常用页面放这里。” |
| 收集箱 | 待整理 N 条 + 最新 3 条 | “收集箱是空的。” |
| AI 建议 | 总结最近页/整理收集箱 | 可关闭 |

**手机**：问候 + 3 个快捷按钮（横排 44 高）+ 最近列表；收集箱入口在底部栏。

### 3.2 文档页

| 区 | 规格 |
| --- | --- |
| 封面 | 200px；渐变/图片；右上三按钮 |
| 页图标 | 60px；emoji/线性图标 |
| 标题 | 36/48 600 宋体；placeholder“未命名” |
| 元信息 | 12/18 secondary：创建时间、字数、同步状态 |
| 正文 | 708；16/28 |
| 引用区 | 底部 1px 分隔；折叠；引用列表 |
| 右栏 | 320；属性/评论/AI；默认收起 |
| 顶条 | 48；面包屑 + 分享 + 评论 + ⋯ + 搜索 |

**空文档**：标题下直接显示“输入 / 插入块，或从一篇空白开始。”；不显示大插画，避免打断输入。

### 3.3 多维表

```
标题 36/48
视图页签：表格 | 看板 | 画廊 | 日历 | +    [视图设置] [筛选] [排序] [搜索] [新建]
工具条 44
数据区（表格 36/40 行；看板列 260；画廊卡 220）
底部：+ 新建记录
```

- 列头：13/20 secondary；类型图标 16；菜单（重命名/类型/排序/筛选/隐藏/删除）。
- 单元格：14/22；编辑就地；标签 20 高；日期 2026-11-18；人员头像 20。
- 记录面板：右侧 320；标题 + 属性 + 正文；不跳页。
- 空表：“还没有记录。点右上角「新建记录」开始。” + 新建按钮。
- 手机：视图名下拉；卡片式记录；点开记录全屏；底部动作面板。

### 3.4 搜索 / 命令面板

- 触发：`Ctrl+P`、顶栏搜索、手机搜索。
- 面板：560×480；输入 44；结果分组“页面/多维表/记录/最近”；行 40；高亮匹配。
- 空：搜索历史 + “试试：收集箱、AI 供应商、同步”。
- 无结果：“没找到。换个词试试。” + 清除筛选。
- 键盘：↑↓ 选择，Enter 打开，Esc 关闭；最近搜索可清除。

### 3.5 收集箱

- 桌面双栏：左列表 320（标题 + 来源 + 时间 + 状态），右详情 708（正文/原文/标签/操作）。
- 状态：待整理 / 已归档 / 失败；筛选 + 搜索；批量选择。
- 操作：打开原文、转为页面、加标签、归档、删除、重试。
- 空：“收进来，慢慢整理。” + “去剪藏 / 安装扩展”。
- 手机：列表 → 详情；底部操作栏。

### 3.6 AI

- 右栏或独立页；宽 360~560。
- 顶部：供应商/模型 chip + 新对话 + 历史。
- 消息：用户右/助手左；助手消息支持 Markdown/代码/引用来源。
- 底部输入：多行 44~120；发送/停止；上下文选择（当前页/选中/全库）。
- 技能：操作（改写/总结/提炼）、对话、问答、技能四个页签。
- 空：“问点什么，或让我总结这一页。” + 3 个示例。
- 错误：Key 无效/额度不足/网络；给“去设置”。
- 隐私提示：“内容会发送到 [供应商]。Key 只保存在本机。”

### 3.7 设置

- 桌面：左导航 200 + 内容 640；分节：外观、编辑器、AI 供应商、同步与凭证、剪藏、快捷键、数据与备份、关于。
- 手机：列表 → 子页；底部保存。
- 表单：label 13/20；控件 32；说明 12/18；保存按钮右下；自动保存可选。
- 危险区：删除数据/断开同步，红色边框。

### 3.8 分享 / 公开只读

- 顶栏 56：品牌标 + 页面标题 + “登录/在观复中打开”。
- 内容 708；无侧栏；无编辑工具条；图片可放大。
- 页脚：“由观复 · Lore 创建” + 举报/隐私。
- 密码保护：居中卡片 400；输入 + 进入。
- 失效：居中“这个分享已关闭。” + 返回首页。

### 3.9 回收站

- 列表：标题 + 删除时间 + 剩余天数；行 48。
- 操作：恢复、彻底删除、清空。
- 空：“空，也是一种整理。”
- 确认：清空不可恢复。

## 4. 空态清单

> 统一结构：线稿 96×96（1.5px 描边，墨色 + 朱砂点）→ 标题 18/26 600 → 说明 14/22 secondary → 一个主按钮（可选次按钮）。

| # | 场景 | 标题 | 说明 | 动作 |
| --- | --- | --- | --- | --- |
| 1 | 空页面 | 从一篇空白开始。 | 输入 `/` 插入块，或直接写。 | — |
| 2 | 空多维表 | 还没有多维表。 | 新建一个，把信息排成你看得懂的样子。 | 新建多维表 |
| 3 | 空记录 | 还没有记录。 | 点右上角「新建记录」开始。 | 新建记录 |
| 4 | 空收集箱 | 收进来，慢慢整理。 | 从浏览器或微信剪藏第一篇文章。 | 去剪藏 |
| 5 | 空搜索 | 没找到。 | 换个词试试。 | 清除筛选 |
| 6 | 空 AI | 问点什么。 | 或让我总结这一页。 | 示例问题 |
| 7 | 空同步 | 还没有连接设备。 | 连接后，内容会在设备间同步。 | 连接设备 |
| 8 | 空回收站 | 空，也是一种整理。 | 删除的页面会在这里保留 30 天。 | 返回 |
| 9 | 离线 | 现在离线。 | 内容已保存在本机，联网后会自动同步。 | 重试 |
| 10 | 加载失败 | 这一页没能打开。 | 可能是数据损坏；试试从备份恢复。 | 重试 / 备份 |

**插画规范**：
- 尺寸 96；画布 120；1.5px 圆头描边；主色 `--gf-text-secondary`，点缀 `--gf-accent`。
- 不用渐变、阴影、拟人脸；不用 emoji 代替插画。
- 深色版：描边 `--gf-text-secondary` 提亮，点缀同色。
- 动效：可选 1 次 400ms 描边绘制；减少动效时静态。

### 5.2 页面图标

- 默认 emoji；可选 32 个线性图标（Lucide）：file, book, folder, lightbulb, target, flask, code, palette, music, camera, globe, heart, star, flag, pin, calendar, clock, check, list, table, chart, brain, sparkles, database, archive, inbox, tag, link, lock, key, user, settings。
- 尺寸 60；选中态 64；不使用彩色贴纸。

### 5.3 标签/状态

9 色标签（见 15）：灰/蓝/青/绿/琥珀/橙/红/粉/紫；浅底深字；圆角 4；高 20；12/18。
状态：待整理（琥珀）、已归档（灰）、失败（红）、同步中（蓝）、已同步（绿）。

### 5.4 图表

- 颜色顺序：主色 → 青 → 琥珀 → 朱砂 → 紫 → 绿。
- 网格线 `--gf-border`；坐标 12/18 secondary；不用 3D、不用阴影。
- 图例可点；直接标注优先于图例。
- 空图表：坐标轴 + “还没有数据。”，不画假数据。

### 5.5 图片/媒体

- 圆角 8；最大宽 100%；说明 12/18 secondary 居中。
- 视频 16:9；封面 + 播放按钮 48；不自动播放。
- 文件卡：图标 32 + 文件名 + 大小 + 下载。
- 书签卡：见 22。

## 10. 迁移影响与验收断言

| 旧 | 新 | 影响 |
| --- | --- | --- |
| 纯文字空态 | 线稿 + 文案 + 动作 | 需 10 张 SVG |
| 首页无“继续写” | 最近编辑卡 | 需查询最近 |
| 多维表跳页编辑 | 右侧面板 | 需面板组件 |
| 整页 spinner | 骨架 | 需骨架组件 |
| 无离线态 | Banner + 本地保存 | 需网络状态 |

**验收断言**：
1. 9 类页面在 1200/768/375 三档不破版。
2. 10 个空态都有标题、说明、动作（动作可选）。
3. 空态插画 96×96，1.5px 描边，深浅色可见。
4. 首屏骨架 ≤300ms 出现；无整页 spinner。
5. 离线可编辑；恢复后自动同步。
6. 错误页有重试；不显示堆栈。
7. 分享页无侧栏/编辑控件；密码页可用键盘。
8. 手机底部栏 5 项，触摸 44+。

## 12. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 空态是“一句话 + 一张线稿”，但线稿的留白、标题和按钮的距离、插画是 96 还是 120，差一点就像两个产品；首页四块的比例，也只有真的排出来才知道是否像仪表盘。预览稿要把 9 类页面骨架、10 个空态、6 套封面并排展示，用户确认后再改源码。

> 预览入口：`docs/复刻/预览/前端设计对比工作台.html` →「页面模式与空态」分区。
