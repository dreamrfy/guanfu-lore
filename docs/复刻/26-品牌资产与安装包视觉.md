## 1. 结论摘要

1. **现有应用图标是蓝色圆角方块占位**，没有品牌识别；本文件给出可落地的标志方案。
2. **推荐标志「回纹印」**：嵌套回纹 + 中心朱砂点，取“回环、观复、窗”三义；16px 仍可读。
3. **主色 `#2F5D8A`，朱砂 `#B4472E`**；标志只用这两色 + 纸白，不做渐变。
4. **文字标**：“观复”宋体 600 + “Lore”无衬线 500；横排/竖排/单标三种锁定。
5. **应用图标**给 16~1024 全尺寸；Windows 圆角 22%，macOS squircle，安卓自适应前景/背景。
6. **NSIS 安装包改成品牌化五页**：欢迎、许可、位置、安装、完成；暖纸底 + 墨蓝头图。
7. **卸载要问“保留本地知识库数据”**，默认保留；说明数据路径，避免误删。
8. **启动页/更新弹窗/OG 图/GitHub banner** 一次配齐，官网、扩展、安装包同源。

| 项 | 内容 |
| --- | --- |
| 名称 | 观复 · Lore |

| 含义 | 看万物生长，也看它们循环回来；知识不是堆放，是反复观察后的洞察。 |
| 英文 | Lore：口传的知识、学问。 |

## 4. 标志

### 4.1 三个方向

| 方向 | 构成 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **A. 回纹印（推荐）** | 嵌套方形回纹 + 中心朱砂点 | 16px 可读；有“回/窗/观”三义；独特 | 需要精确绘制 |
| B. 观字印 | 朱砂方印 + 白文“观” | 文化感强 | 16px 糊；像文创 |
| C. 书页环 | 打开的书 + 回环箭头 | 直观 | 太常见，像笔记软件通用图标 |

**推荐 A**。回纹是中国传统窗棂/器物边饰，天然表达“回环、重复、观复”；方形又像一扇窗，暗示“观”；中心一点朱砂是“洞察/印记”。它不画具体书/笔/AI，避免品类陈词滥调。

### 4.2 构造

- 画布 1024×1024；安全区 80%。
- 外形：圆角方形，圆角 22%（Windows/通用）；macOS 用 squircle；安卓自适应。
- 回纹：3 圈，线宽 72（1024 画布），圆角接头；开口在右下，形成“回”的入口。
- 中心点：直径 120，朱砂 `#B4472E`；与回纹间距 96。
- 背景：墨蓝 `#2F5D8A`；回纹纸白 `#F7F6F2`；中心点朱砂。
- 小尺寸（16/24）：减为 2 圈 + 点；线宽加到 96，避免糊。
- 单色版：墨蓝底白纹，或白底墨纹；不用灰。

### 4.3 使用规范

| 项 | 规范 |
| --- | --- |
| 最小尺寸 | 16px（简化版）；文字标 24px 高 |
| 清空区 | 标志高度的 25% |
| 横排锁定 | 标 32 + 8 间距 + “观复”宋体 600 22/30 + “Lore”无衬线 500 16/24 |
| 竖排锁定 | 标 48 上，“观复 · Lore”下 |
| 单标 | 仅图标，用于 favicon/扩展/安装包 |
| 背景 | 纸白/墨蓝/深色；深色底用白纹 + 朱砂点 |
| 禁止 | 拉伸、描边、投影、渐变、旋转、换色、加字 |

## 5. 应用图标

| 平台 | 尺寸 | 说明 |
| --- | --- | --- |
| Windows | 16/24/32/48/64/128/256 | `.ico` 多尺寸；圆角 22% |
| macOS | 16~1024 | squircle；留安全边 |
| 安卓 | 48~192dp | 自适应：前景回纹+点，背景墨蓝 |

**小尺寸检查**：16px 下必须能看出“方框 + 中心点”；看不清就减圈，不要加细节。

### 7.4 卸载

- 询问“保留我的知识库数据”复选框，默认勾选。
- 说明数据路径与大小；提供“打开数据目录”。
- 不默认删除用户数据；彻底删除需二次确认。

### 7.5 更新

- 更新弹窗 420×?：“发现新版本 vX.Y.Z” + 更新日志摘要 + “现在更新/稍后”。
- 下载进度 + “重启并安装”；失败可重试。
- 更新源 GitHub Releases；签名校验；失败不破坏旧版本。

## 12. 迁移影响与验收断言

| 旧 | 新 | 影响 |
| --- | --- | --- |
| 蓝色占位图标 | 回纹印 | 全端图标替换 |
| NSIS 默认 | 品牌五页 | 需 BMP 资产与配置 |
| 无启动页 | 480×320 | 需 Tauri splash 窗口 |
| 无 OG | 1200×630 | 官网 meta |

**验收断言**：
1. 16px 图标可辨认“方框 + 点”。
2. 深浅色背景上标志都清晰；单色版可用。
3. NSIS 五页中文无乱码；路径默认当前用户。
4. 卸载默认保留数据；有说明与二次确认。
5. 更新失败不破坏旧版本；签名校验通过。
6. favicon/OG/扩展图标同源。
7. 安装包图标不再是占位蓝色块。
8. 启动页 3s 内进入应用；失败有重试。

## 14. 开发前先做 HTML 预览稿

**在按本文件开发之前，必须先做 HTML 预览稿给用户判断。** 标志在 1024 画布上好看不算数，缩到 16px 的 favicon 还认得出才算；NSIS 头图 150×57 的构图，和官网 1200×630 的 OG 完全是两件事。预览稿要把「回纹印」的 16/32/128/512 四档、深浅底、横排/竖排锁定，以及安装包五页、启动页、OG 图并排展示，用户确认后再导出资产。
