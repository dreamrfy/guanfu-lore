# 05 模块 3 · 导航外壳与多页签（终稿）

- 状态：**已收口**（2026-11-17 本轮补测「页签栏与窗口控制」后收口；少量项标"未取"）
- 基准与约束见 [01-基准与约束.md](01-基准与约束.md)；三端差异见 [02-三端形态差异总表.md](02-三端形态差异总表.md)
- 证据（本地，不进仓库）：`ops/观测/windows/28~32-*`
- 单位：桌面 CSS px（webview 1200×762、外壳 1200×800、dpr=1；系统窗口装饰另占高度，PrintWindow 整窗 1200×800）
- **本轮关键定性**：FlowUs Windows 客户端是 **Electron 双层结构**——
  **外壳层**（file:// 页面，自己画的页签栏 + 窗口控制，CDP 目标 type=page）+
  **内容层**（`<webview>`，flowus.cn 网页，CDP 目标 type=webview）。
  **页签栏不在网页 DOM 里**，网页端（浏览器里的 flowus.cn）**没有页签栏**——这是"桌面客户端"与"网页端"的本质差异。

## 1. 外壳层布局（实测 DOM）

```
BODY 1200×800
└─ #root
   └─ .modern-app 1200×800
      ├─ .integrated-tab-bar  1200×38   ← 页签栏（外壳自绘）
      │  ├─ .left-controls    228×38    ← 导航钮（宽=侧栏宽，视觉上与侧栏连成一体）
      │  ├─ .tabs-wrapper     802×38    ← 页签区（228..1030）
      │  │  └─ .tabs-container（内含 .modern-tab ×N + .new-tab-btn）
      │  ├─ .settings-btn     32×26 @(1030,6)   ← 页签栏右侧 ⋯
      │  └─ .window-controls  138×38 @(1062,0)  ← 窗口控制三钮
      └─ .content-area        1200×762 @(0,38)
         └─ .webview-wrapper.active → <webview class=webview-container>
```

**要点**：内容区从 y=38 开始，高 762；模块 1/2 所有"桌面 1200×762"实测值指**内容层 webview**，页签栏的 38px 叠在其上。
外壳用的也是 Tailwind 风格类名；页签栏是纯 DOM（非原生标题栏），即 **Electron `titleBarStyle: hidden` + 自绘栏**的做法。

## 3. 控件清单（外壳层全部可见控件）

1. 导航 4 钮（后退/前进/主页/刷新）——后退、前进有 disabled 态
2. 页签（favicon + 标题 + 关闭钮）
3. 新建页签钮
4. 页签栏 ⋯（下载管理器 / 网络设置）
5. 窗口控制 3 钮（最小化/最大化/关闭）

**网页端对照**：以上全部不存在。浏览器里 flowus.cn 顶栏直接是页面顶栏（分享/评论/⚡/⋯/搜索），无页签、无窗口控制——模块 1 实测的 48px 顶栏就是网页端的第一屏。

## 6. 三端差异

| # | 项 | 桌面客户端 | 网页端 | 手机 |
| --- | --- | --- | --- | --- |
| 1 | 页签栏 | **有**（外壳自绘 38px） | **无**（浏览器自带） | **无**（单页栈，返回键导航） |
| 2 | 窗口控制 | 外壳自绘 3 钮（46×38 大热区） | 无（浏览器/OS） | 无 |
| 3 | 导航钮（后退/前进） | 页签栏左侧 4 钮 | 无（浏览器自带） | 顶栏 `btnBack` 44×48dp（模块 1 §3） |
| 4 | 多页面并开 | 页签=独立 webview 实例 | 浏览器多标签 | 单页面栈，无并开 |
| 5 | 顶栏起点 | 内容层 y=38 起（顶栏 48 在其下） | 顶栏 y=0 起 | 顶栏 48dp 含返回钮 |

**实现提示（我们的栈）**：观复桌面端 = Tauri（WebView2）。对标形态做法：`tauri.conf.json` 里 `decorations: false` + 自绘 38px 页签栏（左 228 导航区 + 页签区 + 窗口控制）；多页签在 Tauri 里可用**多 window/webview** 或**单 window 多 iframe/多 view**——前者贴 FlowUs 的"每页签独立 webview 实例"语义（页面状态互不干扰），推荐前者。网页端（guanfu.app）**不做页签栏**，与 FlowUs 网页端一致。手机端不涉及。
