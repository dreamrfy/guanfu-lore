## 1. FlowUs 侧：网页剪藏的形态（实测）

FlowUs 自己没有"收集箱"概念——剪藏是**浏览器扩展 → 入库到一张多维表**。用户账号里有两张剪藏目标表（都是多维表）：

### 1.1 「网页剪藏」表（61 号证据）

- 页面结构：封面（全宽图 + ✂️ 图标叠放左下）+ 标题 + 视图标签栏（**表格 / 表格 / ＋**）
- **表头字段（官方插件固定结构）**：`No. / 标题 / 标签 / 网址链接 / 创建时间 / 作者`
- 记录 1 条（2026/11/16 21:39），标题单元格为空、有页面图标
- 页尾属性区：AI 生成 / 更换封面 / 调整位置 三按钮（封面 hover 出现）

### 1.2 「微信公众号剪藏」表（62 号证据，信息更全）

- 同一表结构；视图标签栏：**表格 / 时间轴 / 表格 / 1 更多…**（视图工具行：筛选漏斗、排序 ↓↑、🔍、⋯、创建）
- 记录示例的**字段内容形态**：
  - **标签 chips 三色**：`微信`（灰底）、`链接`（灰底）、`公众号`（粉底）——单选/多选字段的色板
  - **网址链接列**：完整 mp.weixin.qq.com 长链接**原样多行显示**（不截断、不折叠、可点）
  - **作者列 = 人员字段**：`老猪的AI提效` 橙底 chip（公众号作者名入人员字段）
  - 创建时间：`2026/10/21 11:35`
- 记录交互（实测）：单击标题单元格=选中（蓝框 + 右上角「📖 打开」浮钮）；双击=就地编辑；点左侧 📄 图标=Emoji 选择器（Emoji/Icons/上传/链接 四页签 + 随机选择/清除）——**记录页打开入口在行右键或浮钮，本轮回合未取**（模块 2 已有记录展开页形态）

### 1.3 官方剪藏插件的入口形态（未取，定性说明）

FlowUs 剪藏动作发生在**浏览器扩展**里（Chrome Web Store 官方扩展）：网页上点扩展图标 → 浮窗选择保存位置/标签 → 写入上面两张表。桌面客户端（Electron webview）内**不出现**扩展浮窗——本轮桌面 CDP 环境实测确认。
→ **扩展浮窗的 UI 形态未取**（需要真浏览器装官方扩展；属浏览器环境，与桌面客户端形态无关，重做观复扩展时可参考自家扩展 `extension/` 独立设计）。

## 2. 观复侧现状（代码盘点，非观测）

观复的剪藏链路**已是自建闭环**，与 FlowUs 形态对照如下：

| 能力 | 观复现状（代码） | FlowUs 对照 | 差距 |
| --- | --- | --- | --- |
| 收集入口 | **快速剪藏对话框**（`ClipDialog.tsx`：粘贴 URL → 调本地剪藏服务 → 落「剪藏库」表） | 浏览器扩展浮窗（形态未取） | 入口形态不同：观复是 App 内对话框 + 扩展（`extension/` MV3）双通道 |
| 自动收集 | **服务器剪藏箱**（微信转发 → 企微客服 → 服务端 5 分钟自动收 R2 → 客户端自动导入 `clipBoxAuto.ts`） | FlowUs 无此能力（独有链路） | 观复独有，原位替换商业化槽位 |
| 未读状态 | **收集箱未读角标**（`clipReadState`/`unreadClipCount`，侧栏实时刷新） | 无 | 观复独有 |
| 入库结构 | 「剪藏库」表记录（正文块 + 图片附件 + 原文快照，`clipIngest.ts`） | 多维表记录（标题/标签/网址/创建时间/作者） | **形态差异**：观复剪的是"文章正文页"，FlowUs 剪的是"表里一行" |
| 阅读体验 | 离线快照（断网可读） | 网址链接外跳 | 观复独有优势 |
| 去重 | 同链接直接打开原记录（`findExistingClipRecord`） | 未知 | — |

## 3. 设计要点（观复重做时照抄/保留的部分）

**照 FlowUs 抄的**（进 95% 对照）：
1. 剪藏目标表 = 多维表 + 固定字段列（No./标题/标签/网址链接/创建时间/作者）——观复的「剪藏库」若要对齐 FlowUs 观感，可补一个"剪藏清单视图"（表视图 + 同名列）。**是否采纳待用户拍板**：观复现有"正文页"形态信息密度更高，两种哲学（条目清单 vs 全文页）不冲突，可并存。
2. 标签 chips 三色板、人员字段 chip（橙底）、网址列原样多行——字段渲染细节已在模块 2/5 覆盖。
3. 封面 hover 三按钮（AI 生成/更换封面/调整位置）——属模块 4/页面封面体系。

**观复独有（单独设计稿，不进对照表）**：
- 微信剪藏双通道（App 内粘贴 URL 对话框 + 浏览器扩展）
- 服务器剪藏箱 + 未读角标 + 自动导入
- 离线快照阅读
