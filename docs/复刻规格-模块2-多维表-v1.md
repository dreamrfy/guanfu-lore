## 12. 手机端"字段编辑"的真实路径（结论）

- **没有列头菜单**：点列头（任务/年份/月份/周次）无反应；**长按列头也无反应**（两种输入都试过）。
- 字段编辑走的是另一条路：**视图设置 → 属性 → 点某个字段 → 「编辑属性」面板**（属性名 / 属性类型 / 隐藏 / 删除）。
- 也就是说：**桌面端的"列头下拉菜单"在手机端被替换成"属性列表面板"**——这是三端差异里又一条容易做错的地方（照搬桌面会给手机做一个点不出来的列头菜单）。

## 13. 手机端表格的两种形态（实测）

| 形态 | 表现 |
| --- | --- |
| **空表** | 表体只有「创建记录」+ 每列列尾「统计」；**没有可点的单元格** |
| **有数据的表**（剪藏表） | 移动端是**卡片式行**：`No.` + 标题（长文本截断）+ 标签 + 行尾 `‣‣‣`；点行会展开/进入记录，而不是"点单元格出编辑器" |

> 单元格编辑器（点单元格弹浮层）在本轮**没有抓到**：空表没有格子，有数据的表点行变成"展开记录"。下一批改从**桌面端**取（桌面是标准网格，DOM 可读，单元格/列头菜单都能拿到）。

## 14. 视图删除与副作用（如实记录）

- 视图编辑面板底部的**「删除」在自动化下点不动**（点中心、点右侧、先收键盘都试过，面板无变化）。
- **副作用**：一次误触把我在观测中新建的「画廊」视图**重命名成了 `%`**（视图行支持就地改名，我误操作触发了它）。
- 因此你的「学习进度」表里现在多了两个视图：**`%`**（原画廊）与 **`时间轴`**。都请手动删除（管理视图 → 点该行右侧按钮 → 面板底部「删除」）。
