## 二、第一批要做的（按动手顺序）

### 第 1 步 · 地基（先做，因为它决定后面一切）

- **技术栈搭建**：Tauri 2 + React + BlockNote；一套代码出桌面端与网页端
- **本地数据库**（SQLite）+ 数据结构：页面 / 块 / 表 / 字段 / 记录 / 视图配置
- **自托管服务端**（你的 VPS）+ **对象存储 R2**
- **自动备份与恢复**（含"删掉几条 → 从备份恢复"的验证）
- **应用外壳**：侧栏、标签条、顶部工具条、右侧面板、浅深色主题、字体切换（开源字体）、图标切换（Iconify）
- **基础设施**：部署、升级与数据迁移、日志与诊断、安全（HTTPS + 登录）

### 第 2 步 · 编辑器（产品的心脏）

- 页面、侧栏页面树、页面树操作、标题、图标、封面
- 块类型：段落、标题、列表、待办、折叠、引用、着重文字、代码块、分割线、图片、视频/文件、书签、简单表格、多维表块
- 块的操作：斜杠菜单、块菜单（六点手柄）、拖拽、颜色面板、块转换、Markdown 输入快捷、快捷键、撤销重做
- **内容安全**：自动保存（验收 = 强杀进程重开内容还在）、回收站
- 连接：@提及、反向链接与底部引用条、页面模板
- **高亮与批注**（原文划线 + 我的批注）

### 第 3 步 · 表格与检索

- 多维表：字段类型、组合筛选、排序、分组、视图栏、记录页（右侧面板 + 整页形态）、原文只读 + 我的想法
- 全局搜索、全局标签、收藏置顶、主页

### 第 4 步 · 剪藏

- **微信转发通道**（企业微信）+ 入库去向配置 + 入库回执
- 粘贴链接入库、浏览器扩展剪藏（整页/选区）、网页划线高亮
- 来源解析：**公众号**（正文+图）、**B站**（yt-dlp，标题/封面/字幕）
- **内容留存**：原文离线快照、图片下载与备份（R2）
- 流水线：去重、失败重试、入库状态、未读/已读、**收集箱/未读队列**、批量操作
- **快速捕捉入口**（全局快捷键/悬浮窗）、本地文件导入

### 第 5 步 · AI

- **供应商网关**（LiteLLM 自托管）：多家 + 自定义供应商、模型选择、密钥安全、成本与用量统计、内容外发开关
- 交互入口：侧边对话、全局对话、选区工具条（改写/续写/翻译）、整篇工具条（总结/提炼）、空格唤起、斜杠 AI 命令、记录页 AI 面板
- **Skill**：添加/启用/停用/手动选用（采用 Agent Skills 开放标准）
- **MCP**：服务器管理、授权、工具调用、调用过程可见、写操作确认
- 结果落地：单独存放 → 采纳插入正文、重新生成、生成历史
- 批量：AI 状态字段（可筛选）、批量生成、后台任务队列

### 贯穿各步

- 输出：导出 Markdown、整库导出备份、复制为富文本、单条记录导出
- 流程纪律：**交付时分开标注「界面完成」与「功能已实装（点下去数据真的变）」**

## 五、验收原则

1. 每条功能按《需求清单与部件树》里写的「③ 你怎么验收」执行——**点不下去或数据没变 = 不算完成**。
2. 有几条是"照妖镜"级验收，必须真跑：
   - 自动保存 → **强杀进程**后重开内容还在
   - 图片与原文备份 → **断网**打开图还在
   - 备份恢复 → 删数据后能从备份还原
3. 交付说明里**分开写**「几何/界面已对齐」与「功能已实装」，不混为一谈。
