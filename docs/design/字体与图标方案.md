## 1 中文字体：三端可用性与授权

### 1.1 系统字体（各端自带，0 成本 0 风险）

| 端 | 默认中文黑体 | 授权状态 |
| --- | --- | --- |
| Web（桌面浏览器） | Windows=微软雅黑 / macOS=苹方 / Linux=Noto Sans CJK | 随系统授权，**页面只引用不嵌入**即无风险 |
| Android | Noto Sans CJK（思源黑体同源）系统内置 | 随系统授权 |
| Windows 桌面程序 | 微软雅黑 | 随 Windows 授权（**不可打包再分发**） |

**要点**：字体声明为系统栈引用（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），不嵌文件——体积 0、授权 0 风险，与草图观感一致（草图就是系统栈渲染的）。

**红线（行业维权案例）**：把**微软雅黑**打进安装包/服务器再分发 = 授权违约（雅黑版权在方正，微软授权只覆盖 Windows 内使用，方正历史维权案例多）。任何"字体文件随包分发"的方案必须逐字库核对授权。

### 1.2 可嵌入的开源中文字体（若要跨端一致观感）

| 字体 | 授权 | 特点 | 体积代价 |
| --- | --- | --- | --- |
| 思源黑体 Source Han Sans | SIL OFL 1.1 | 跨端完全一致；7 字重；与安卓系统字体同源 | 全字集约 8MB/字重；woff2 子集化后 1–3MB/字重 |
| 思源宋体 Source Han Serif | SIL OFL 1.1 | 标题/引文可选宋体增质感 | 同上 |
| MiSans（小米） | 官方"免费商用"声明（允许应用内嵌） | 可变字重单文件、观感现代 | 单文件约 6–9MB |
| HarmonyOS Sans | 官方免费商用声明 | 与鸿蒙生态观感一致 | 同量级 |
| 霞鹜文楷 LXGW WenKai | SIL OFL 1.1 | 手写楷体感，适合"个人知识库"的温度感 | 9MB+ |

### 1.3 推荐与备选

- **主推：系统字体栈**（§1.1）——0 风险 0 体积，与草图一致；各端渲染差异靠字阶 token 兜底
- **备选 A：嵌思源黑体**——追求三端像素级一致时再考虑（接受子集化后 1–3MB/字重代价）
- **备选 B：MiSans 可变字体**——想要更现代观感时（注意其"免费商用"是官方声明而非 OFL，**授权声明原文要存档留底**）
- **不推荐**：iconfont 上来路不明的免费字体；任意"免费下载"字体站的文件

### 1.4 授权注意事项清单

1. 微软雅黑：随 Windows 使用无风险，**嵌入分发违约——不做**
2. 苹方：Apple 平台系统字体，同样**不可嵌入再分发**
3. 思源系列（OFL）：可嵌可改可分发；需**随分发附带 OFL 许可文本**（进仓库反而是合规做法），改名需避开保留名
4. MiSans / HarmonyOS Sans：官方免费商用声明，**保存声明原文留底**，留意条款更新
5. 霞鹜文楷（OFL）：同思源，可放心嵌入
6. 任何嵌入方案，上线前把授权文本与出处链接归档（可进仓库）

## 2 图标：矢量图标库 vs 自绘

### 2.1 对比

| 维度 | 图标库 | 自绘 |
| --- | --- | --- |
| 一致性 | 同源风格统一 | 依赖作图水平，易波动 |
| 覆盖面 | 数千个，覆盖 99% 需求 | 只画用到的 |
| 授权 | MIT/ISC/Apache 清晰 | 无风险但耗时 |
| 定制 | 描边宽/尺寸统一可调 | 完全可控 |
| 维护 | 上游持续更新 | 全靠个人 |

### 2.2 推荐

- **主推：Lucide（ISC 授权）**——线性 1.5–2px 描边风格与草图一致（token §5"线性图标 1.5px 描边"），覆盖面广，可按需引入
- **备选：Material Symbols（Apache 2.0）**——变量字体方案，字重/填充可调，Google 维护
- **备选：Tabler（MIT）**——同类线性风格，更几何感
- **自绘**：仅当图标库确实缺（如"公众号"专有图标）时补少量自绘，风格对齐 Lucide（24 网格、1.5px 描边）
- **不推荐**：iconfont 平台图标混搭（授权参差、风格不一致）；FontAwesome 免费版（风格厚重，不匹配草图）

### 2.3 覆盖核对：草图所需图标在 Lucide 是否都有

> 核对口径（2026-11-04 审计整改）：原表只抽了 10 个通用图标，却写成"草图所需图标全部覆盖"。
> 现在补查**视图图标**与**属性图标**，并按"已核对项 / 未核对项"分开陈述。

这些不影响"图标库方案成立"的结论，但不能据此声称"草图 100% 覆盖"。

## 3 结论（一句话版）

- **字体**：系统字体栈（0 风险 0 体积），备选思源黑体 / MiSans；**永不嵌入微软雅黑/苹方**
- **图标**：Lucide 为主 + 少量自绘补缺；不用 iconfont 混搭
- P2 开工按此执行；若用嵌入字体，OFL/声明文本随仓库归档
