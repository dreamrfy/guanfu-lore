## 1 颜色用法

### 1.1 主色（蓝 #2563eb）——只给"前进类"动作

| 用在哪 | 不用在哪 |
| --- | --- |
| 主按钮（新建、创建第一篇笔记、再次尝试存档） | 普通信息文字（用 text.primary） |
| 选中态、当前导航项 | 警告/错误（那是语义色的职责） |
| 链接（查看原因、查看进度、打开文章） | 大面积底色（除选中行浅蓝底） |

〔出处：09 主按钮"再次尝试存档"+ 蓝色链接；17 主按钮"创建第一篇笔记"〕

### 1.2 语义色——状态标签与提示卡

| 语义 | 用法 | 出处 |
| --- | --- | --- |
| 绿=完成/可用 | 标签（已完成、已存档、已读）+ 提示卡（离线可用，绿底+√） | 06、09、10 |
| 黄=进行中/待验证/需注意 | 标签（存档中、处理中）+ 警示卡（未同步修改已保护、网络断开暂停、未接入/待验证） | 09、10、17 |
| 红=失败/阻塞 | 标签（存档失败、生成失败）+ 失败卡（左侧红竖条+浅红底） | 09 |
| 灰=中性/未开始 | 标签（未读、待验证、未保留） | 06、09 |
| 蓝=阅读中/信息提示 | 标签（阅读中）+ 信息卡（旧版离线可读新版等待下载，左侧蓝竖条） | 06、10 |

**规则**：提示卡一律"浅色底 + 左侧 3px 竖条 + 同系深色字"，不整块高饱和；红只给失败，不用于删除按钮以外的强调。

### 1.3 背景

- 全局 `#f7f6f3` 暖灰白；侧边栏更浅一档；内容区/卡片纯白。
- 悬停 `rgba(0,0,0,.04)`、选中 `rgba(37,99,235,.10)`。
〔出处：01/02 全部页面〕

## 2 文字层级与阅读宽度

| 层级 | token | 用法 | 出处 |
| --- | --- | --- | --- |
| 页面标题 H1 | 20/28 semibold | 每页一个（如"任务与同步"） | 09 |
| 文章标题 H2 | 17/24 semibold | 阅读面板标题、列表行主文字 | 02、06 |
| 区块标题 H3 | 15/22 semibold | "文章快照""AI 解读"分区 | 02 |
| 正文 | 14/22 | 表格单元格、简介列表 | 01、06 |
| 辅助 | 13/20 | 来源+时间（"云原生手记 · 11/02 收藏"） | 06 |
| 标签/说明 | 12/18 | 状态标签、底部设计注释 | 09、10 |

- 阅读宽度：正文阅读区 **44em 封顶**（02 侧边阅读、06-B 文章页）；表格视图全宽不受此限（01）。
- 辅助信息一行放下就一行（"正文与图片存档"），放不下换行不加省略号的场景：失败原因必须完整展示，**不用 ellipsis**（09 失败原因原文完整可见）。

## 3 列表与卡片密度

- **表格行高 44px**：主文字 14px + 上下各 12px；一行一条剪藏，不双行卡片（01）。
- **移动端列表**：同一数据换布局不换密度——标题一行（长则两行截断），右侧只留状态标签（06-A：标题+阅读状态两列，其余列横向滚动）。
- **卡片**：内边距 16px，卡片间距 12px；提示卡内边距 12px（09、10）。
- **任务列表**（09）：主标题 + 副行（阶段说明）+ 右侧标签 + "查看原因"链接，四元素固定位置，行间用 1px 分隔线不用卡片堆叠。

---

## 4 留白与分组

- 页面级留白：内容区左右 24px 起；卡片内 16px；元素间距 4 的倍数（8/12/16/24）。
- **分组靠空隙不靠框**：侧边栏"我的页面"组与"任务与同步/回收站/设置"之间只用空隙+分组标题，不画分隔框（01、09 侧栏）。
- 相关操作相邻：主按钮+次按钮并排（"再次尝试存档"+"查看原文"，09），间距 8px。
- 底部注释区：与内容区留 32px，用 ①②③ 圆圈编号 + "原则标题 + 一句解释"的形式（每张草图底部通用模式）。

## 5 状态与标签系统（全局唯一口径）

| 状态词 | 样式 | 说明 |
| --- | --- | --- |
| 已存档/已完成/已读/离线可用 | 绿 | 成功要具体到阶段（09 注①：收到链接≠存档成功） |
| 存档中/下载中/处理中 | 黄 | 进行中的用词带"中" |
| 存档失败/生成失败 | 红 | 必须配"查看原因" |
| 未读/待验证/未保留 | 灰 | 未开始的事不用警示色 |
| 阅读中 | 蓝 | 唯一用蓝的状态，与主色同源 |

**开关表示意愿，状态表示结果**（10 注①）：开关打开≠已离线可用；"下载中 12/18 项"用进度条+计数，完成后才显示绿色"离线可用"。

## 6 空状态与加载态

草图明确"不共用'暂无数据'"（17 注③），分场景：

| 场景 | 样子 | 出处 |
| --- | --- | --- |
| 空资料库 | 提供新建/导入入口的引导卡（"创建第一篇笔记"），不是一句话空白 | 17 |
| 筛选无结果 | 提供"清除筛选"动作，文案区别于空库 | 17 注③ |
| 首次配置失败 | 保留已填内容，文案写下一步，不让用户重来 | 17 注③ |
| 正在下载 | 进度条 + n/m 计数 + "完成后才显示离线可用"的说明 | 10-A |
| 断网下载暂停 | 黄底警示卡"保留已下载进度，联网后继续"，不报错样式 | 10-A |

## 7 错误提示样式原则

1. **失败必须三件套**：红标签 + 失败原因原文 + 下一步动作（"再次尝试存档"）——只显示"失败"二字不合格（09）。
2. **失败说明与下一步分开**："验证、限流与删除不是一回事；不确定的原因明确说不确定，不承诺重试能解决"（09 注②）。
3. **部分成功不许标全局成功**：正文与图片已存但 AI 失败 → "生成失败"标签 + "正文与图片已存好，仍可正常阅读"（09 第二行）。这与服务端 SNAP-02（图片失败只能 partial 不标 complete）口径一致。
4. **AI 失败不砸原文**：AI 重试不覆盖已有快照与历史版本（09 注③）。
5. **保留记录**：再次失败仍保留这条记录，不显示"收藏成功"（09 右栏）。
6. 不弹全屏错误对话框；错误就地显示在所属卡片/列表行。

---

## 8 移动端特殊规则

- **不是把桌面版缩小**（06 注①）：同资料同视图，触屏编辑用面板，其余列横向滚动且标题列保留。
- **先同步简介，再按需读全文**（06 注②）：目录摘要≠全文下载；AI 解读、快照、属性分开查看。
- **完成下载才叫离线可用**（06 注③）：下载中必须单独提示；未同步的个人修改不能被清理。
- 触屏目标：状态标签、Tab、开关高度 ≥ 32px；表格横向滚动要有可见提示（06-A 底部"← 横向查看其他列"）。
