## 1 颜色

### 1.1 背景

| Token | 值（目测） | 用途 |
| --- | --- | --- |
| `bg.app` | `#f7f6f3`（暖灰白） | 应用最外层背景 |
| `bg.sidebar` | `#fbfaf7`（比 bg.app 更浅） | 左侧页面树 |
| `bg.content` | `#ffffff` | 内容区 / 表格 / 阅读面板 |
| `bg.hover` | `rgba(0,0,0,0.04)` | 列表/树节点的悬停态 |
| `bg.selected` | `rgba(29,78,216,0.10)` | 当前行/选中节点（浅蓝） |

> 交互态说明（2026-11-04 整改）：hover/selected 会叠在 `bg.app`/`bg.sidebar`/`bg.content` 上形成“合成底”，
> 文字对比度必须在合成底上重算。实测后 `text.secondary` 调深为 `#5c6670`、`primary` 调深为 `#1d4ed8`，
> 现在 84 个组合最低 4.56（脚本：`scripts/wcag-contrast.mjs`）。

### 1.2 主色与交互色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#1d4ed8`（蓝） | 主按钮（新建）、选中态、链接 |
| `primary.hover` | `#1e40af` | 主按钮悬停 |
| `text.link` | `#1d4ed8` | 正文内链接 |

> 主色由 `#2563eb` 调深为 `#1d4ed8`：原值在 selected 合成底（`#e9effd`）上只有 4.49，低于 4.5 红线。
> 主按钮仍是白字，白/`#1d4ed8` = 6.70，比原来更稳。

### 1.3 语义色（状态标签，浅底 + 深字）

| Token | 底色 | 字色 | 用途 |
| --- | --- | --- | --- |
| `status.saved` | `#e8f5e9` | `#2e7d32` | 已存档 |
| `status.generated` | `#e8f5e9` | `#2e7d32` | AI 已生成 |
| `status.reading` | `#e3f2fd` | `#1565c0` | 阅读中 |

| `status.neutral` | `#f0efec` | `#616159` | 未读 / 未保留 / 未开始 |

### 1.4 文字

| Token | 值 | 用途 |
| --- | --- | --- |
| `text.primary` | `#1f2937` | 正文 |
| `text.secondary` | `#5c6670` | 辅助信息（来源/时间） |
| `text.disabled` | `#9ca3af` | **仅真禁用控件**（WCAG 对 inactive 控件豁免） |
| `text.placeholder` | `#5c6670` | 输入框/搜索框占位（属普通文字，**不适用禁用豁免**） |

> 占位与禁用拆成两个 token（2026-11-04 整改）：原文档把 `text.disabled` 同时用于“占位/禁用”，
> 只有 2.54 对比度。禁用态有豁免，普通占位没有——拆分后占位文字按普通文字要求 ≥4.5。
> 占位与辅助文字同色时，用字号/字重（13px/400 + italic 可选）区分层次，不靠降低对比度。
