## 7 待定项（需用户或设计确认）

1. 封面占位的渐变配色（草图是暖米色渐变）→ 是否做成“每篇自动取色”
2. 侧边栏与内容区的分界（草图是无边框的底色差）→ 是否加 1px 分隔线
3. 状态标签的字色对比度 → 深色下需复测
4. 中文字重的可用性（600/700 在 Windows 的渲染）
5. （2026-11-04 夜间调整）text.secondary `#6b7280→#656f7a`、status.neutral 字色 `#757575→#616159`：WCAG 实测在应用底/灰底上分别 4.47、4.01，不达 4.5 红线，微调后 4.73 / 5.43（计算见《深浅色主题-v0.1》§2.2/§2.3）
