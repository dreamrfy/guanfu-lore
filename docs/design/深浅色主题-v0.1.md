# 深浅色主题规范 v0.1

- 日期：2026-11-04 夜间整理（2026-11-04 审计整改：补交互合成底、拆分占位/禁用 token）
- 依据：`设计token-v0.1.md`（浅色基线）+ WCAG 2.1 对比度**实测计算**（脚本 `scripts/wcag-contrast.mjs`，非估算）
- 验收口径：正文/辅助文字/占位文字/状态标签 ≥ 4.5:1，**含 hover/selected 合成底**；禁用态豁免（WCAG 对 inactive 控件不要求）

---

## 1 原则

1. **避免纯黑纯白**：深色底用 `#1f1f1e` 系（不是 #000）；浅色内容区保持纯白（浅色下纯白内容区是惯例，不受此条限制）
2. **亮度层级 = 背景抬升**：深色下层级越高越亮（应用底 #1f1f1e → 侧栏 #262625 → 内容区 #2a2a29 → 悬停 #333332）
3. **图片/快照永不反色**：离线 HTML 快照与图片保持原样；深色下不套 filter（必要时 `brightness(.9)` 降刺眼）
4. **状态色"底加深、字提亮"**：语义不变，重新配对
5. **切换用 200ms 颜色过渡**，禁止闪变
6. **红线**：正文/辅助文字/占位文字/状态标签对比度 < 4.5:1 的组合不得上线（禁用态豁免）；
   **判定必须包含 hover/selected 合成底**，不能只测静态底色

### 2.6 图片/代码块/快照的深色处理

| 项 | 处理 |
| --- | --- |
| 图片/离线快照 | 保持原样不反色；必要时 `filter: brightness(.9)` |
| 代码块 | 深色专用配色（底 #262625、字 #e5e5e3），**不套浅色样式的反色** |
| 封面渐变占位 | 深色下换成同亮度差的灰阶渐变 |

---

## 3 切换时机

1. **默认跟随系统**（prefers-color-scheme / 安卓 DarkTheme）
2. **手动三档**：浅 / 深 / 跟随系统，存用户偏好
3. 切换瞬间 200ms 颜色过渡（§1.5）；切换不重建页面、不丢滚动位置
4. 深色下若个别快照/图片刺眼，只做 `brightness(.9)`，**不做全局反色**

---

## 4 已知取舍

- 深色下状态标签对比度全部 ≥5.8，**优先可读性，牺牲与浅色完全相同的色相**
- 浅色内容区保留纯白（与草图一致）；深色内容区比应用底亮一档，靠亮度差分层
- `bg.selected` 深色用 `#60a5fa` 的 **12%** 透明度（原定 16%，实测 16% 时次要文字在选中底上只有 4.31，故降为 12%）
