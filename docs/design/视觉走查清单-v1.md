### 9.1 同步冲突页（11 草图）专属验收项

- [ ] 冲突双方内容都可见（本地 / 云端 并列），不出现"只保留一份且静默覆盖"
- [ ] 明确提供"保留本地 / 保留云端 / 合并"三选一，默认项不隐藏风险
- [ ] 冲突未处理前，相关条目在清单里可见标记（不是只在冲突页可见）
- [ ] 冲突处理结果有回执（"已保留本地版本"），可再次查看历史
- [ ] 断网时进入冲突页不报错，显示"联网后可处理"

### 9.2 备份导出 / 单页导出（16、18 草图）专属验收项

- [ ] 导出范围在点击前可见（全部 / 当前筛选 / 选中条目），不默认"全部"却静默导出部分
- [ ] 导出中显示进度与可取消；取消后不留下半成品文件
- [ ] 文件名规则稳定（含日期与条数），重复导出不覆盖同名旧文件而不提示
- [ ] 单页导出内容与阅读面板一致：图片、表格、失败原因原文完整，不丢图不截断
- [ ] 导出失败走"红标签 + 原因原文 + 下一步"三件套，不弹全屏错误框
- [ ] 断网/空间不足时有明确提示，说明"已完成部分"与"下一步"

### 9.3 AI 配置页（14 草图）专属验收项

- [ ] Key 校验失败时**保留已填内容**，只标红出错字段（17 注③ 同口径）
- [ ] 提供"测试连接"动作，成功/失败都有可读结果，不用转圈代替结论
- [ ] 额度/用量说明与实际计费口径一致，超限时有提示而非等失败
- [ ] 关闭 AI 功能后，已有 AI 结果仍可查看（不因关闭而清空）

1. 每页走查完在页首记"日期+走查人"，全绿才可合并
2. 不合格项记到《真实感差距清单》或新建 issue，**不口头记忆**
