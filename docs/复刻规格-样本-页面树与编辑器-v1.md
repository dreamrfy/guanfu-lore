# 复现规格 · 样本 v1 ｜模块 1：侧栏/页面树 + 页面与编辑器

- 日期：2026-11-16 ｜ 状态：**样本 v2（v1 格式已获认可；本版补齐桌面/浅色/更多面板）**
- 基准：FlowUs **三端**（安卓真机 / Windows 客户端 / 网页端）；Notion 只在两个专项里出场
- 目标：观复三端在**前端表现与交互逻辑**上对齐 FlowUs 95%；只换图标与字体；颜色与文案先记录、后续各自专项对比拍板
- 红线：**不复制 FlowUs 代码**。条目 7「实现落点」写的是"在我们自己的栈里怎么做"

> 本文件按约定**不含 FlowUs 界面截图**（截图/控件树/录屏全部留在本地 `ops/观测/`，不进公开仓库）。

## 0. 这份样本要你验收的三件事

1. **粒度够不够**：每一屏拆到「入口路径 / 布局解剖 / 控件清单 / 交互清单 / 状态矩阵 / 三端差异 / 实现落点 / 观复差距」八段，是否是你想要的细度。
2. **量得对不对**：尺寸是否要精确到 px/dp（本样本给了实测值），还是允许"约等于"。
3. **有没有缺项**：模块内你关心的界面/交互是否在清单里（见 §5 待补清单），要不要加。

## 2. 逐屏条目

### S1 侧栏 / 页面树

**入口路径**
- 安卓：页面视图左下角「☰」按钮 `btnOpenDrawer`；或从屏幕左缘右滑
- 网页/桌面：左侧常驻栏（宽 228），非抽屉
- 观复现状：安卓已是抽屉（结构接近），网页/桌面为常驻侧栏（已是 228 宽，见下）

**布局解剖（实测）**

| 项 | 安卓（px / dp） | 网页（CSS px） | 备注 |
| --- | --- | --- | --- |
| 侧栏宽度 | 794px = **264.7dp** | **228** | 场景不同：手机是抽屉遮罩式，桌面常驻 |
| 行高（页面条目） | 120px = **40dp** | **32** | 手机行高更大（触控） |
| 工作区行 | — | 211×38 @ (8,8)，圆角 **6** | 含工作区头像 26×26（圆角 4） |
| 图标尺寸 | 由行高约束（约 20dp） | 页面 emoji 图标 **18×18** @ x=18 | — |
| 页面名起点 | x=198px = **66dp** | x=41 | 手机缩进更大 |
| 文字字号 | 由控件树不可得（见 §5 待补） | **14px** | — |
| 分组标题字号 | — | **12px**，行高 32 | 分组行右侧两个 20×20 图标（设置/新建） |
| 行右侧按钮 | `iv_more` 108×120px = **36×40dp**，`iv_create` 同尺寸，紧邻拼接 | 20×20 图标 @ x=175 / 195 | — |

**控件清单（安卓，带 resource-id ≤ 实测 bounds）**
- `iv_more`（每行右侧「…」菜单）→ 见 S2
- `iv_create`（每行右侧「+」新建子页）
- `ivTriangle`（子页展开三角）
- `group_title_layout` / `group_title_tv` / `group_expand_iv`（分组行，可点整行）
- `tvWorkspaceName`（工作区名，可点切换）
- 底部固定区：知识库广场 / 模板中心 / 回收站 / 帮助

**交互清单**
- 点行 → 打开页面；点 `+` → 在**该页下**新建子页；点 `…` → 行菜单（S2）
- 点分组行 → 折叠/展开该分组；点分组右侧 `+` → 在该分组下新建根页
- 长按行 → 待测（§5）
- 拖动排序 / 拖入子级 → 待测（§5）

**状态矩阵**：空工作区（无页面）、分组折叠、选中行高亮（安卓 `selected=true` 可读）、只读/锁定页面。

**三端差异**

| 维度 | 安卓 | 网页/桌面 | 采纳口径 |
| --- | --- | --- | --- |
| 形态 | 抽屉 + 遮罩，默认收起 | 常驻左栏，可折叠 | 各自贴合对应端 |
| 行高 | 40dp | 32px | 各自贴合 |
| 行内按钮 | 常显「…」「+」 | 悬停显出 | 手机常显（无 hover） |
| 分组结构 | 「空间页面 / 个人页面」两级 | 同结构 | 一致 |

**实现落点（我们的栈）**
- Web/桌面：现有 `Sidebar.tsx` 已是树形渲染，需补：工作区行、分组头部（含右侧设置/新建）、行内 hover 按钮、行高 32 与字号 14 的 token 化；数据层沿用现有 pageTree.
- 安卓：现有 Compose 抽屉（`MainScreen` 的 `SidebarContent`）需补：工作区行、分组合并、行内「…/＋、子页三角、底部四入口（知识库广场/模板中心/回收站/帮助 → 观复侧按 §「独有功能」方案替换）。

**观复现状差距 + 改动量**：安卓 **L**（抽屉结构要重排 + 行内按钮 + 分组）；Web/桌面 **M**（补齐分组/工作区行与 hover 态）。风险：折叠/展开状态记忆、长按拖拽排序（待观测）。

## 9. 本轮新得到的交互结论（写进护栏）

1. **手机侧栏行「长按」不弹菜单**：长按 1 秒无任何菜单（`ops/观测/android/13-*`），行的所有操作都在右侧「…」里 → 观复手机端**不要做长按菜单**。

4. **页尾引用区在桌面是常驻一行三项**（引用当前页面 / 提及的页面引用 / 引用建议），手机端未见（待补）——我们 A09 的反链面板要按这个结构改造。
