## 已知边界（诚实口径）

- 拖拽仅支持「变成目标页的子页面」（追加到其子列表末尾）；精确插入到某兄弟之间的位置由后续包打磨
- 排序 e2e 用「上移」演示；「下移」与上移同一代码路径（单测覆盖）
- 折叠状态为会话内记忆（不持久化），属 P2-T02「页面打开方式」范畴
