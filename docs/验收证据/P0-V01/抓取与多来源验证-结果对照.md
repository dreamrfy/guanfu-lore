## 5 本轮 4 个实现坑（都会伪装成"抓不到"）

| # | 坑 | 现象 | 正确做法 |
| --- | --- | --- | --- |
| 1 | 正文容器带隐藏样式 | 微信输出 `style="visibility: hidden; opacity: 0; "`，原样保留 → 离线 HTML 打开**正文整块不可见** | 清洗时删掉 `visibility:hidden` / `opacity:0` / `display:none`，并加 CSS 兜底 |
| 2 | URL 参数不能删 | 缺 `chksm` → 302「未知错误」；缺 `from_masonry` → 「参数错误」 | 转发来的 URL 一字不删 |
| 3 | 懒加载图只有 `data-src` | 只替换 `src` 等于没替换，文件仍依赖外部图片 | 优先 `data-src`；无 `src` 时**补 src** |
| 4 | HTML 实体未转义 | `&amp;from=appmsg` 直接请求下载失败 | 先 unescape |

## 6 复现方式

```bash
# 抓一篇公众号文章（输出自包含离线 HTML）
cd E:\dev\tmp\wecom-kf-test
node fetch-article.js "<完整的公众号文章URL>"
# 输出：out\offline_<时间戳>.html  +  out-index.jsonl
```

**脚本内置的安全约束**（对应需求 SNAP-05）：
- 只允许 http/https；解析域名后拒绝环回/私有/链路本地/保留地址（自定义 DNS lookup，校验与连接同一次解析，防 DNS rebinding）
- 自己接管重定向，每一跳都重新校验
- 输出目录与文件名不掺入任何远端内容
- 抓取底线 B 档：常规 UA + 限速 + 可重试，不做破解
