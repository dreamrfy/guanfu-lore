## 需求

模块 M（模板变量 + 全局标签）的真浏览器自验收官：M01 占位符填充 + M02 全局标签 在真实应用里走查取证。

## 走查方式（真浏览器、真 IndexedDB，无 mock——模块 M 不依赖服务端）

`m03-walkthrough.mjs`（playwright-core 连 Chrome for Testing 9223，干净 profile，vite 5173）：

1. **建模板源页**：标题 `日记 {{日期}}`，正文三段（`{{标题}}`、`{{时间}}`、无占位符各一段）→ 侧栏「模板 → 把当前页存为模板」。
2. **用模板新建页**：标题自动变 `日记 2026-11-15`；正文 `日记 2026-11-15 的随手记（日期 2026-11-15）/ 早上 09:36 起床 / 没有占位符的一段`——占位符全部填充、无 `{{` 残留，模板原件（侧栏页 `日记 {{日期}}`）不被改动。
3. **页头标签条**：给新页打「工作」「周报」，chips 正确渲染。
4. **标签统一面板**：侧栏 `＃ 标签` → 计数 `工作(2) 周报(1)` → 点「工作」跨页列出 2 页（会议记录 + 日记 2026-11-15）→ 点页直达。

脚本真跑输出（节选）：

```
[m03] ✓ 源页就绪 ｜ title=日记 {{日期}}
[m03] ✓ 新页标题：{{日期}} 已填 ｜ title=日记 2026-11-15
[m03] ✓ 正文 {{标题}} 已填 ｜ 日记 2026-11-15 的随手记（日期 2026-11-15） 早上 09:36 起床…
[m03] ✓ 无占位符残留
[m03] ✓ 页头 chips = 工作/周报
```

只读复验（走查后重新打开应用）：`TAGS: ["工作2","周报1"]`，`HITS: ["会议记录","日记2026-11-15"]`。

## 单测逮不到的回归（真机走查的价值）

**TagBar 无限重渲染**：M02 初版选择器写成 `s.pages.find(...)?.tags ?? []`——无标签页面每次选择器都返回**新数组引用**，zustand 的 `useSyncExternalStore` 判定快照永远在变 → React "Maximum update depth exceeded"，应用白屏起不来。修法：默认空数组提为模块级常量 `NO_TAGS`，选择器返回 `?.tags`（引用稳定）。**单测测不出来**：store 测试不渲染 React 组件。教训：zustand 选择器内禁止现场造数组/对象，新增组件必须真机过一遍首屏。
