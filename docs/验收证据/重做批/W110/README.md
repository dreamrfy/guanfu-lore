## 面板结构

- 入口：顶栏「分享」图标；页面 ⋯ 菜单「分享页面」也接到同一面板。
- 页签：**公开分享**（选中）｜**邀请协作**（禁用；观复不做协作）。
- 公开分享区：标题 + 说明 + `待接入` 徽章。
- 权限选项：**仅自己**（选中）｜**获得链接的人**（禁用，待 W111/W113 接入）。
- 复制页面链接：真实写入剪贴板（`?page=<id>`），复制后面板收起。
- 底部说明：公开链接与匿名只读页暂未接入。
