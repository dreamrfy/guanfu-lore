## 走查中抓到并修掉的真 bug

**启动竞态空快照**：`startAutoBackup` 在挂载即触发，可能抢在 `hydrate` 写入首篇页面前拍快照——
备出 **0 页空快照**，将来恢复它会清空用户数据。修复：备份前等主库 ready（15 秒兜底跳过本轮）。
点验首轮抓到的正是这个（快照显示 0 页）。

## 边界（诚实记录）

- 备份落在**同一浏览器/WebView 档案**的独立库里：换设备/重装系统不带走（带走的仍是手动导出文件）。
  写本地文件需要桌面端 fs 插件（Rust 重编），列为后续项。
- 服务端 R2 备份未做（本轮范围外），如需要可加 `/api/backup` 复用现有凭证。
