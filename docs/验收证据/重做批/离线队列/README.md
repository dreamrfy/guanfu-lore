# 剪藏失败离线队列 · 验收证据

- 日期：2026-11-22（27 号 §3.1 承诺兑现）
- 实现：
  - `app/src/data/clipQueue.ts`：失败链接入队（localStorage，同 URL 幂等），逐条重试，失败 tries+1，超 5 次出队（死链不堆积）
  - `clipIngest.ts` 增 `processOneQueuedClip`（抓取+入库不打开记录）
  - `ClipDialog`：抓取失败自动入队；显示队列行（条数 + 「立即重试」）；成功后自动消化队列并保留结果消息
  - `ClipButton`：队列数徽章（监听 `gf:clip-queue-changed`）
  - `App.tsx`：启动 5 秒后自动消化上次失败队列（等同步/服务探活稳定）
- 测试：`src/data/clipQueue.test.ts` 4 用例；全量 **292 条全绿**
- 点验：`npm run clip-queue-check` → **PASS**

## 走查中修掉的 UI 问题

手动重试成功后，结果消息原本挂在"队列行"里，队列清空时整行消失 → 用户看不到结果。
改为：有结果消息就保留该行（仅隐藏重试按钮）。
