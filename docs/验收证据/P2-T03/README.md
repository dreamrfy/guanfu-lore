# P2-T03 编辑器基础块（2026-11-08，AI 侧已实测，与 P2-T01/T02 合并验收）

> 验收标准（任务表）：标题、段落、加粗、列表、勾选、引用、分割线；自己写一段带勾选的笔记，打字不卡、光标不跳。
> **结论：六种块全数落地 + 回车拆块真机验证 + 36/36 测试全绿。**

## 交付物

| 文件 | 职责 |
| --- | --- |
| `lib/editor/block_model.dart` | 块模型（六类型）+ 序列化（JSON v1，旧纯文本自动兼容按行转段落）+ Enter 拆分/块首退格合并（纯函数） |
| `lib/editor/markdown_controller.dart` | 加粗渲染控制器：底层文本存 `**标记**`（选中映射不失真），显示层渲染粗体；工具栏包裹动作 |
| `lib/editor/blocks_editor.dart` | 块编辑器组件：每块独立控制器/焦点（键击零重解析=不卡不跳）、块菜单（类型切换/加粗/删除）、勾选交互、分割线渲染 |
| `main.dart` | NoteDetailView 接入：正文 TextField → BlocksEditor，走原防抖保存/草稿链 |
| `test/editor_test.dart` | 10 个专项：序列化往返/旧文本兼容/拆分（标题降级、勾选继承）/合并（含分割线特例）/加粗渲染 |

## 与既有机制的融合

- 保存链完全复用：块变更 → onChanged(序列化) → SaveController 防抖保存 + 键击即时草稿（T05 崩溃恢复对块编辑器依然生效）
- 旧笔记兼容：打开旧纯文本笔记自动按行转段落，内容无损

## 已知边界（诚实口径）

- 段落内不支持换行（回车=新块，FlowUs 心智）；段落内换行需求后续包评估
- 行内样式目前仅加粗（斜体/代码/下划线留待后续）；块拖拽排序待与页面树拖拽体系统一
- 移动端块首退格合并依赖块为空时的删除事件，非空块首退格合并暂为桌面按键路径
