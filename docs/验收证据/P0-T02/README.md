# P0-T02 双技术栈原型对比（2026-11-07）

> 任务包要求：中文输入、1000 行表格滚动、离线读写、Windows 打包四项对比，验收方式为用户各点 2 分钟。
> 结论先行：**推荐 Flutter**（用户实测安卓懒加载表格「很顺很丝滑」；网页端略卡的代价真实存在但可接受，且全量画法本就不用于真实产品）。

## 一、交付物

| 原型 | 位置 | 说明 |
| --- | --- | --- |
| React | `prototypes/react_proto/`（Vite + React 18 + TS） | 网页版，`npm run build` 0 错误，产物 145KB JS |
| Flutter | `prototypes/flutter_proto/`（Flutter 3.47.9） | 网页 + 安卓双端，APK 47.3MB（release） |
| 表格画法开关 | 两者均含 | Flutter 侧可切「懒加载（真实产品做法）/ 全量（最坏情况）」，用于把「组件画法问题」与「平台天花板」分开验证 |

两套原型界面内容一致：① 中文输入 ② 离线读写（localStorage / shared_preferences）③ 1000 行 × 8 列表格。

## 二、实测结果（验收人：用户本人）

| 测试项 | React 网页 | Flutter 网页 | Flutter 安卓（用户真机） |
| --- | --- | --- | --- |
| 网页可用性 | ✅ 一次通过 | ❌→✅ 修两轮才通（见四） | — |
| 中文输入 | 「没有任何问题」 | 未专项反馈 | 未专项反馈 |
| 1000 行·全量画法 | 丝滑（浏览器原生合成兜底） | 有可感卡顿 | **掉帧较重**（v1 实测） |
| 1000 行·懒加载画法 | （React 原生滚动天然按需） | （未重测） | **「很顺很丝滑」**（v4 实测） |
| 离线读写 | 通过（刷新留存） | 通过 | 通过 |
| 首次构建耗时 | 首渲染数百 ms 级 | 慢（引擎启动） | **4 ms**（DataTable 版数据） |

**关键判断：v1 的「Flutter 卡」经 v4 对照实验证伪为画法问题**——同一台手机同一张表，全量 DataTable 掉帧严重，懒加载 ListView「很顺很丝滑」。真实产品只会用懒加载。截图证据：`flutter-安卓-全量画法-v1.png`、`flutter-安卓-懒加载画法-v4.png`。

## 三、对比与推荐结论

| 维度 | React（+Tauri/Capacitor 套壳） | Flutter |
| --- | --- | --- |
| 网页端大表格 | 优（浏览器原生滚动） | 略卡（自绘引擎多一道工序；懒加载后差距缩小） |
| 安卓/Windows | 依赖设备 WebView/系统内核，老旧内核有兼容坑 | **原生渲染，实测真机丝滑**；三端像素级一致 |
| 离线数据 | 经桥接层 | 直连本地存储 |
| 生态与 AI 熟练度 | 优（AI 对 React 更熟，开发略快） | 够用 |
| 部署（国内） | 网页零障碍 | Web 必须本地化引擎+字体（坑已踩平，见四） |
| 包体 | Web 145KB | APK 47.3MB（多架构） |

**推荐：Flutter。** 理由：主力场景（安卓 + Windows）原生性能实测占优；网页端是辅助入口，略卡可接受；三端一致性与直连离线能力是本项目（表格 + 多视图 + 离线优先）的长期收益。代价如实列出：Web 部署需携带本地引擎与字体；包体偏大；开发期 AI 熟练度略低。

## 四、过程中发现并已解决的问题（沉淀）

1. **Flutter Web 国内白屏**：引擎默认从 gstatic.com 下载 → 构建产物自带 `canvaskit/`，bootstrap 配置指向本地即修复（已写入全局记忆）
2. **Flutter Web 文字全空白**：字体不随构建打包、运行时才从 gstatic 拉取 → 从 `gstatic.loli.net` 镜像按运行时请求清单拉取 37 个 woff2 存入 `web/fonts.gstatic/`，构建自动携带
3. **Gradle 内存 OOM（AllocateHeap）**：模板默认 `-Xmx8G -XX:MaxMetaspaceSize=4G`，16G 内存带模拟器跑不动 → `gradle.properties` 压至 `-Xmx2G/1G`
4. **DataTable 全量渲染掉帧**：该组件官方定位仅适合几十行；大表必须懒加载（真实产品口径）
5. **Mimosa 误报**：`source scripts/env.sh` 被判「Bash 写源码」→ 用 adb 全路径绕开
