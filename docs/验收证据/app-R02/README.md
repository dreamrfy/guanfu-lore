## 需求

R01（原文只读 + 想法分区）的真浏览器走查收官：剪藏来源的记录页，原文区不可编辑、想法区可写、切走再回来想法还在。

## 走查方式（真浏览器、真 IndexedDB，无 mock）

`r02-walkthrough.mjs`（playwright-core 连 Chrome for Testing 9223，vite 5173）：

1. **造记录**：新建表格 → ＋新建记录 → 打开记录面板 → 正文输入两段（此时还不是「剪藏库」，正文可编辑）。
2. **改名触发分区**：表改名成「剪藏库」→ 记录面板正文区标签实时变「原文（只读）」，下方出现「💡 想法」分区。
3. **原文只读**：往原文区打字「不该打进去的字」→ 文本纹丝不动。
4. **想法可写**：💡想法区输入「我的想法：这篇值得再读一遍」→ 正常出现。
5. **持久化**：切到别的标签页再回剪藏库重开记录 → 想法还在、原文完好且仍只读。

脚本真跑输出：

```
[r02] ✓ 改名前正文可编辑 ｜ text=这是导入的文章正文第一段…
[r02] ✓ 正文区标签变「原文（只读）」 ｜ labels=["原文（只读）","💡 想法"]
[r02] ✓ 出现「💡 想法」分区
[r02] ✓ 原文区打字无效（只读）
[r02] ✓ 想法可写入 ｜ text="我的想法：这篇值得再读一遍"
[r02] ✓ 切走再回来想法还在
[r02] ✓ 回来后正文仍只读且未丢
```
