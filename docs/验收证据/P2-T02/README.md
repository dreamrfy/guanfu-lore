## 过程中发现并修复

- **分栏关闭后树不刷新**：内嵌模式删除页面后 onClosed 未触发 _reload()，树显示旧快照 → 补刷新（专项回归）
- 库文件/资源目录、python sqlite3 不 close 等坑见 P1-T07/T08 记录
