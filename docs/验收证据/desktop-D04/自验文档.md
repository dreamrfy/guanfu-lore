## 一、逮到并修复的真 bug：更新后不会重启

自验走查 `desktopUpdater.ts` 的完整链路时发现：更新流程最后一步 `relaunch()` 来自
`@tauri-apps/plugin-process`（package.json 34 行有该前端依赖），但 **Rust 侧完全没有这个插件**——
`Cargo.toml` 没有 `tauri-plugin-process` 依赖、`main.rs` 没注册、capabilities 没放权。
运行时表现：下载安装成功 → `relaunch()` 抛错 → 被 `catch` 静默吞掉 → **更新装了但应用不重启**，
用户手动重开才生效。这正是模块自验该逮的接线遗漏。

修复（本任务一并提交）：
1. `app/src-tauri/Cargo.toml`：加 `tauri-plugin-process = "2"`；
2. `app/src-tauri/src/main.rs`：注册 `.plugin(tauri_plugin_process::init())`；
3. `app/src-tauri/capabilities/default.json`：permissions 加 `process:allow-restart`。
