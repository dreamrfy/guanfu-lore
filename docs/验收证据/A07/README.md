# A07 块编辑器二期 · 验收证据

日期：2026-11-16
范围：块拖拽排序、缩进层级、`/` 命令面板（任务表 A07）。

## 做了什麽

- `DocEditor` 由「根层 index」改造成 **path 树定位**（`[0]`、`[0,1]`…），新增
  `indent / outdent / moveTo`，`delete` 遇到有子块的块时把子块提升为同级（不静默丢内容）。
- `PageEditor` 按 `views()` 深度优先渲染子块并逐层缩进；每块底部 `+ → ←`，
  `→` 缩进成上一个兄弟的子块，`←` 从父块提出；左侧 `≡` **长按拖拽**，可跨父级落到目标行前/后。
- 输入框以 `/` 开头时弹出 **块类型命令面板**（10 种：正文/标题 1-3/无序/有序/待办/引用/代码/分割线），
  选中后清掉斜杠并切类型。
- 父块行尾显示「含子块（长按 ≡ 拖拽；→/← 调整层级）」提示。

## 单测

`testDebugUnitTest` 81/81 绿（新增 `DocEditorTreeTest` 10 条）：

- 缩进成上一个兄弟的子块（并落进 JSON children）
- 同级第一个不能缩进；根层不能反缩进
- 反缩进插到父块之后
- 同父级前/后移动（拖拽落点）
- 拒绝拖进自己的子树 / 拖到自己身上
- 跨父级移动
- 删除父块时子块提升为同级（内容保留）
- 嵌套 path 上改字
- 未知块 + 未来字段（futureKey/answer）在移动后原样保留

| 路径 | 结果 |
| --- | --- |
