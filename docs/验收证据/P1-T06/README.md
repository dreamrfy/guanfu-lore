## Windows 图标不可见事件（本包插曲，沉淀）

- 现象：回收站 IconButton 在 Windows release 渲染为空白圈（tooltip 正常），安卓/网页正常
- 排除：换实心图标变体无效 → 非单个字形问题
- 定位：`--no-tree-shake-icons` 构建后图标出现 → **图标树摇在 Windows 构建误裁**（同码点安卓正常，属平台差异）
- 固化：`scripts/build-windows.sh`（--no-tree-shake-icons，代价 +1.6MB 字体）；顺带把 Windows 默认窗口 1280x720→900（窄窗口时 AppBar 动作被挤进溢出菜单的体验问题）
- 连带坑：C++ runner 源文件（main.cpp）写中文被 MSVC GBK 代码页判错（C4819 警告升级错误）→ **runner 源文件保持纯 ASCII**；exe 被占用导致 LNK1104 → 先 taskkill 再构建
