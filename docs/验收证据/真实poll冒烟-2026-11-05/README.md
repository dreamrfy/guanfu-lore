## 发现（2 条，均不阻塞接云）

1. **http:// 公众号链接被白名单拒绝**：真实转发中出现了 `http://mp.weixin.qq.com/...`（来自订阅号消息原始链接）。当前口径「origin 须为 https」将其判为不支持。可选处理：对 `mp.weixin.qq.com` 做 http→https 规范化后再抓（抓取仍是 https，攻击面不变）。**待用户拍板。**
2. **B站封面未落盘**：元数据路径拿到了封面 URL，但没有下载为资源（G1 红线下记录里也不能存完整 URL）。与《接云清单》§6「封面写入记录」的说法有差距，接云时补：封面下载 → 资源落盘 → 记录存 assetId。
