# A04 验收证据 · 笔记列表 + 搜索 + 侧栏

日期：2026-11-16 ｜ 执行：主会话 ｜ 设备：模拟器 `emulator-5554`（Android 14 / API 34）
APK：`android-shell/app/build/outputs/apk/debug/app-debug.apk`（11:0x 版）

## 交付内容

- **主框架**：`MainActivity` 改 `ComponentActivity` + Compose 单 Activity（架构 §4）
- **抽屉侧栏**（`ui/MainScreen.kt`）：全部笔记 / 收集箱（未读-总数）/ 回收站 / 标签 / 页面树
- **页面树**（`ui/PageTree.kt`，纯 Kotlin）：复刻 web `Sidebar.buildTree` 三条边界——
  孤儿页兜底顶层、纯环补末尾、入参顺序即仓库 `sortKey` 顺序（旧页在前、新页在后）
- **标签**：在内存 pages 上归并统计（web M02 同语义），软删页不计入；点标签筛选列表
- **笔记列表**：Room `SELECT ... WHERE deletedAt IS NULL ORDER BY sortKey`，对齐 web
  `db.pages.orderBy("sortKey")`；点击进页面详情占位（子页列表，正文查看器 A05 接入）
- **全文搜索**（`ui/Search.kt`，纯 Kotlin）：标题 + 正文块（含嵌套子块），标题命中排前、
  单页最多 5 条、片段前后 36 字符、命中位置带 start/end 供界面高亮（web search.ts 同语义）
- **收集箱**（`ui/NotesState.kt`）：固定表名「剪藏库」+「状态」单选（未读/已读），
  标题取第一个 text 字段（web clipBox/aiBatch 同语义）
- **回收站**：`deletedAt IS NOT NULL`，按删除时间倒序（恢复/彻底删除留给后续任务）

## 冒烟方式

模拟器无外网（A02/A03 已论证），本任务不依赖网络：用 sqlite3 直接向设备内 Room 库
种入一套代表性数据（父子页、孤儿页、回收站页、标签、剪藏库两条记录），再走界面验证。

种子数据：

| 类型 | 内容 |

| 页面 | 项目笔记（根）→ 设计稿要点 / 会议记录；孤儿页（父级缺失）；8px 标题命中页；已删除的旧页面；A03 冒烟页 |
