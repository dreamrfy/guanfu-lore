上个月中旬领的 Instabox，等邀请码等了一两天才进去。进去一看，免费机给的是 4 核 8G，说实话比我预期大方，我手里那几台小鸡平时也就 1 核 1G、2 核 2G 这么过着。

这台我没拿来建站，建站它也不合适。我干的是另一件事：把 ZCode 装上，再让我的 AI 助手 Muse 直接连着这台机器，晚上的活丢给它俩，我睡觉，早上起来收东西。

先说 Instabox 是个啥

INSTABOX · 免费机规格

它是 InsForge 家的，10 月 14 号才上线，卖点就写在脸上：给 AI Agent 用的云电脑。官网 instabox.sh，拿 Google 或者 GitHub 账号注册。注意，注册完不是当场就能用，是进候补名单，官方把邀请码发到你邮箱里，一般等一两天。我当时就是等了差不多两天，码到了填进去，账号才算激活。

免费机就一种规格，不用挑

激活以后点创建机器，免费的就一种规格，不用挑。几秒钟机器就起来了，Debian 13，root 随便造，Docker 装好了，Node、Bun、Go、Rust 也都在，还带个桌面，浏览器里就能打开看，Chromium 都给你开着。它本来就是用于 Agent 的，官方模板里 Claude Code 和 Codex 都是预装的，你自己的 Agent 连上去就能使唤它。免费额度这块官方说没有累计时长限制，机器只能建 1 台，早期注册的好像能建 5 台，快照能存 5 个。

领之前最好知道的三件事


它会睡觉

闲着 30 分钟没人理，它自己就暂停了。东西不丢，唤醒也快，一秒不到就回来，但你要是打算让它通宵跑活，就不能让它真闲下来，得有东西隔一会儿戳它一下。


没有正经公网 IP

进机器靠它自己的命令行工具，或者把端口发成一个公开链接。想拿它挂网站当 VPS 用的趁早打消念头，方向不对。


免费随时可能变

官方说法是先免费着，收费方案还没想好。翻译一下就是哪天开始收费、或者把免费额度砍了，都不稀奇。所以这台机器我只让它干活，重要文件不往上存，别的机器的钥匙更不可能放它身上。

它就是个工位，不是保险柜。

哦对，国内打开它官网和控制台，我手机是直连不上的，得挂代理。不过机器在境外，它自己往外跑的网倒是不用操心。

ZCode 和晚上这摊事

ZCODE · 夜间额度

ZCode 是智谱给 GLM-5.3 做的编程客户端，我在机器上装的桌面版，v3.16.3，它还自带一个命令行版本，跟桌面版共用一个登录，省事。登录走 Z.ai 全球侧。这边有个活动我觉得是这篇的重点：每天晚上 7 点，客户端左下角头像上头会冒出来一张活动卡片，点一下，领 3 亿个 GLM-5.3-Flash 的额度，当天夜里 11 点到第二天早上 9 点能用。白天领、夜里花，窗口卡得正正好，就是给你通宵跑活用的。

— ZCode 与 GLM-5.3 深度集成

— 长程任务：交给它慢慢跑

每晚 19:00 领 3 亿额度 · 23:00–09:00 夜里用

活怎么派呢，我基本不自己上手敲。举个我真在用的例子：逆向一个 app。睡前把安装包丢进机器，交代清楚要看什么——接口怎么走的、关键逻辑在哪、加没加固——剩下的就不管了。真正烧额度干活的是机器里的 ZCode，一点一点往下啃；Muse 在外头盯着，机器暂停了它给唤醒，任务断了它给续上，进度它都记着，反正就一个要求：这一晚得跑满，别让那 3 亿额度白白过期。早上我起来，它把进度和结论汇总好发我，能接着往下走就走，走不通就当昨晚白忙，没成本。

— 还能远程遥控着干活

适合丢给它的都是这种不着急、但费时间的活。逆向分析、整个项目的测试慢慢跑、一大批文档挨个整理，都行。着急的活别往这上面放，免费机加夜间额度，图的就是个不花钱慢慢磨。
