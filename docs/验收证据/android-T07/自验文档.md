# 观复壳（android-shell）模块自验文档 · T07

日期：2026-11-15 ｜ 执行：看门狗 v4

## 1. 微信两个入口的 intent 过滤

按《手机端入口调研-微信三种路径实证.md》，做路径②③，路径①（URL Scheme）搁置：

### 入口②：微信文章页 → 浏览器打开（VIEW）

- 动作链：微信文章右上角「…」→ 选择「浏览器打开」→ 系统弹浏览器选择器 → 选「观复壳」
- 命中的 intent-filter（`app/src/main/AndroidManifest.xml` MainActivity）：

```xml
<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="http" />
    <data android:scheme="https" />
</intent-filter>
```

- APK 内验证：`aapt2 dump xmltree --file AndroidManifest.xml` 确认 VIEW + DEFAULT + BROWSABLE + scheme http/https 齐备（android-T03/evidence.txt 摘录）。

### 入口③：微信文章 → 分享给朋友/更多（SEND）

- 动作链：微信文章右上角「…」→「更多打开方式 / 分享」→ 选择「观复壳」（text/plain 分享目标）
- 命中的 intent-filter：

```xml
<intent-filter>
    <action android:name="android.intent.action.SEND" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:mimeType="text/plain" />
</intent-filter>
```

- APK 内验证：aapt2 已确认（android-T02/evidence.txt 摘录）。

### 收到后的行为（两入口一致）

EXTRA_TEXT / data 提取链接 → 界面上屏 → 自动 `POST {设置的服务地址}/api/clip` + Bearer →
成功/失败 Toast。服务端按 url 幂等，重复分享不产生重复记录。`singleTask + onNewIntent`，
运行中再次分享不重建 Activity。
