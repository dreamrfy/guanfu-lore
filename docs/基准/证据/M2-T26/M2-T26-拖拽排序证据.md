## 3 没做成的一步（如实记录）

**release 端（真实窗口）的拖拽手势没验证成功**：用合成鼠标消息（`mouse_event` 按下 → `SetCursorPos` 分步移动）截图，
拖拽前/中两张图**逐像素完全相同**（diff bbox = None），说明 `onPanStart` 没被触发。
可能原因：① 合成消息的移动是"跳变"，Flutter 的手势判定没通过；② 窗口没有拿到前台焦点（本脚本没点标题栏激活）。
→ 已拆 **M2-T32**：改用「先点标题栏激活 + 按 20ms 逐步移动 + 每步 1px」或真鼠标复验，并同时验「长按 300ms 后才可拖」。

## 4 与真机的差异（待补采）

真 FlowUs 是**长按**手柄再拖（tooltip 原文「长按拖拽」）。我们这版用 `onPan`（按下即拖），
长按时长没有实测依据（控制器里留了 `kDragLongPress = 300ms` 常量但手势还没用它）→ 已记进 M2-T32。
真机的**指示线样式**（颜色/粗细/是否带圆点）本轮也没抓到：在真机上做"半程拖拽 + 原路放回"时，
DOM 里没找到 1-6px 高的带色横条（截图里也没有明显蓝线）——只用像素扫描找蓝色也没命中 →
所以我们的 2px `#0285FF` 是**按主色推的**，标记为待证实。
