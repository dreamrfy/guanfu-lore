## 1 核对结果：内核有 13 条，但与 FlowUs 有 3 处不一致

内核 `standardCharacterShortcutEvents` 自带字符快捷事件，逐条比对后：

| 转换 | 内核 | FlowUs | 处理 |
| --- | --- | --- | --- |
| `# ` / `## ` … → 标题 1-6 | ✅ | ✅ | 直接沿用 |
| `- ` / `* ` → 项目符号 | ✅ | ✅ | 沿用 |
| `1. ` → 编号列表 | ✅ | ✅ | 沿用 |
| `[] ` / `[x] ` → 待办（未勾/已勾） | ✅ | ✅ | 沿用 |
| **`> ` → 引述** | ❌ 内核认的是 `"` | ✅ `>` | **自写**，并剔除内核那条 |
| **`---` / `***` / `___` → 分割线** | ❌ 内核两个字符就转（`--`/`**`/`__`），会把 `**加粗**` 打断 | ✅ 三个字符 | **自写**三条，剔除内核三条 |
| **行首 ` ``` ` → 代码块** | ❌ 没有代码块组件 | ✅ | **自写** |
| 行内 `**粗**` / `*斜*` / `_斜_` / `~删~` / `` `代码` `` / `--`→破折号 / `[]()`→链接 | ✅ | ✅ | 沿用 |

> 破折号有个联动坑：内核会把 `--` 立刻替换成 `—`，所以敲 `---` 时到第三个横线文本已经是 `—-`。
> 我们这条分割线同时接受 `---` / `—-` / `——` 三种形态（已用断言锁住）。
