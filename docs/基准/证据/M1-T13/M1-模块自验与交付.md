**怎么复跑对照图**（两步，都已脚本化，在仓库外）：

```
# 1) 抓真 FlowUs（1920×945，停在「学习进度」文档页）
node E:/dev/tools/flowus-cap/m1-t13-real.mjs
# 2) 启动我们的 exe → 裁客户区 1920×945 → 与真 FlowUs 并排合成
powershell -File E:/dev/tools/capture_m1t13.ps1
python -I E:/dev/tools/m1-t13-compare.py
```

> **截图链路是新东西，记下来**：Flutter Windows 是 GPU 渲染，`PrintWindow` 要带 `PW_RENDERFULLCONTENT(2)` 才截得到；
> 而且必须**先算非客户区（FRAME 16×39）把窗口调大**、再按客户区偏移（8,31）裁出来，否则图里会出现黑边。
> 另外 PowerShell 变量名**大小写不敏感**——我用 `$h` 当窗口句柄时把高度参数 `$H` 覆盖成了句柄值，
> 第一次就截成 1920×1051622 的废图。

## 3 已知差异（没对齐的，逐条写明，不粉饰）

| # | 差异 | 归属 |
| --- | --- | --- |
| 1 | **主区内容**：真 FlowUs 是数据库表格视图（列头 + 行 + 数据），我们只有占位大标题「无标题」 | M4（多维表）、M2（文档） |
| 2 | **页面自定义图标**：真 FlowUs 里「微信公众号剪藏」是彩色图标、「网页剪藏」是红色剪刀 emoji；我们统一普通页图标 | M2-T11（页面图标） |
| 3 | **字体**：真 FlowUs 用自有字体（`my-quote` 系），我们只声明了 fontFamily、**字体文件没打包**，实际回退系统字体 → 字形与字宽有差 | 新任务 M1-T15 |
| 4 | **AI 行图标**：真的是浅蓝渐变圆脸，我们用了采到的 `IcAiFill`（星形） | 新任务 M1-T15 |
| 5 | **容量卡片图标**：真的是数据库圆柱，我们用了 `IcInfo`（带圈 i）；**升级链接**：真的黑色 `立即升级 >`，我们蓝色 `立即升级 ›` | 新任务 M1-T15 |
| 6 | 侧栏底部真实还有「W 徽标 + 客服气泡」，我们没做（未采到规格） | 新任务 M1-T15 |
| 7 | 图标视觉重量：我们的图标偏黑偏实（跟随 IconTheme 后好一些，但真 FlowUs 的更淡） | 随 #3 字体/图标一并复核 |

> 这 7 条都**不是"看起来差不多"就放过**：1–2 是别的模块的正差（M2/M4 做完自然补上），
> 3–6 已拆成 **M1-T15**，7 随 #3 一起复核。
