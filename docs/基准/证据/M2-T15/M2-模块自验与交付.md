## 2 本模块**装配完成**的东西（这轮新接的）

1. **演示壳接上真实本地库**：启动时 `AppDatabase()` → 取第一页（空库则建「学习进度」并灌演示文档）
2. **保存链接进来**（M2-T14 的 `PageSavePipeline`）：正文改动 → 防抖落库 + 键击即时草稿；标题改动 → 防抖落库
3. **崩溃恢复横幅**：打开页面发现"草稿 ≠ 主库" → 顶部横幅「发现未保存的草稿」+「恢复」/「忽略」；
   恢复写回正文并清草稿，忽略只清草稿（两条都有断言）

### 顺手修了一个真 bug

演示壳原来的 `_snack()` 用 `ScaffoldMessenger.of(context)`，但这个 context 在 `MaterialApp` **之上** →
点工具栏任何一项都会抛 `No ScaffoldMessenger widget found`。改成 `GlobalKey<ScaffoldMessengerState>` 挂到 MaterialApp。
