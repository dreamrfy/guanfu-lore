# M1-T14 缺失图标补采 · 验收记录

日期：2026-11-10　执行者：watchdog 会话

## 1 为什么这 10 个图标之前没有

M0-T15 收割图标时只扫 `[data-icon]` 属性。这 10 个不在这套命名体系里：

| 来源 | 图标 | 原因 |
| --- | --- | --- |
| 侧栏图标行 | 首页 / 头像 / 通知（3 个） | **DOM 里的 `<svg>` 没有 `data-icon` 属性**（只有自研 `path` + Lucide 的 class），收割脚本认不到 |
| 空页类型选择器 | 思维导图 / 看板 / 画廊 / 收集表 / 导入 / 文件夹（6 个） | **必须有"新建空页"才会出现这个面板**，M0 采集时没走到这条路径 |

> 另外 4 个（目录 / 时间轴 / 日历 / 模板）其实已有资产，只是 M1-T12 把它们当"没采到"用了 Material 占位 —— 本轮一并换成实测图标。

## 2 怎么补的（两处都是"抠 DOM 原文"，不是画图）

1. **侧栏 3 个**：图标行是 5 个 32×32 盒子（x=8/53/98/142/187），直接取各自 `querySelector('svg').outerHTML`。
   实测 viewBox：前两个 `0 0 20 20`（自研），后三个 `0 0 24 24`（Lucide）——与 `基准-图标对照` §0 的"两家混用"结论一致。
   这三个**没有 `data-icon`**，名字按语义自命名（`IcHome` / `IcAvatar` / `Bell`），manifest 的 `note` 字段写明了。
2. **空页选择器 6 个**：点「空间」分区行右端的 `＋` → 新建空页 → 面板出现（13 行，**每行都带 `data-icon`**）：
   `IcPageEmpty` / `IcAi` / `IcFolder` / `IcMindmap` / `IcTemplate` / `IcImport` / `IcTable` /
   `IcBoard` / `IcGallery` / `IcList` / `IcTimeline` / `IcCalendar` / `IcFormNew`。
   → 名字直接沿用真 FlowUs 的 `data-icon`，不自己起名。

**用完即删**：为打开选择器新建的那篇空页（`da0824f1…`）已按三步删除法彻底删除，
侧栏复核回到基线 12 项（`学习进度 / 磷化工知识库 / 无标题多维表格 / 配置 / 无标题 / 无标题 / liunx命令 / 网站 / 账号 / 微信公众号剪藏 / 网页剪藏 / 归档历史材料`）。

## 3 落盘与接线

- 9 个新 SVG 同时写入 `docs/基准/图标/` 与 `client/assets/icons/`，并**追加进 `icons-manifest.json`**（92 → 101）
- 重新生成 `lib/design/flowus_icons.dart`（101 个名字常量）
- 侧栏图标行 3 个占位 → 真图标；空页选择器 13 项全部真图标（`_icon` 由 `Object` 收敛回 `String`）
