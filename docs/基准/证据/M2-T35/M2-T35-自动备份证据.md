# M2-T35 证据 · 启动自动备份（事故善后）

日期：2026-11-10　执行者：watchdog 会话（run-1794304640）

## 1 做了什么

- `client/lib/data/database.dart`
  - **修正 `appDbFile()`**：从 `getApplicationSupportDirectory()` 改成 **`getApplicationDocumentsDirectory()`** ——
    必须和 drift_flutter 的默认一致（上一轮就是因为这里写错，误判"库没落盘"）。本机 Documents 被重定向到 `D:\win\文档`。
  - 新增 **`backupDbWithRotation(dbFile, keep: 10)`**：把 `db + -wal + -shm` 一起复制到同目录 `backups/`，
    文件名 `bijiapp.sqlite.<毫秒时间戳>.bak`，按时间戳轮转只留最新 10 组。
    **必须连 wal 一起拷**：drift 的写入先落 WAL（主库经常不 checkpoint），只拷主文件会丢最新数据。
- `client/lib/main_shell.dart`：启动时**在做任何读写之前**先调用备份，并把结果写进 boot 日志。
