## 1 圆角体系（先记住这个，最容易做错）

FlowUs 一共只用 **5 档圆角**，各有明确归属：

| 圆角 | 用在哪 |
| --- | --- |
| **2px** | 徽标 / 只读标签（如「免费版」） |
| **4px** | 下拉菜单项、引用 chip |
| **6px** | **按钮、侧栏项、顶栏工具按钮**（最常用） |
| **12px** | **弹层面板、下拉菜单面板** |
| 9999px | 圆形浮动按钮、开关 |

## 5 侧栏页项（三态）

### 5.1 三态实测（M0-T16 补全，**鼠标移开后测量**）

M0-T05 时"选中态"没测干净（量的时候鼠标还停在项上，量到的是 hover）。M0-T16 重做：**点选后把鼠标移到 (1400,500) 再量**，三态彻底分开：

| 状态 | 背景 | 文字色 |
| --- | --- | --- |
| **常态** | `rgba(0,0,0,0)` 透明 | `rgb(95,94,91)` |
| **hover** | **`rgba(0,0,0,0.03)`（黑 3%）** | `rgb(95,94,91)`（**不变**） |
| **选中** | **`rgba(0,0,0,0.06)`（黑 6%）** | **`rgb(0,0,0)`（变黑）** |
| 未选中对照 | 透明 | `rgb(95,94,91)` |

→ **结论：选中底是 hover 的两倍（6% vs 3%），且文字同时变黑。**
（M0-T05 里"选中底疑与 hover 同为 3%"的猜测**作废**。）

### 5.2 块手柄与「＋」的真实位置与触发区间（M0-T16 新增）

在内容列（x=720、宽 708）左缘做横向扫描（dx = 相对内容列左缘的偏移，往左为负）：

| 鼠标位置 | 出现的控件 |
| --- | --- |
| `dx ≤ -60`、`dx = -40`、`dx ≥ +24` | **都不出现** |
| `dx = -24`、`dx = +12` | **只出现块手柄**（`IcMenu`） |
| **`dx = -12`、`dx = 0`** | **手柄与「＋」都出现** ✅ |

| 控件 | 位置 | 尺寸 | 图标 |
| --- | --- | --- | --- |
| **块手柄（拖拽）** | x=**700**（内容列左外 **20px**）、随所在块 y 走 | **16×16** | `IcMenu` |
| **下方插块「＋」** | x=**698**（内容列左外 **22px**） | **20×20** | `IcBlockAdd` |

- 两者竖直关系：`IcMenu` 在上、`IcBlockAdd` 在下，y 相差约 **14px**
- **热区结论（精确版）**：**手柄的触发带宽 ≈ `dx ∈ [-24, +12]`（宽约 36px）**；**「＋」的带宽更窄，≈ `dx ∈ [-12, 0]`（宽约 12px）**。
  → 实现时两者要**分别设热区**，写成一个宽度会重现"加号点不到 / 乱弹"的问题

### 5.3 键盘焦点环：**基本没有**

按 8 次 Tab 逐个量 `document.activeElement`：

| 元素 | outline | box-shadow |
| --- | --- | --- |
| 侧栏项 | `3px none`（样式为 none） | 无 |
| 顶栏「分享」按钮 | `2px solid rgba(0,0,0,0)` ← **颜色透明** | 无 |
| 另一个按钮 | `3px none` | 无 |
| 若干 DIV | `0px none` | 无 |

→ **FlowUs 基本不显示可见的焦点环**（outline 不是 `none` 就是透明）。这既是"照抄点"（我们也不画），也是它的一处**可访问性缺口**——键盘用户看不到自己在哪。**记录在案，等用户拍板要不要跟。**

元素本身是 `<a data-test-id="aside-item-toc">`，class 里直接写着尺寸答案：

```
rounded-md flex items-center relative h-8 border-transparent group mx-2 border
text-t2-medium text-grey2 space-x-1 pr-2 animate-hover-black3
```

| 项 | 值 | 依据 |
| --- | --- | --- |
| 尺寸 | 211×**32**（`h-8`） | 实测 |
| 外边距 | `0 8px`（`mx-2`） | 实测 + 类名 |
| 右内边距 | `8px`（`pr-2`） | 实测 + 类名 |
| 圆角 | **6px**（`rounded-md`） | 实测 + 类名 |
| 字号 | 14/24/w500 | 实测 |
| 常态 | 底透明、字 `rgb(95,94,91)`（`text-grey2`） | 实测 |
| **hover** | 底 **`rgba(0,0,0,0.03)`** | 实测 + 类名 `animate-hover-black3`（**黑 3%**，不是 6%） |
| 过渡 | **0.1s** | 实测 |

> ⚠️ **选中态未干净分离**：本次鼠标停留在该项上，量到的是 hover 样式。已有旁证（`M0-T01` 证据）显示**选中项文字为 `rgb(0,0,0)`**，底色疑与 hover 同为 `rgba(0,0,0,0.03)`，**但未验证，标为待复核**，不要当结论用。

## 6 开关 / 徽标 / 输入框

**开关**：**30×18**，圆角 9999px，含 1 个滑块子元素。
- 开：底 `#0285FF`（主色）
- 关：底 `rgb(189,189,189)`

**只读徽标（如「免费版」）**：48×22，圆角 **2px**，内边距 `2px 6px`，字 **12/18/w400**，底 `#E5E5E5`、字 `#91918E`。

**输入框**（实测两个样本）：

| 样本 | 尺寸 | 内边距 | 字号 | 边框 |
| --- | --- | --- | --- | --- |
| 空间名输入 | 830×20 | `0 12px` | 14/20 | **无**（`0px`），底透明 |
| 空间域名输入 | 318×30 | `0 8px` | 14/20 | **无**（`0px`），底透明 |

> **重要结论**：FlowUs 的 `input` 自身**没有边框、没有背景**——视觉上的输入框外框由**父容器**提供。实现时不要给 `TextField` 直接画边框，否则会多一圈。

## 8 给 M1/M2 的实现要求

1. **圆角只用 2 / 4 / 6 / 12 / 全圆 五档**，按第 1 节的归属分配。
2. **按钮高度只用 32 / 28**（图标钮另算），主按钮实心主色、次按钮白底 + `#E0E0E0` 描边。
3. **菜单项高 32、面板圆角 12、面板内边距 `8px 0`**；分隔线让行距变 41。
4. **侧栏 hover 是黑 3%**（`rgba(0,0,0,0.03)`），过渡 0.1s。
5. **输入框本身不画边框**，外框交给父容器。
6. 定位元素一律**用 `data-test-id`**，不要用文案（文案会变、也会重名）。
7. 阴影分三档：菜单（5px/8px）、弹层（12px/20px）、圆形钮（用 1px 边框代替阴影）。
