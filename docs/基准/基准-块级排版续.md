## 1 ⚠️ 纠正两处旧结论

### 1.1 「标题 40/64/600」搞错了对象

M0-T04 从样式表里量到 `40px/64px/w600`，我写成了「大标题 40/64」。**实测分清了两个东西**：

| 元素 | 字号 / 行高 / 字重 | 元素高 | 说明 |
| --- | --- | --- | --- |
| **页面大标题（`<h1>`，页面顶部那个）** | **40 / 64 / w600** | **64** | 一行，`x=716` |
| **文档内标题（块 `type=7`，level 1）** | **30 / 45 / w600** | **40** | 18 个样本全是这一档 |
| 正文段落（块 `type=1`） | **16 / 26 / w400** | **21**（文字行盒） | 122 个样本 |
| 次级小字 | 14 / 20 / w400 | 20 | 少量 |

→ **`40/64` 是"页面大标题"，不是文档内的标题块。文档内 level 1 标题是 `30/45/w600`。**
（M2 实现时这两个千万别混：页顶那个 H1 与正文里的 `# 标题` 是**两套字号**。）

### 1.2 正文行高不是恒定的 24，会随**页面布局设置**变

M0-T04 在「归档历史材料」上量到 `16/24`（149 处），本次在「账号」页量到 **`16/26`（122 处）**。

**原因**：页面 ⋯ 菜单里有 **「页面布局：紧密 / 默认 / 宽松」** 与 **「小字号」**（M0-T10 实测到这些项）。
**行高受页面级布局设置影响**，所以「16/24」不是全站常量。

→ **实现要求**：正文行高**不能写死 24**，要按页面布局设置取（默认档在「归档历史材料」实测为 24、「账号」实测为 26，**两页可能用的不同档**）。
→ 待补：把「紧密/默认/宽松」三档各自的 行高/字号 各量一次（已并入 **M0-T27**）。

## 2 块高与列表缩进（实测）

| 块 | 单行块高 | 备注 |
| --- | --- | --- |
| 段落（type 1） | **34** | 与 M0-T19 一致（16/26 行盒 + 上下各 4 内边距 ≈ 34） |
| 标题 level 1（type 7） | ⚠️ **两个数对不上：文字元素 40 / 块容器 34** | 见下 |
| 项目列表（type 4） | **26 / 34 / 36 / 52** | **高度不唯一**（与是否折行、是否含子项有关） |

### 2.1 ⚠️ 标题块高：两个脚本量出了不同的数，**标为待复核**

- `heading-font.mjs`（按文字元素量）：`30px/45px/w600` 的 18 个样本，**元素高 40**
- `blocks2.mjs`（按块容器量）：同一批 `type7/lv1`，**容器高 34**

**两者矛盾，说明我这两个脚本选中的 DOM 层级不是同一个。** 我**不挑一个当结论**——如实标为待复核（并入 M0-T27，那里会用"逐块精确定位 + 逐层记录父子高度"的方式一次定死）。

**可以确定的部分**：标题的**字号/行高/字重 = 30/45/w600**（18 个样本完全一致，两个脚本都读到同一组值）。

**列表缩进**：实测两种 `x` —— **716** 与 **742**，即**缩进 26px** 一档。
→ 列表的缩进台阶是 **26px**（不是 20 或 24）。

## 3 没采到的（如实说明）

| 项 | 为什么没有 |
| --- | --- |
| **空块（空段落）高度** | 他空间里**没有空段落**；要造就得建页（本轮预算内不做，避免又一次建页/删页风险） |
| **标题 level 2 / 3 / 4 的块高** | 「账号」页的 18 个标题**全是 level 1**，没有 2-4 的样本 |
| **引述 / 代码块 / 分割线 的块高** | 他空间里没有这些块 |
| **列表各层级（level）的缩进** | 只采到两档 x（716/742），更深的层级没有样本 |

→ 已拆 **M0-T27**：在**隔离测试页**上（用斜杠菜单造块、造完删页）一次采齐：空块高度、标题 2-4 级块高、引述/代码块/分割线块高、列表 1-3 级缩进、以及**页面布局三档（紧密/默认/宽松）各自的行高与字号**。

## 4 给 M2 的实现要求

1. **页面 H1（40/64/w600）与文档内标题（30/45/w600）是两套字号**，别混。
2. **正文行高按页面布局取**，不要写死 24 或 26。
3. 段落块高 **34**（含上下内边距）；标题**字号是 30/45/w600**，**其块高待 M0-T27 复核后再写死**。
4. **列表缩进台阶 26px**。
5. 列表块高**不唯一**（26/34/36/52），实现时按内容行数算，别取固定值。
