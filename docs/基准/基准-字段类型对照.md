- **`id_number`（自动编号）**：M0-T09 在**数据**里见过这个类型，但「更换类型」菜单的 18 项里**没有对应项**

## 2 「关联」为什么没测到（如实说）

点「关联」后 **类型没有变化**（`formula → formula`）。判断：**关联需要先选"关联到哪张表"**，
大概率弹了一个配置层，而我的 `Escape` 把它关掉了，所以没生效。

→ **`relation` 这个名字是按惯例推的，不是实测**（FlowUs 也可能叫 `relation`/`link`/`ref`）。
已并入 **M0-T29**：单独测关联，连同"关联的配置项结构"一起采。

## 4 方法记录（这套办法值得复用）

```
建空页（侧栏分区 +）
  → 空页会显示「类型选择器」（M0-T06 实测过）
  → 点「表格」→ 得到多维表页（自动带 标题 + 分类 两列）
  → 点「分类」列头 → 菜单里点「更换类型」（data-test-id 可靠）
  → 点目标类型（[data-test-id="勾选框"] 这种）
  → 读 /api/docs/{id} 的 data.blocks[*].data.schema → 拿 type string
  → 循环下一个类型
  → 全部测完：三步彻底删页 + 核对侧栏基线
```

**为什么这条路可靠**（对比 M0-T25 的失败）：**每一步都是"点可见元素"，没有一条依赖键盘输入与斜杠菜单的自动匹配**。
