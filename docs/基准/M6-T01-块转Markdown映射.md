## 3 图片「带出」的实测细节（这条最容易做错）

- **引用全是相对路径**：`![alt](Image.png)` 这种，图片文件与 `.md` 同目录。
- 实测扩展名分布：`png` 585 / `jpg` 251 / `webp` 31 / `gif` 22 / **无扩展名 251**（形如 `import/<uuid>`，
  是"导入型"图片的路径，没有后缀）。
- **文件名会去重加序号**：同目录出现 `Image.png` / `Image 1.png` / `Image 2.png` … `img.png` / `img 1.png`…
  → 重名时以 ` 1`、` 2` 递增（空格 + 数字，在扩展名之前）。
- alt 文本：有的为空（229 处），有的就是原图描述（64–232 字）。
- 包里另有一个 **`未导出的附件.txt`**（38 行）：附件没能导出时列清单，导出器要能产出这个文件。

## 4 文件名/目录名规则（与 `基准-导出格式.md` §3/§4 一致，此处补充实测）

- 根：`<页面标题>+<页面 id>.csv` 与 `<页面标题>+<页面 id>/`
- 记录：`<记录标题>+<记录 id>/`，内含 `<记录标题>+<记录 id>.md` 与该页图片
- **标题里的空格在文件名里变成 `+`**（实测 `04 29 出发…` → `04+29+出发…`）

## 5 本任务没测到的（已拆 M6-T08）

1. **图片块的数字 type**：从记录正文的接口取块类型这次没拿准（接口返回的是库文档），
   所以导出器现在按 `data` 里的图片键（`src`/`url`/`alt`/`fileName`）**识别**图片块，而不是按 type 号。
2. 待办**已勾选**的写法（`[x]`？）：样本里全是未勾选。
3. 代码块的语言行除了 `Plain Text` 还有哪些取值。
4. 简单表格的**表头分隔行**（`| --- | --- |`）是否出现：只数到数据行的竖线数，没确认分隔行。
