## 1 动效体系（全量去重统计，按出现次数排序）

### 1.1 过渡（transition）

| 过渡属性 | 时长 | 缓动 | 出现次数 |
| --- | --- | --- | --- |
| **background-color** | **0.1s** | **ease-out** | **547** ← 绝对主力 |
| background-color, border-color, color, fill, stroke | 0.1s | `cubic-bezier(0.4, 0, 0.2, 1)` | 61 |
| opacity | 0.1s | `cubic-bezier(0.4, 0, 0.2, 1)` | 33 |
| opacity | **0.15s** | `cubic-bezier(0.4, 0, 0.2, 1)` | 18 |
| all | 0.15s | `cubic-bezier(0.4, 0, 0.2, 1)` | 14 |
| all | **0.02s** | ease-in | 12 |
| all | 0.2s | `cubic-bezier(0.4, 0, 0.2, 1)` | 2 |
| all | 0.5s | `cubic-bezier(0.4, 0, 0.2, 1)` | 2 |
| all | 0.3s | `cubic-bezier(0.4, 0, 0.2, 1)` | 1 |

### 1.2 动画（animation）

| 动画名 | 时长 | 缓动 | 次数 |
| --- | --- | --- | --- |
| `fade-in` | **0.3s** | ease | 13 |
| `fadeIn` | 1s | ease | 4 |

> `@keyframes` 只读到 1 个名字（`l13`）——其余样式表跨域，`cssRules` 读不到。**不影响结论**：过渡体系已经足够完整。

### 1.3 三条可直接照抄的结论

1. **hover 变色统一用 `0.1s ease-out`**（547 处）——这是全站最普遍的一条，做错整站"手感"就不对。
2. **第二梯队是 `0.1s cubic-bezier(0.4, 0, 0.2, 1)`**（就是 Tailwind 的默认 ease，共 94 处），用于颜色组与透明度。
3. **没有超过 0.5s 的过渡**（除 2 处 0.5s）；**没有弹跳/回弹类缓动**——全程克制。另外有 12 处 `0.02s ease-in` 是"几乎瞬时"的微交互。

## 2 hover 揭示模式（三种，实测）

FlowUs 的"悬停才出现"不是一种做法，而是**三种并存**：

| 模式 | 实现 | 实测样本 |
| --- | --- | --- |
| **① display 切换** | `hidden ... group-hover:flex` | 侧栏页项的 `⋯`（`aside-item-more`）与 `＋`（`aside-item-create-by-space`），各 20×20，默认 `display:none` |
| **② 透明度切换** | `opacity-0 transition-opacity group-hover:opacity-100` | 20×20 的图标按钮，默认 `opacity:0`（**占位不消失**，避免布局跳动） |
| **③ 反向切换** | `group-hover:hidden` | 页项左侧的 **emoji 图标**默认显示，**hover 时隐藏** |

### 2.1 最重要的一条：侧栏页项的 hover 是"换内容"

页项默认显示 **页面 emoji 图标**（20×20）；鼠标悬停时**图标隐藏，原位换成 `⋯` 和 `＋` 两个按钮**。
→ 实现时这是一个"同一个位置切换内容"的交互，不是"图标旁边多出两个按钮"。位置错了会很显眼。

## 3 右键行为（实测）

**侧栏页面项右键 = 与 `⋯` 完全相同的菜单**（同一套 8 项，同一位置逻辑）：

```
添加到快速访问 ｜ 拷贝副本 ｜ 复制页面链接 ｜ 重命名 ｜ 移动到 ｜ 删除 ｜ 在侧边栏打开 ｜ 在新窗口打开
```

（菜单面板规格见 `基准-组件.md` 第 3 节：224×292 / 圆角 12 / 项高 32 / 两条分隔线）

→ 实现时**右键和 ⋯ 共用一个菜单组件**，不要写两套。

## 4 正文区 hover（部分实证）

鼠标移入正文区后，内容列左缘（x≈719~720）会出现 **20×20 的图标**。已确认有元素出现，但**没能区分是"块手柄"还是"添加评论"**——按既有逆向文档，正文块 hover 应在块左缘浮现 `+` 与 `⠿`（拖拽手柄）。

> **标为待补**：块手柄的确切位置、尺寸、出现区域（哪个 x 区间触发）需要 M0-T16 或 M2-T07 实现时对照采。

## 5 给 M1/M2 的实现要求

1. **hover 过渡一律 `0.1s ease-out`**（背景色）；透明度用 `0.1s cubic-bezier(0.4,0,0.2,1)`。
2. **不要加弹跳/回弹缓动**，FlowUs 全程克制；最长的过渡也就 0.5s（2 处）。
3. **侧栏页项 hover = emoji 图标位置换成 `⋯`/`＋`**（三态：常态图标 → hover 操作钮 → 选中）。
4. **右键与 `⋯` 共用一个菜单组件**。
5. "悬停才出现"的元素要**按模式选实现**：会改变布局的用 `display` 切换（模式①），不会的用透明度（模式②）——混用会导致移动端/键盘态表现不一致。
