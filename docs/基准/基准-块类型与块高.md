## 1 块类型：两个**新识别**（重要）

用一个隔离页按顺序输入，逐块读接口对照：

| 输入 | 产出 type | 结论 |
| --- | --- | --- |
| `这是一段正文样本` | `1` | 段落 ✓（与 M0-T17 一致） |
| `# 标题一` | `7` / **lv1** | 标题 1 ✓ |
| `## 标题二` | `7` / **lv2** | 标题 2 ✓ |
| `### 标题三` | `7` / **lv3** | 标题 3 ✓ |
| `#### 标题四` | `7` / **lv4** | 标题 4 ✓ |
| `- 项目项` | `4` / lv4 | 项目列表 ✓ |
| `1. 编号项` | `5` / lv4 | 编号列表 ✓ |
| **`> 引述样本`** | **`12`** / lv4 | ⚠️ **type 12 = 引述文字**（见 1.1） |
| `---` | `9` | 分割线 ✓ |
| **`` ``` ``**（代码围栏） | **`25`** | ✅ **type 25 = 代码块**（见 1.2） |
| （空行） | `1` / len=0 | **空段落** |

### 1.1 ⚠️ 可能推翻 M0-T17：「type 12 = 待办」

M0-T17 里我断「`type=12` = 待办列表」，依据是 **AI 生成内容**里那批成片的 12 号块（"今日核心目标/次要任务…"）。

**本轮是可控实验**：我明确输入 `> 引述样本`，得到 **type=12**（`len=4` 正好是"引述样本"）。
→ **可控证据比从 AI 内容推断更强**。所以 **`type=12` 更可能是「引述文字」，T17 的"待办"判定存疑**。

**那"待办"是哪个 type？仍未定。** 不猜。
→ 已把这条写进 M0-T28 的验证清单（用 `/dblb` 或在 MD 快捷里试 `[]`——注意 `[]` 曾在 T17 触发过 AI，须小心）。

### 1.2 ✅ `type=25` 身分：代码块

`type=25` 在 M0-T22 / M0-T25 两次"意外出现"、一直没定名。
**本轮它是回答一个明确的输入（`` ``` ``）产生的**，且伴随 `len=0`（代码块初始为空）→ **`type=25` = 代码块（代码片段）**。
（仍有 80% 把握而非 100%：没在输入后验证代码块内是否真能写代码。标为"高置信"，M0-T28 可复核。）

## 2 块高（单行）——**空块高度终于测到了**

| 块 | 单行块高 | x |
| --- | --- | --- |
| 段落（type 1） | **34** | 716 |
| **空段落（type 1，len=0）** | **34** | 716 |
| 标题 lv1 | **57** | 716 |
| 标题 lv2 | **52** | 716 |
| 标题 lv3 | **34** | 716 |
| 标题 lv4 | **31** | 716 |
| 项目列表（type 4） | 36 | 716 |
| 编号列表（type 5） | 34 | 716 |
| 引述（type 12） | 26 | **742** |
| 分割线（type 9） | 36 | 716 |
| 代码块（type 25） | 26 | **742** |

**两条稳健结论**：
1. **空段落与普通段落同高（34）** —— 这是 M0-T19/M0-T24 一直缺的那个数。
2. **标题块高随 level 递减：57 > 52 > 34 > 31** —— 相对关系可靠。

### 2.1 ⚠️ 精度说明（不掩饰）

这一轮 DOM 里捞到 **22 个矩形**却只有 **12 个块**，配对是按"DOM 顺序对应接口顺序"猜的。
→ **标题各级的绝对块高精度有限**（M0-T24 在「账号」页量到 lv1 是 34、这轮量到 57，两者矛盾，原因未查清）；
**但"lv1 > lv2 > lv3 > lv4"这个相对关系在两次测量里都成立**，可以按这个用。
→ 并入 M0-T30：用"逐块精确锚点"（给每个块加唯一文本再按文本定位）重测一次，把绝对值定死。

## 3 ⚠️ 页面布局三档：**没测出差异**（推翻我在 M0-T24 的推测）

M0-T24 我发现「归档历史材料」是 `16/24`、「账号」页是 `16/26`，推测是**页面布局设置**在起作用。

**本轮实测：把同一页依次切到「紧密 / 宽松 / 默认」，正文一直是 `16px/24px`，没变。**

→ **两个结论**：
1. **「页面布局」影响的不是行高**（大概率是页面宽度/块间距之类）。
2. **`16/24` 与 `16/26` 的差异原因仍未查清**（可能是页面字体设置、或那两页内容形态不同）。**不猜。**

（测量本身也有干扰：切换时页面 ⋯ 菜单是开着的，样本里混进了菜单元素。）
