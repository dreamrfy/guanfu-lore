### ❌ 弃（界面层整体重写）

| 文件 | 理由 |
| --- | --- |
| **`main.dart` 整个 UI（约 2,000 行）** | 它是"**笔记 + 表格**两套心智拼出来的"：一个 NoteDetailPage 装块编辑器、另一个 RecordDetailPage 装表格行——**与 FlowUs「一切皆页面」的模型不是一回事**。而且从没按真基准做过（颜色/字号/间距全是拍脑袋）。**改不如重写。** |
| **`editor/blocks_editor.dart`（404 行）** | 自研块编辑器，已被 `appflowy_editor_ce` 取代；且其"首屏块无监听器→打字不保存"的历史 bug 说明自研成本高。**弃**。 |
| `table/table_view.dart` | 多维表 UI 需按 `基准-多维表界面.md` 全量重写（列宽 180 / 列头高 37 / 列头菜单 11 项…）。现版本是"看起来像"的近似。**弃，M4 重写**。 |
| `editor/markdown_controller.dart` | 自研 Markdown 快捷键逻辑；appflowy_editor 自带 `characterShortcutEvents`，改用内建的。**弃**。 |

| 文件 | 怎么改 |
| --- | --- |

## 3 本次落地的设计系统

`client/lib/design/tokens.dart` —— **基准值在代码里的唯一落点**，任何界面代码都引用它，不允许自己写魔数。

| 常量组 | 内容 |
| --- | --- |
| `FlowUsLayout` | 侧栏 228 / 标签条 48 / 横幅 44 / 主区起点 92 / 内容列 708 + 居中公式 + 侧栏内部骨架 + overlay 滚动条 |
| `FlowUsRadius` | 2 / 4 / 6 / 8 / 12 / 全圆（**5 档，全站只用这些**） |
| `FlowUsColors` | `light` / `dark` 两套完整色板（ThemeExtension），含 **深色下悬停底是白 6%** 这条坑 |
| `FlowUsTypography` | 字体栈（照抄）、页面 H1 40/64/600、文档内标题 30/45/600、正文 16 + 块级24/行内26、代码块 14/21、字重只用 400/500/600 |
| `FlowUsBlockMetrics` | 块高 34、块间距 2、列表缩进 26、勾选框 24×24、**块手柄与「＋」两个不同热区（36 / 12）** |
| `FlowUsComponents` | 按钮 32、菜单面板 224×292 项高 32、弹层 1200、确认弹窗 302×170 |
| `FlowUsMotion` | hover 0.1s ease-out、标准曲线、最长 0.5s、**无弹跳** |

**防漂移**：`test/design_tokens_test.dart` **25 个断言**把关键值钉死（含"深色悬停底是白 6%"、
"两个热区必须不同"、"选中底重于 hover"）。跑法 `cd client && flutter test test/design_tokens_test.dart`。
