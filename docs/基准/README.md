## 怎么采集

工具与全部用法见 **`tools/flowus-cap/README.md`**。三条要点：

1. 采前先确认通道活着：`curl -s --max-time 5 http://127.0.0.1:9222/json/version`；无响应就 `cmd //c "E:\dev\tools\flowus-cap\browser.cmd"`。
2. **采集禁区**：真 FlowUs 的「配置」页面（含明文密钥）——采集脚本会直接拒绝（退出码 2）。要采别的页面先 `--url` 或 `--click` 切走。
3. 停在登录页时**不要自己点登录**，需要用户给一次验证码。

## 已实测到的首批数值（2026-11-10，窗口 1920×945 / DPR 1）

> 来源：`docs/基准/证据/M0-T01/`。这些是**顺手量到的**，正式落表在 M0-T02/M0-T03。

| 元素 | 数值 |
| --- | --- |
| 侧栏 | 宽 **228px**，背景 `rgb(247,247,247)`，右边框 `rgb(240,240,240)`，`z-index 100`，`position: fixed` |
| 侧栏页面项 | 左 8px、宽 211px、高 **32px**，圆角 **6px**，字号 **14px**，未选中文字 `rgb(95,94,91)`，选中 `rgb(0,0,0)` |
| 顶部标签条 | `x=228, y=0, w=1692, h=48`，背景 `rgb(255,255,255)` |
| 容量提示条 | `x=228, y=48, w=1692, h=44`，背景 `rgba(2,133,255,0.05)` |
| 正文基准 | 字号 **16px**、行高 **24px**、文字色 `rgb(55,53,47)`、默认边框色 `rgb(229,229,229)` |
| 字体栈 | `my-quote, "PingFang SC", "Microsoft YaHei", ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif, …` |

**重要发现**：FlowUs 的配色体系**不是 CSS 变量**（实测首页只有 3 个自定义属性，还都是图标 URL），而是编译进 Tailwind 工具类（`bg-aside` / `text-t1` / `border-grey7`）。所以 **M0-T03 必须靠「class + 计算样式」反推调色板**，别指望 `tokens.json`。
