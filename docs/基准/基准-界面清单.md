## 6 稳定定位钩子全量（15 个，实证）

实现与自动化**一律用这些**，不要用文案定位：

| `data-test-id` | 归属 |
| --- | --- |
| `aside-item-toc` | 侧栏页面项（×12） |
| `aside-item-more` | 页项行内 `⋯`（隐藏×12） |
| `aside-item-create-by-space` / `-by-private` | 页项行内 `＋` |
| `aside-toc-header-create-by-space` / `-by-private` | 分区头 `+` |
| `aside-space-create` | 空间菜单「创建新空间」 |
| `doc-title` | 文档标题 |
| `page-header-more` | 页面右上 `⋯` |
| `drive-file-share` | 页面右上「分享」 |
| `delete-bar-restore` / `delete-bar-delete` | 删除恢复横幅的两个按钮 |
| `trash-item-restore` / `trash-item-delete` | 回收站行操作 |

> ⚠️ **安全提醒（已写进纪律）**：`*create*` 类钩子点了会**真的建页**。采集时**一律不点**（本任务前一轮就踩过，见执行报告）。

## 7 验收口径（给 M11 用）

逐屏验收按本清单走，每项三态：
- **对齐** = 并排截图看无差异
- **差异** = 列出差异项与原因（如字体渲染、FlowUs 自身 AA 不达标等已知例外）
- **未实现** = 明确标出，不允许含糊

**当前进度**：本清单共 **48 项** —— 🟢 **实证 29 项** / 🟡 **待实证 19 项**
（编号行 41 项：🟢 28 / 🟡 13；第 5 节按模块整块列 7 项：🟢 1 / 🟡 6。41+7=48，28+1=29，13+6=19）

M11 开始前必须把 🟡 全部转成 🟢，否则"逐屏验收"没有基准。
