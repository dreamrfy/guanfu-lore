# 基准 · 图标对照表（自研 `Ic*` 全量导出）

> **M0-T15 交付物。** 从真 FlowUs 的 `[data-icon]` 属性全量收割，共 **57 个**，SVG 原文存在 `docs/基准/图标/`。
> 采集时间：2026-11-10 ｜ 收割界面：外壳 / 侧栏 hover / 行内菜单 / 页面 ⋯ 面板 / 导出子菜单 / 空间设置（6 个面）
> 清单：`docs/基准/图标/icons-manifest.json`（含每个图标的来源界面与渲染尺寸）
> 复跑：`node tools/flowus-cap/icon-harvest.mjs`

## 0 最重要的发现：这套图标**混了两家**

| 家 | 数量 | 特征 | 我们怎么用 |
| --- | --- | --- | --- |
| **FlowUs 自研 `Ic*`** | **51** | `viewBox="0 0 20 20"`、**填充式**（靠 class `fill-current` 上色）、名字形如 `IcAdd` / `IcTrash` | **直接用导出的 SVG**（已在 `docs/基准/图标/`） |
| **Lucide** | **6** | `viewBox="0 0 24 24"`、`stroke="currentColor"`、`stroke-width=2`、圆头、class 带 `lucide lucide-*` | **用 Lucide 包**，不用自备：`Search` `Undo2` `Redo2` `MoveHorizontal` `Presentation` `Store` |

> 所以「图标风格不统一」不是我们的问题——**FlowUs 自己就是两家混用**。我们照抄这个分布即可。

**渲染尺寸分布**：`16×16` **29 个** ｜ `20×20` **25 个** ｜ `12×12` 2 个 ｜ `14×14` 1 个
→ 主力还是 **20 与 16 两档**（与 `基准-字体与图标.md` 的结论一致）。

## 3 给 M1/M2 的实现要求

1. **图标清单以本表为准**，共 57 个；实现时**不要自己找"差不多"的替代图标**——自研集是填充式 20 网格，用 Lucide 的描边图标顶替会一眼看出不一样。
2. **51 个自研图标直接用 `docs/基准/图标/*.svg`**（原文，含 viewBox 与路径）。
3. **6 个 Lucide 名的用 `lucide_icons` 包**，参数：24 网格 / `stroke-width: 2` / 圆头圆角。
4. **尺寸只用 20 / 16 / 12 / 14 四档**，主力 20 与 16。
5. **上色靠 `fill-current`**（自研集）：把 SVG 的 `fill` 设为 `currentColor`，颜色跟随主题 token（`grey2`/`grey3`/`active_color`…）。
6. **深色下图标不用换**：颜色来自 `currentColor`，跟着主题走即可（呼应 `基准-色彩.md` 第 4 节的成对反转）。
