## 2 两处必须知道的历史冲突

### 2.1 `type=12`：引述 还是 待办？——✅ **已结案（M0-T32）**

- **M0-T17**：从 **AI 生成的内容**里看到成片 `type=12`（"今日核心目标/次要任务…"）→ 推断为**待办列表**。
- **M0-T27 / T31**：用**可控输入** `> 引述样本` → 得到 `type=12` → **引述文字**。
- **M0-T32**：打 `/` 后从菜单点「待办列表」→ 得到 **`type=3`**。

**结论：`12` = 引述文字；`3` = 待办列表。T17 当年把 12 记成"待办"是错的**（AI 拿引述块做了模板条目，
我被那个现象带偏了）。**争议结束，两条都定了。**

### 2.2 块高测量两次矛盾（M0-T24 vs T27）

- M0-T24 在「账号」页量到 标题 lv1 **块高 34**
- M0-T27 在隔离页量到 标题 lv1 **块高 57**

两者矛盾，原因是我的"DOM 矩形 ↔ 接口块"**按顺序猜配对**不可靠 → 并入 M0-T30 用"唯一文本锚点"精测。
**可用的只有相对关系**：lv1 > lv2 > lv3 > lv4。

## 3 造块方法总结（三次失败后的最终结论）

| 方法 | 可靠性 | 备注 |
| --- | --- | --- |
| **Markdown 快捷**（`#` `##` `-` `1.` `>` `---` ` ``` `） | ✅ **最可靠** | M0-T17 / T27 都成功。**首选** |
| **斜杠菜单：输入 `/`+中文关键词 → 按坐标点选条目** | ✅ **可靠** | M0-T28 成功拿到 折叠列表/折叠标题/简单表格 |
| 斜杠菜单：输入快捷码 + **回车选第一项** | ❌ **不可靠** | T22/T25 两次都失败——回车选的是"过滤后第一项"，未必是目标 |
| 斜杠菜单项有没有 `data-test-id`？ | ❌ **没有** | T28 实测：4 个条目 `testId` 全为 null → 只能按坐标点 |

## 4 斜杠菜单里**造不出**的块（多次尝试，已定性）

「**思维导图**」「**按钮**」「**同步块**」「**数据图表**」——**造不出来**。尝试记录：

| 轮次 | 做法 | 结果 |
| --- | --- | --- |
| M0-T22 | 键盘 `↓` 遍历 + 滚轮 | 菜单滚不动（虚拟列表，只有 `scrollTop` 有效） |
| M0-T25 | 输入快捷码 + **回车选第一项** | 老实说这条方法本身不可靠，只成 1 个 |
| M0-T28 | `/关键词` 过滤 + 坐标点选 | 这 4 个**过滤后菜单 0 项** |
| **M0-T33** | **只打 `/` → 用 `scrollTop` 逐屏滚到底（共收集 101 项，覆盖全菜单 8 组）→ 点「思维导图」行** | **点了没有任何反应**（无新增块、无类型变化）；后续再打 `/` 菜单干脆不弹 |

**结论（据实）**：**在"文档内 / 当前免费版账号"这个环境里，这 4 种块无法通过斜杠菜单创建**。
菜单里**能看到**「思维导图 /swdt」这一项（T22 枚举到过），但点了不生成块。

**可能原因（不猜死）**：
- 免费版限制（`freePersonal` 套餐已由 M0-T23 确认）；
- 或这类块需要"建页面"而不是"插块"（思维导图原本在空页类型选择器里也有单独入口）。

→ **不阻塞 M2**：M2 首版只做基础块（正文/标题/列表/待办/引述/分割线/代码/简单表格），
这 4 种属"高级块"，排在 M2 后期或单独模块；**到时用"空页类型选择器"路径而不是文档内插块**。

## 5 给 M2/M4 的实现要求

1. **块类型数字照第 1 节写死**；`12` 用"引述"，`25` 用"代码块"，`27/28` 是简单表格与其单元格，`38` 是折叠标题。
2. **造块（做测试/造数据时）优先用 Markdown 快捷**；需要造 Markdown 造不出的块，才用"斜杠菜单 + 过滤 + 坐标点选"。
3. **`type=28` 是表格的内部结构块**——实现简单表格时别把它当独立块类型暴露给用户。
4. 本表与任何旧文档冲突 → **以本表为准**。
