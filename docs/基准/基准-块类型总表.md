## 2 两处必须知道的历史冲突

### 2.1 `type=12`：引述 还是 待办？

- **M0-T17**：从 **AI 生成的内容**里看到成片 `type=12`（"今日核心目标/次要任务…"）→ 推断为**待办列表**。
- **M0-T27**：用**可控输入** `> 引述样本` → 得到 `type=12`（`len=4` 正好是这段文字）→ **引述文字**。

**以可控输入为准**：`type=12` 记为**引述文字**，T17 的"待办"判定**存疑**。
**"待办列表"到底是哪个 type，仍未定** → 留在 M0-T30 复核（注意 `[]` 曾在 T17 触发过 AI）。

### 2.2 块高测量两次矛盾（M0-T24 vs T27）

- M0-T24 在「账号」页量到 标题 lv1 **块高 34**
- M0-T27 在隔离页量到 标题 lv1 **块高 57**

两者矛盾，原因是我的"DOM 矩形 ↔ 接口块"**按顺序猜配对**不可靠 → 并入 M0-T30 用"唯一文本锚点"精测。
**可用的只有相对关系**：lv1 > lv2 > lv3 > lv4。

## 3 造块方法总结（三次失败后的最终结论）

| 方法 | 可靠性 | 备注 |
| --- | --- | --- |
| **Markdown 快捷**（`#` `##` `-` `1.` `>` `---` ` ``` `） | ✅ **最可靠** | M0-T17 / T27 都成功。**首选** |
| **斜杠菜单：输入 `/`+中文关键词 → 按坐标点选条目** | ✅ **可靠** | M0-T28 成功拿到 折叠列表/折叠标题/简单表格 |
| 斜杠菜单：输入快捷码 + **回车选第一项** | ❌ **不可靠** | T22/T25 两次都失败——回车选的是"过滤后第一项"，未必是目标 |
| 斜杠菜单项有没有 `data-test-id`？ | ❌ **没有** | T28 实测：4 个条目 `testId` 全为 null → 只能按坐标点 |

## 4 斜杠菜单里**造不出**的块（本方法失败）

「思维导图」「按钮」「同步块」「数据图表」：输入 `/关键词` 后**菜单返回 0 项**。

→ 可能原因（**未验证，不猜死**）：
- 它们在菜单更靠后的分组里（`高级块`），过滤匹配不到；
- 或是**付费功能**（当前是免费版，M0-T23 已确认 `freePersonal` 套餐）。

→ 并入 M0-T30：改用"滚动到分组后再点"的方式重试，并记录是"找不到"还是"点了没反应"。

## 5 给 M2/M4 的实现要求

1. **块类型数字照第 1 节写死**；`12` 用"引述"，`25` 用"代码块"，`27/28` 是简单表格与其单元格，`38` 是折叠标题。
2. **造块（做测试/造数据时）优先用 Markdown 快捷**；需要造 Markdown 造不出的块，才用"斜杠菜单 + 过滤 + 坐标点选"。
3. **`type=28` 是表格的内部结构块**——实现简单表格时别把它当独立块类型暴露给用户。
4. 本表与任何旧文档冲突 → **以本表为准**。
