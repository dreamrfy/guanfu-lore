# 竞品交互研究：FlowUs 实拍规格 + 开源方案评估 v1

> 2026-11-08。起因：V2.1 五包验收反馈——「不要自己发明交互，去看 FlowUs 怎么做的」。
> 本文 = FlowUs Windows 实机走查（截图在 `E:\dev\tmp\flowus-study\shots\`）+ Notion 惯例 + 开源编辑器选型，**只定规格，不含代码**。
> 状态：Windows 端研究完成；安卓端待用户装 APK 后补充（移动端交互会有差异）。

## 一、FlowUs Windows 实拍规格（证据截图编号）

### 1. 侧栏：新建入口（回应问题 ①）
- **没有右下角悬浮按钮，没有任何常驻「新建」**。
- 鼠标悬停「私人」区块标题行 → 右侧浮现 `⋯ +` 两个图标（01 截图）；悬停「空间」区块 → 只浮现 `+`。
- 页面项悬停 → 浮现行内操作（02 截图）。
- **点 `+` 不弹对话框**：直接创建一个「无标题」页面并打开（03 截图），进入下方第 2 条的空页面流程。
- 启示：我们的 FAB + 「新建内容」对话框（先填标题）整个删掉。

### 2. 空页面首屏（回应问题 ①③）
- 页面标题就是正文区顶部的灰色大字「无标题」——**点击标题即改名，侧栏同步**（标题无独立弹窗）。
- 提示行：「按回车开始编辑，或从下方选择页面类型」。
- 类型选择列表（行式，非卡片，悬停高亮+回车箭头）：
  - 第一组：页面、AI 写作、文件夹、思维导图、模板、导入
  - 第二组「多维表」：表格、看板、画廊、目录、时间轴、日历、收集表
- **把页面内容全部删光 → 空页面状态（含类型选择器）自动重现**（10 截图）。
- 启示：改名 bug 的根因是我们的「对话框标题」与页面脱节；正解 = 标题内嵌正文首行、侧栏同源。

### 3. 编辑器 / 菜单（回应问题 ③）
- 输入 `/` → **行内浮层菜单**贴在当前块下方（06 截图），分组展示，每项带**拼音快捷码**：
  - AI 组：FlowUs AI、继续写作 /xyz、翻译、更多
  - 基础块：正文 /zw、待办列表 /dblb、页面 /ym、引用页面 /yyym、标题1 /h1、标题2 /h2、标题3、标题4、简单表格 /jdbg、项目列表 /xmlb、编号列表 /bhlb、折叠列表 /zdlb、分割线 /fgx、引用文字 /yswz、着重文字 /zzwz、代码片段 /dmpd、数学公式 /sxgs、思维导图 /swdt…（07/08 截图）
- 菜单可滚动、可继续输入过滤。

### 4. 块交互惯例（Notion 官方模式，FlowUs 同源）
- 悬停块左侧 → 出现 `⠿` 手柄（+ 与 ⠿）；点 ⠿ 开操作菜单：变成(Turn into)/复制/评论/颜色/移动到/删除。
- 拖 ⠿ = 拖动重排（蓝色落点线）；Alt+拖 = 复制。
- 我们当前实现的问题：手柄是常驻按钮+点开一个大杂烩对话框（类型+加粗+删除混在一起），与惯例相反。

## 二、开源方案评估（回应「有没有开源的方案」）

| 方案 | 匹配度 | 状态 | 许可证 | 结论 |
| --- | --- | --- | --- | --- |
| **appflowy_editor**（pub.dev，AppFlowy 官方） | 高：块组件模型、slash 菜单、BIUS、快捷键/主题全可定制，Flutter 原生 | v6.2.0，约 11 个月未发版，但被 AppFlowy 产品本身长期验证 | **AGPL-3.0 / MPL-2.0 双许可** | 候选 A |
| flutter_quill | 中：成熟文档编辑器（Delta 模型），Notion 式块/斜杠菜单/拖拽要自己搭 | 活跃维护 | MIT | 备选 |
| 自己照规格重做自研编辑器 | 交互可完全对齐 FlowUs，数据格式（块 JSON）不动，无许可问题 | — | — | 候选 B |

**AGPL 说明（如实口径）**：我们 App 自用不分发，AGPL 义务不触发；但若未来上架商店分发，AGPL 要求开放源码。MPL-2.0 选项则宽松（仅文件级）。选 A 前需在 LICENSE 里确认可选 MPL。

## 三、四个问题的改造方向（待拍板后立方案）

1. **侧栏新建**：删 FAB 与对话框 → 区块头悬停出 `+`（普通页）/`+`+`⋯`（私人区），点 `+` 直接建页；页面项悬停出 `⋯`/`+`。
2. **改名同步**：标题内嵌页面正文首行（大字灰占位「无标题」），改名即改库，侧栏与打开中的列表自动同步（单一数据源）。
3. **编辑器重做**：两条路线二选一——
   - 路线 A：接入 appflowy_editor（功能一步到位，代价=数据格式迁移 + AGPL 语义 + 依赖重量）；
   - 路线 B：自研编辑器严格照本文规格重写交互（悬停手柄/行内 slash 浮层/块菜单分组/拖拽重排），数据格式不动、无许可问题，工作量约 2-3 个任务包。
4. **Windows 端**：截图 5 显示的是**旧构建**（无类型选择卡片）——重新 `flutter build windows` 即得新功能，非设计缺陷。

## 三b、多维表格交互完整规格（2026-11-09 凌晨补齐，截图 12~33）

- **表格=页面里的一个块**：块手柄菜单显示「块统计: 4（4 条记录）」，选中出现多选工具条（已选中 N / 分类 / 🗑删除 / ⋯），行复选框浮现。
- **点第一列单元格 = 直接打开记录页**（面包屑「多维表格 / 记录名」）；悬停第一列出现「⊞ 打开」按钮。记录页 = 属性区（字段图标+名：值行式，「+ 添加属性」就地加字段）+ 分隔线 + **普通块编辑器正文**（占位「按回车开始编辑，或 模板」）。
- **「创建 ▾」按钮** = 新建记录（表格 模板记录 / 创建模板记录），不是新建视图；新视图在视图栏「+」。
- **列头单击 → 字段菜单**：字段名就地改名、更换类型 ▸（类型子菜单）、在左/右侧插入、升序/降序/筛选、隐藏/冻结列/拷贝副本/**删除（带「确认删除」对话框）**。
- **列尾 ⊕** = 加字段。
- **行悬停**：左侧浮现 `+ ⠿`（上方插行/拖拽），行内浮现「⊞ 打开」；⠿ 点击开页面级菜单（打开方式/复制/删除/编辑属性/移动到/插入行/块统计）。
- **删记录**：确认框「将删除选中的 N 项数据，删除后可在回收站中恢复」。
- **分类（单选）单元格点击** → 「查找或创建选项」下拉。

## 三c、其他关键惯例（本轮补充）

- **空块占位文案**：「按空格使用 AI，输入文字或 / 命令」——比我们的「写点什么…」信息量大。
- **块手柄**：悬停块左侧浮现 `+ ⠿`；⠿ 菜单完整清单：AI 助手 Ctrl+J / 复制 / 剪切 / 创建副本 / 复制并移动到页面 / **转换为 ▸** / 复制块链接 / 删除 Del / **移动到** Ctrl+Shift+P / **颜色 ▸ / 对齐方式 ▸** / 添加评论 / 在上方插入 A / 在下方插入 B / 在右侧添加分栏 ▸ / 底部块统计与最后编辑信息（30 截图）。
- **改名同步**：标题在正文首行，改标题 → 标签页、侧栏**三处即时同步**（31 截图）——bug#2 的正解。
- **右键侧栏页面项**：添加到快速访问/拷贝副本/复制页面链接/重命名/移动到/删除/在侧边栏打开/在新窗口打开（32 截图）。
- **删除页面**：页面不关闭，顶部出红色横幅「当前页面已删除」+「恢复 / 彻底删除」（33 截图）——可反悔设计，优于我们当前的「删除即关闭」。
