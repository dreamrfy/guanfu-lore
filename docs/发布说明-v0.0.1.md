## 3 红线与实现方式

| 红线 | 实现 |
| --- | --- |
| 资源只存编号（G1） | `AssetRef = {assetId, provider, ext}`；地址由存储层按编号生成 |
| 正文为空/图片缺失不得 `complete`（SNAP-02） | `deriveStatus()`；图片按整页全口径统计（img/srcset/source/CSS/其他入口），相对引用必须文件存在 |
| 抓外部地址要有 SSRF 防护 | 仅 http/https；`net.BlockList` 拒绝私有/保留地址（IPv6 fail-closed）；DNS 钉住；逐跳重定向复检；主机白名单；响应上限 |
| HTML 不得执行脚本 | 正文走 `sanitize-html` 白名单；快照用 DOM 清理脚本/事件/远程资源；CSP 由本项目唯一注入 |
| 凭证不进仓库 | 只从 `KF_SECRETS_FILE`（仓库外）读取；路径含仓库内即拒绝 |
| 文档不得把未验证写成已验证 | 发布说明、README、验收证据均单列「未验证」 |

## 5 已知限制与风险

1. `poll` 未用真实凭证验证——接真实环境前必须做一次冒烟。
2. B站真实短链/API 未联网复跑；白名单接线有测试，但真实响应字段可能变化。
3. 云函数 Runtime 需 Node 24；若平台只提供 20/22，需要先编译成 `.js`。
4. 幂等键从 FNV-1a 改为 SHA-256 前 16 位：旧库 id 不兼容，需清库重导或按 `source_url` 重算迁移（见 `server/README.md`）。
5. 静态扫描（Mimosa）状态为 `inconclusive`（调用图不完整），不能据此宣称项目已通过安全审计。
6. 小红书/抖音正文、公众号长图需浏览器渲染，属阶段二。
