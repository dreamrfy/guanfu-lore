## 1. 最终结论（已锁定）

| 项 | 值 |
| --- | --- |
| 中文正式名 | **观复** |
| 英文正式名 | **Lore** |
| 组合写法 | 观复 · Lore |
| 中文正式 slogan | **万物并作，吾以观复。** |
| 英文正式 slogan | **All things arise; I watch them return.** |
| 出处 | 《道德经》第十六章（原文无"其"字，用原句） |

**为什么这对名字成立**（后续对外解释也可以照这段说）：
- 中文"观复"是**动作**——看着万物循环往复（《道德经》"万物并作，吾以观复"）；
- 英文"Lore"是**结果**——一代代传下来、值得反复回看的知识（folklore 的 lore）；
- 一个讲"回来"，一个讲"留下来的东西"。**同一件事的两面，互镜而非互译**——这正是 DeepSeek/深度求索那种"中英各写各的、气质相通"的结构。
- 产品闭环"捕获→整理→提炼→输出"本质就是知识的循环往复，"复"字就是产品的骨架。

## 2. 用户否决过的方向（不要再提）

| 轮次 | 提案 | 用户反馈 | 教训（写下来防止重犯） |
| --- | --- | --- | --- |
| 1 | 单字中文名（笺、镌、渊、砚、蕨、壤…） | "太短了，正常产品没有单字的，奇怪" | 中文产品名默认 2–4 字；单字只适合做简称，不适合做正式名 |
| 1 | 拉丁/生僻英文名（Recursus、Iterum、Respice、Dacapo、Verso） | "念着不顺口，这软件主要给中文母语者用" | 英文名第一要求是**中文用户也能脱口而出**；拉丁词、音乐术语全部出局 |
| 2 | 造词/复合词（Recircle、Returnscope、Revoyage） | "怪、生硬，说不出来哪里不对" | **不要造词**。DeepSeek 用的两个词都是本来就活的英文词；品牌造词穿西装，活词才自然 |
| 3 | 直译式英文 slogan（Behold the return of all things） | （自查后主动放弃） | 逐字硬译=翻译腔。检验法：给英语母语者看，像不像他自己写的格言 |

**最终通过检验的英文名特征**（Lore / Tide / Echo / Haven / Fathom 这一类）：
真实存在、1–2 音节、小学词汇、中文用户第一眼看就能念对、意思和产品对得上。

## 3. 过程里确认过的事实（省得下次再查）

- **观复博物馆**（马未都，北京）与"观复"重名。类别为博物馆/展览（第 39/41 类），与软件（第 9/42 类）通常不构成注册冲突，**法律上大概率可行**；但品牌联想上，部分人第一反应会是博物馆。用户知情后仍选定"观复"。
- 拼音域名 `guanfu.com` 已被注册（RDAP 实查）；`guanfu.app / .dev / .ai` 当时实查为可注册。**域名策略整体推迟**——等名称落进代码、要建官网/服务时再统一办（用户自行处理费用与注册）。
- 大厂惯例佐证：中文 AI 产品几乎全部"中文雅名 + 短英文/拼音名"双轨（通义千问→Qwen、混元→Hunyuan、深度求索→DeepSeek、阶跃星辰→StepFun）。观复/Lore 沿用此结构。
- 仓库目录名 `bijiapp` 是历史遗留（早期"笔记"定位），**与正式名无关**；是否改技术标识见待办 M13-02。

## 5. Logo 方向备忘（给 M13-01 用，届时直接开工）

- **画面语言**（与"观复/Lore"同源）：回到原点但已升高一层的**圆/螺旋**（复）；**书页/纸卷**（lore＝传下来的文字）；年轮；灯火。
- **必须避开**：大脑侧影、星光/火花、机器人、无限环、紫粉渐变球（AI 俗套五件套）。
- **流程**：文生图出方向（一次 4–8 张，纯白底、居中、≤2 色、无文字）→ 选定后图生图微调 → 描摹成 SVG 并手工简化 → 出多尺寸 PNG（1024/512/256/128/64/32/16）+ `favicon.svg` + `npx tauri icon` 一键出全套。
- **验收**（每条都要过）：16px 可辨认；纯黑单色可辨认；灰度不糊；圆角方形/圆形裁切不丢形；与 Obsidian/Notion/Anytype/Mem/Recall 的图标都不撞形；标记本身不含文字（字标另做，中英两版）。
