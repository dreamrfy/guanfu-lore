## 1. 合并策略：android-shell 为主体，client/android 废弃

**结论：在 `android-shell/` 原地长成完整客户端；`client/android/` 标记废弃不再投入。**

理由（实证）：
- `client/android` 是 Flutter 模板壳：MainActivity 只有 130 字节的 `FlutterActivity` 继承（实测），无任何业务代码；其 gradle 绑定 flutter plugin loader，与"原生 Kotlin 全功能"目标相悖。
- `android-shell` 已有真资产：VIEW/SEND intent 接入（manifest:20,25）、ClipClient.kt（剪藏 HTTP 客户端）、SettingsActivity（服务器地址+Token，effectiveUrl/effectiveToken 内置默认+用户覆盖语义，SettingsActivity.kt:108-113）、单测 4 件、签名脚本与 keystore 流程（v3.3 T 模块验收过）、`app.guanfu.shell` 包名与 `DEFAULT_CLIP_BASE_URL=https://clip.guanfu.app` BuildConfig 注入。
- 用户指令"不凭空重开工程"（任务表 A 模块背景）。

**具体动作（A02 执行）**：
1. `android-shell` 根目录改名事项不做（目录名保留，applicationId 保持 `app.guanfu.shell`，避免换包名引发 T08 回归）；displayName 走 M13 品牌资源（等用户挑 Logo，不在 A02 范围）。

## 2. 数据层：Room 表模型 = web Dexie 表的 1:1 复刻

原则：**JSON 载荷原样存，Android 不做格式转换**。BlockNote 块是纯 JSON（`{id,type,props,content}`），web 端同步 payload 就是它的 JSON 串（sync.ts buildPushPayload 直接透传 OutboxRow.payload）——安卓端存同一 JSON，渲染成 Compose 树即可与 web 互通。

| Room Entity | 复刻自 | 说明 |
| --- | --- | --- |
| PageEntity | PageRow（db.ts:26-40） | id/parentId/title/icon/coverAssetId/createdAt/updatedAt/deletedAt/sortKey/tags(JSON 数组列) |
| DocEntity | DocRow | pageId 主键、blocks(TEXT 存 JSON 串)、updatedAt |
| CollectionEntity | CollectionRow | fields/views 存 JSON 串（结构 web 端说了算，安卓只读解析） |
| RecordEntity | RecordRow | values(JSON)/doc(JSON)/thoughts(JSON)/snapshotAssetId |
| AssetEntity | AssetRow | data(BLOB)、pageId/kind/mime/size；缓存目录另放 files/，库里存相对路径+状态 |
| OutboxEntity | OutboxRow | 自增 id、entity/entityId/op/payload(TEXT)/baseSeq/actor/createdAt；唯一索引(entity,entityId) 实现 coalesce |
| SyncConflictEntity | SyncConflictRow | 同构 |
| KeyValueEntity | meta 表 | 游标 syncCursor、seqs、deviceId、AI 配置等键值 |

DAO 对齐 web repo 语义：`listOutbox()/putOutbox()/deleteOutbox()`、`listPages(orderBy sortKey)`（web 教训：**排序字段必须建索引**，db.ts v2 版本注释）、孤儿页兜底查询（父页不在/已删 → 当顶层显示，Sidebar.tsx:29 语义）。

版本迁移：Room `version = 1` 起步，**字段变更一律新开 version(n)**，继承 web db.ts 头注纪律。

## 3. 同步引擎：复刻 sync.ts 算法，WorkManager 调度

server 侧零改动（红线之外还有个实际理由：web/安卓/桌面共用同一套 sync API 与游标语义）。安卓复刻五个关键点（全部有 web 实测教训背书）：

1. **pull**：`POST /api/sync/pull {since: cursor, limit: 500}` → 逐条 `entity:entityId` 判断。
2. **自回声防护**（sync.ts:289-299，S04 踩过的坑）：outbox 还挂着的行不被远端覆盖，只推游标。
3. **补缺图**（sync.ts:307-310）：pull 到的 payload 里 collectAssetRefs 出的附件 id 本地没有 → GET /api/sync/assets/:id 取回；失败不拦主流程。
4. **push**：先传缺附件（POST /api/sync/assets，失败不拦）→ `POST /api/sync/push {changes:[...]}`；`applied` 更新本地 seqs；`conflict` → 存 SyncConflictEntity，绝不静默丢。
5. **冲突解决**：`POST /api/sync/conflicts/resolve`；列表 UI 对齐 web 的冲突副本展示；冲突 AI 合并一期不做安卓（conflictAi 411 行依赖 AI 面板，后置）。

调度：WorkManager `PeriodicWorkRequest(15min)` + 网络约束 + `runSync()` 手动下拉刷新入口；应用退后台不强制即时同步（对齐 web syncAuto.shouldAutoSync 的保守语义）。

## 4. UI 层：Jetpack Compose 单 Activity + 导航

- 单 Activity（沿用 shell 的 MainActivity 位），Compose Navigation：`登录/设置 → 主框架(列表页) → 页面查看 → 编辑器 → 表格详情 → 收集箱`。
- 页面结构对照 `_cleanup/待归档/flowus-wireframes-v1/06-android-flow.png`：抽屉式侧栏（集合树/标签/收集箱入口/回收站）、顶部同步状态条、FAB 新建。
- 块渲染（A05）：BlockNote JSON → Compose 树。一期覆盖 web 端已有块型：paragraph/heading/bullet/numbered/checklist/quote/image/code/table/callout/bookmark/collectionBlock/pageMention；未知块型降级显示「[不支持的块]」+ 原始 JSON 可查看（与 web 的兼容策略对齐）。
- 编辑器（A06-A07）：**不自研富文本引擎**。方案：每块一个 Compose 输入态，块间用 LazyColumn；`/` 命令面板、拖拽排序用 Compose reorder 库。明确风险：这不是 BlockNote/ProseMirror，块级迁移（如复制到 web）靠 JSON 层保证，所见即所得细节允许与 web 有差异（A14 全流程自验时校准）。
- 表格（A08）：JSON 复用 CollectionRow/RecordRow；一期只做表格视图（与 web 一致），看板/日历/画廊安卓侧是否跟进看 F03 审阅圈定（F02 报告决策点 3）。

## 5. 网络与凭证

- HTTP：OkHttp + kotlinx-serialization（不引 Retrofit 减少反射面）；Bearer Token 统一拦截器；超时/重试对齐 web post()（sync.ts:222-240）。
- 凭证：EncryptedSharedPreferences 存 `{serverUrl, token, deviceId}`；**默认值语义沿用 shell**：`BuildConfig.DEFAULT_CLIP_BASE_URL`（=https://clip.guanfu.app）+ `DEFAULT_CLIP_TOKEN`（gradle 从 `E:\credentials\clip.token` 注入，现有 build.gradle.kts:29-30 机制不动）；设置页可覆盖。剪藏与全功能客户端共用同一份凭证（web 端同语义：sync.ts 头注"同步接口与剪藏接口在同一服务上，地址和 Token 复用"）。
- deviceId：首次启动生成 `and-<random>`，对齐 web `dev-` 前缀约定（sync.ts deviceId()）。

## 7. 风险与红线

- **块编辑器差距**：Compose 自建编辑器与 BlockNote 所见即所得有差距，A06 优先保"数据互通正确"，样式差异记录到 A14 校准清单。
- **凭据安全**：token 只进 EncryptedSharedPreferences 与 BuildConfig 注入路径，**不写仓库/文档**（红线 2）。
- **工程纪律**：安卓构建抢 `ops/锁/构建.lock`；`gradlew --stop` 先行；APK 路径写报告；DONE 门槛=assembleDebug+模拟器 install+冒烟（纪律 2）。
- **不做**：分栏（web 端也未做，F02 决策点 2）、AI 面板（后置批次）、托盘类桌面特性。
