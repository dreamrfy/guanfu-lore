# 浏览器扩展（剪藏任意网页）

## 装上

1. Chrome / Edge 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开**开发者模式**。
3. 点「加载已解压的扩展程序」，选这个 `extension/` 目录。
4. 点扩展图标 → 填**剪藏服务地址**（本机自测 `http://127.0.0.1:8787`；云端用你的域名）→ 需要就填 Token → 保存。

## 用

- 页面上右下角会出现「✂ 剪藏」按钮，点它；或点扩展图标里的「剪藏当前页」。
- 成功后页面右下角提示「已剪藏：标题」。
- 回到网页端「快速剪藏 → 服务器剪藏箱」能看到这条，一键导入「剪藏库」。

## 设计要点

- **正文由浏览器抓，服务器不自己抓**：普通网页正文要渲染才有，服务端直接拉 HTML 常常拿到空壳。
  扩展在渲染后的页面里取正文，交给服务端清洗（去脚本/样式）并存档——**服务端只信清洗后的内容**。
- 扩展抓到的正文可能很大，截断到 200KB 再上传。
- 服务端会把这条剪藏写进同一个 R2 桶，所以它和微信转发来的剪藏在「剪藏箱」里长得一样。

## 已知限制

- **https 页面调 http 服务会被浏览器拦**（混合内容）。要么用 `http://127.0.0.1`（浏览器视为可信来源），
  要么等域名 + HTTPS 到位后填 `https://` 地址。
- 没有"划线高亮"（只剪整页）——划线要等编辑器侧的选区协议，列入下一批。
- 剪藏的正文里如果有登录后才可见的内容，扩展抓到什么就是什么（不会绕过权限）。
