它为你做什么

四步闭环，把互联网信息变成你自己的知识。

📥 剪藏（捕获）

微信公众号文章、B站视频，微信转发即入库；网页划线、粘贴链接也行。原文本地留底，不怕被删。

🗂 多维表格（整理）

块式文档 + Notion 式多维表，筛选、排序、分组视图，学习进度尽在掌握。

🤖 Agent 级 AI（提炼）

总结改写、知识库问答（RAG）、可挂 Skill 与 MCP；供应商你自己选，Key 自己管。

📤 导出分享（输出）

Markdown / HTML 导出，整库备份恢复，数据永远在你手里。

上手三步

观复是纯开源自部署软件：你的 AI Key、你的存储桶、你的数据。

  1. ① 自选服务 —— 在设置界面填入你自己的 AI 供应商与对象存储（任何兼容 OpenAI 接口的服务、任何 S3 兼容桶）。
  2. ② 部署剪藏服务 —— 一份 Docker Compose 把服务端跑起来，配好域名即可从微信转发收藏。
  3. ③ 开始收集 —— 桌面端写作整理，手机端微信转发即剪藏。
